# 二分查找与二分答案

> **学完能做到**：在有序序列里 O(log n) 查找；识别"最大的最小值 / 最小的最大值"类题目并用二分答案解决；实数二分。
> **前置知识**：排序、函数。

---

## 1. 猜数游戏

我心里想一个 1～100 的数，你每猜一次我告诉你"大了"或"小了"。最聪明的策略是每次猜中间：50、25 或 75……每次排除一半，最多 7 次就能猜中（2⁷ = 128 > 100）。

这就是**二分**：每次把范围缩小一半，n 个元素只需要 log₂n 次。10⁹ 个元素也只要 30 次。

## 2. 二分查找

**前提：序列有序。**

### 找第一个 ≥ x 的位置（最常用）

```cpp
// a[1..n] 从小到大，返回第一个 >= x 的下标，没有则返回 n+1
int lowerBound(int x) {
    int l = 1, r = n, ans = n + 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] >= x) { ans = mid; r = mid - 1; }   // mid 可能是答案，继续往左找更靠前的
        else l = mid + 1;                              // mid 太小，答案在右边
    }
    return ans;
}
```

手推：a = [1, 3, 3, 5, 8]，找第一个 ≥ 4：

| l | r | mid | a[mid] | 动作 |
| --- | --- | --- | --- | --- |
| 1 | 5 | 3 | 3 | 3 < 4，l = 4 |
| 4 | 5 | 4 | 5 | 5 ≥ 4，ans = 4，r = 3 |
| 4 | 3 | — | — | 结束，答案 4 |

**这个写法的好处**：用 `ans` 记录答案，`l <= r` 循环，`l = mid + 1`、`r = mid - 1`，不会死循环。**建议只背这一种写法**，所有二分都按这个改。

### STL 写法

```cpp
int p = lower_bound(a + 1, a + n + 1, x) - a;   // 第一个 >= x
int q = upper_bound(a + 1, a + n + 1, x) - a;   // 第一个 > x
int cnt = q - p;                                // x 出现的次数
```

### 例：A-B 数对（P1102）

给 n 个数和 C，问有多少对满足 A - B = C。即对每个 B，数有多少个 A = B + C。排序后对每个 a[i] 用 `upper_bound - lower_bound` 数 a[i] + C 出现的次数，总复杂度 O(n log n)。答案可能很大，用 `long long`。

## 3. 二分答案

### 什么题可以二分答案

题目问"**最大的最小值**"或"**最小的最大值**"，或者问"至少/至多是多少才能满足要求"，往往可以二分答案。

**核心条件：单调性**。如果答案 x 可行，那么比 x 更"宽松"的答案也一定可行。这样可行和不可行之间有一条分界线，二分找这条线。

### 套路

1. 确定答案的范围 [L, R]。
2. 写 `check(mid)`：**假设答案是 mid，能不能做到？** 这一步通常用贪心，O(n)。
3. 二分：可行就往更优的方向找，不可行就往另一边。

总复杂度 O(n log(R - L))。

### 例题精讲：砍树（P1873）

n 棵树，锯片高度设为 H，每棵比 H 高的树会被砍下 (高度 - H) 的部分。要至少得到 M 米木材，H 最大是多少？

- H 越小，得到的木材越多。如果 H 可行，那比 H 小的都可行 → 单调。
- check(H)：算砍下的总长度是否 ≥ M。

```cpp
bool check(long long H) {
    long long total = 0;
    for (int i = 1; i <= n; i++) if (h[i] > H) total += h[i] - H;
    return total >= M;
}

long long l = 0, r = 1e9, ans = 0;
while (l <= r) {
    long long mid = (l + r) / 2;
    if (check(mid)) { ans = mid; l = mid + 1; }   // 可行，试试更高
    else r = mid - 1;
}
```

### 例题精讲：跳石头（P2678）

起点到终点之间有 N 块石头，最多移走 M 块，使得**相邻两块之间的最短距离尽量大**。

- 问"最短距离的最大值"→ 二分答案 d。
- check(d)：要让所有相邻距离都 ≥ d，最少要移走几块？贪心：从起点走，如果下一块石头离上一块**保留的**石头不到 d，就移走它；否则保留。最后比较移走的块数和 M。

```cpp
bool check(int d) {
    int removed = 0, last = 0;          // last：上一块保留的石头位置
    for (int i = 1; i <= n + 1; i++) {  // a[n+1] = L 是终点
        if (a[i] - last < d) removed++;
        else last = a[i];
    }
    return removed <= m;
}
```

> 注意：终点不能移走。如果终点离 last 不到 d，上面的写法会"移走终点"，其实等价于移走 last 那块石头，次数一样，所以是对的。

### 例题精讲：数列分段 II（P1182）

把数列分成 M 段，使每段和的**最大值最小**。

- 二分答案 x（每段和不超过 x）。
- check(x)：贪心地往当前段里加数，超过 x 就开新的一段，看段数是否 ≤ M。
- 下界是最大的单个数（否则这个数放不进任何一段），上界是总和。

## 4. 实数二分

答案是小数时，循环固定次数或者直到区间足够小：

```cpp
double l = -100, r = 100;
for (int it = 0; it < 100; it++) {     // 100 次后精度远远足够
    double mid = (l + r) / 2;
    if (f(mid) 和 f(l) 同号) l = mid;
    else r = mid;
}
```

### 例：一元三次方程求解（P1024）

已知三个根都在 [-100, 100]，且根与根的差 ≥ 1。在每个长度为 1 的区间 [i, i+1] 里，如果 f(i) 和 f(i+1) 异号（或 f(i) = 0），说明里面有根，再二分找到它。

## 5. 第 k 小的数（P1923）

n 个数（n 到 5×10⁶）求第 k 小。`sort` 可以过，但更快的是 `nth_element(a, a + k, a + n)`，平均 O(n)，它利用了快速排序"划分"的思想，只排需要的那一边。

## 6. 易错点清单

1. 序列没排序就二分。
2. 死循环：l 和 r 更新不当。固定用"`ans` + `l <= r` + `mid ± 1`"的写法。
3. 溢出：`l + r` 可能超过 int，用 `long long` 或 `l + (r - l) / 2`。
4. 答案范围的上下界设错（尤其下界）。
5. check 的方向弄反：可行时应该往哪边走？想清楚"更优"是更大还是更小。

## 8. 自测

1. 有序数组 [2, 4, 4, 4, 7]，`upper_bound(4) - lower_bound(4)` 是多少？
2. 为什么"跳石头"可以二分？
3. 二分 10¹⁸ 的范围，大约要循环几次？

<details><summary>答案</summary>

1. 3（4 出现了 3 次）。
2. 如果最短距离 d 能做到，那么更小的距离也一定能做到（移走的石头只会更少），满足单调性。
3. 约 60 次（2⁶⁰ ≈ 10¹⁸）。
