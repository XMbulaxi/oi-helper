# 栈与队列

## 栈：后进先出

像一摞盘子，只能从顶上放、从顶上拿。

```cpp
stack<int> st;
st.push(x);   // 放入
st.top();     // 看栈顶
st.pop();     // 弹出
st.empty();   // 是否为空
```

**用途：** 括号匹配、表达式求值（P1449 后缀表达式）、模拟进栈出栈（P4387）。

## 队列：先进先出

像排队，从队尾进、从队头出。

```cpp
queue<int> q;
q.push(x);
q.front();
q.pop();
```

**用途：** 模拟排队（P1996 约瑟夫问题）、缓存（P1540 机器翻译）、以及之后的 **BFS 广度优先搜索**。

## 链表

P1160 队列安排需要频繁在中间插入、删除，用数组模拟双向链表：

```cpp
int L[N], R[N];
// 把 x 插到 k 的右边
R[x] = R[k]; L[x] = k;
L[R[k]] = x; R[k] = x;
```

## 卡特兰数

P1044 栈：n 个数进栈出栈，有多少种出栈顺序？答案是卡特兰数，可以用递推 `f[i] = sum(f[j] * f[i-1-j])` 求出。

## 常见错误

1. 栈或队列为空时调用 `top()` / `front()` / `pop()`，会运行错误。先判断 `empty()`。
2. 多组数据时没清空栈。

## 做题建议

按顺序做。约瑟夫问题用队列模拟：报数的人出队再入队，报到 m 的人直接出队。
