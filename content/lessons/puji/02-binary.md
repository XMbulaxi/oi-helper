# 排序进阶与二分

## 二分查找

在**有序**数组里找一个数，每次看中间，排除一半。速度 O(log n)。

```cpp
// 找第一个 >= x 的位置
int l = 1, r = n, ans = -1;
while (l <= r) {
    int mid = (l + r) / 2;
    if (a[mid] >= x) { ans = mid; r = mid - 1; }
    else l = mid + 1;
}
```

STL 写法：`lower_bound(a + 1, a + n + 1, x) - a` 返回第一个 >= x 的下标，`upper_bound` 返回第一个 > x 的下标。

## 二分答案

当题目问"**最大的最小值**"或"**最小的最大值**"时，往往可以二分答案：

1. 猜一个答案 mid。
2. 写一个 `check(mid)` 判断这个答案能不能做到。
3. 能做到就往更优的方向找，做不到就往另一边找。

能二分的前提是答案有**单调性**：如果 mid 可行，那比 mid 更"宽松"的也一定可行。

```cpp
// 跳石头：最短跳跃距离最大是多少
bool check(int d) {   // 最短距离至少为 d，需要移走几块石头
    int cnt = 0, last = 0;
    for (int i = 1; i <= n + 1; i++) {
        if (a[i] - last < d) cnt++;
        else last = a[i];
    }
    return cnt <= m;
}
```

## 实数二分

P1024 在一个小区间里二分找方程的根，循环到 `r - l < 1e-4` 为止。

## 常见错误

1. `l` 和 `r` 的更新写错导致死循环。固定用上面这一种写法，减少出错。
2. `mid = (l + r) / 2` 在 l + r 很大时溢出，用 `long long` 或 `l + (r - l) / 2`。
3. 数组没排序就二分。
