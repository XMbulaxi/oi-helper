# 动态规划入门

动态规划（DP）= 把大问题拆成小问题，记下小问题的答案，避免重复计算。

## 做 DP 的四步

1. **定义状态**：`f[i]` 或 `f[i][j]` 表示什么？（这是最难也最关键的一步）
2. **写转移方程**：`f[i]` 怎么由更小的状态算出来？
3. **确定初始值**（边界）。
4. **确定计算顺序**和最终答案在哪。

## 例：数字三角形（P1216）

- 状态：`f[i][j]` 表示从 (i, j) 走到最底层能得到的最大和。
- 转移：`f[i][j] = a[i][j] + max(f[i+1][j], f[i+1][j+1])`。
- 初始：最底层 `f[n][j] = a[n][j]`。
- 顺序：从下往上算，答案是 `f[1][1]`。

## 例：最长上升子序列（LIS）

- 状态：`f[i]` 表示以第 i 个数结尾的最长上升子序列长度。
- 转移：`f[i] = max(f[j] + 1)`，其中 `j < i` 且 `a[j] < a[i]`。
- 复杂度 O(n²)。导弹拦截（P1020）数据大时需要 O(n log n) 的二分优化写法。

## 例：最长公共子序列（LCS）

```cpp
if (a[i] == b[j]) f[i][j] = f[i-1][j-1] + 1;
else f[i][j] = max(f[i-1][j], f[i][j-1]);
```

P1439 是排列的 LCS，可以转化为 LIS 来做到 O(n log n)。

## 记忆化搜索

不会确定计算顺序时，可以写成递归 + 记忆化。滑雪（P1434）就很适合：

```cpp
int dfs(int x, int y) {
    if (f[x][y]) return f[x][y];
    f[x][y] = 1;
    for (四个方向) if (h[nx][ny] < h[x][y]) f[x][y] = max(f[x][y], dfs(nx, ny) + 1);
    return f[x][y];
}
```

## 常见错误

1. 状态定义不清楚，转移时自己也说不清 `f[i]` 是什么意思。**先用一句话写下状态的含义**。
2. 计算顺序不对，用到了还没算好的状态。
3. 初始值漏设。

## 做题建议

P1216 → P1434 → P1164（计数类 DP）→ P1020 → P1439。每题做完都写下"状态、转移、初始、答案"四行笔记。
