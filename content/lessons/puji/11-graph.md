# 图的存储与遍历

## 什么是图

由点和边组成。边可以有方向（有向图）或没有方向（无向图），也可以有边权。

## 两种存法

**邻接矩阵**：`g[u][v] = 1` 表示有边。简单，但点多时（比如 10⁵）存不下。

**邻接表（推荐）**：

```cpp
vector<int> g[N];
g[u].push_back(v);          // 有向边 u -> v
// 无向图再加一句 g[v].push_back(u);

for (int v : g[u]) { ... }  // 遍历 u 的所有出边
```

带边权时用 `vector<pair<int,int>>`。

## DFS 和 BFS 遍历

和地图上的搜索一样，只是"四个方向"换成了"所有相邻的点"。

```cpp
void dfs(int u) {
    vis[u] = true;
    cout << u << " ";
    for (int v : g[u]) if (!vis[v]) dfs(v);
}
```

P5318 要求按编号从小到大访问，存好边后先对每个 `g[u]` 排序。

## 反向建图

P3916：求每个点能到达的最大编号点。正着想很难，**反过来建图**，从编号最大的点开始遍历，能走到的点答案就是它。

## 拓扑排序

有向无环图里，把所有点排成一列，使得每条边都从前指向后。P1113 杂务就是拓扑排序 + 求最早完成时间。

```cpp
// 入度为 0 的点入队
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) {
        f[v] = max(f[v], f[u] + len[v]);
        if (--indeg[v] == 0) q.push(v);
    }
}
```

## 常见错误

1. 无向图只加了一个方向的边。
2. 用邻接矩阵存大图，内存超限。
