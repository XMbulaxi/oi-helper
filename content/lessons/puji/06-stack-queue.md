## 1. 栈：后进先出

想象一摞盘子：只能从**顶上**放，只能从**顶上**拿。最后放的最先拿走（LIFO）。

```cpp
stack<int> st;
st.push(x);     // 压入栈顶
st.top();       // 查看栈顶（不删除）
st.pop();       // 弹出栈顶（不返回值）
st.empty();     // 是否为空
st.size();
```

也可以用数组手写，速度更快：

```cpp
int stk[N], top = 0;
stk[++top] = x;   // 压入
stk[top];         // 栈顶
top--;            // 弹出
top == 0;         // 为空
```

## 2. 栈的应用

### 括号匹配（P1739）

遇到左括号压栈；遇到右括号，栈顶必须是匹配的左括号，弹出；最后栈要为空。

```cpp
bool check(const string &s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(') st.push(c);
        else if (c == ')') {
            if (st.empty()) return false;   // 右括号多了
            st.pop();
        }
    }
    return st.empty();                       // 左括号多了也不行
}
```

多种括号（`()[]{}`）时，弹出前要检查类型是否对应。

### 后缀表达式（P1449）

后缀表达式（逆波兰式）把运算符写在数字后面：`3 4 + 5 *` 表示 (3+4)×5。

计算方法：遇到数字压栈；遇到运算符，弹出两个数（**先弹出的是右操作数**），计算后压回。

```
3 4 + 5 *
压3 → [3]
压4 → [3,4]
+  → 弹出4和3，压7 → [7]
压5 → [7,5]
*  → 弹出5和7，压35 → [35]
```

### 中缀表达式求值（P1981）

计算 `1+2*3+4`（只有加和乘）。思路：遇到 `*` 立刻和栈顶相乘，遇到 `+` 就把数压栈，最后把栈里所有数加起来。

```cpp
// 题目要求结果对 10000 取模
long long cur; char op;
cin >> cur;
stack<long long> st;
st.push(cur % 10000);
while (cin >> op >> cur) {
    cur %= 10000;
    if (op == '*') { long long t = st.top(); st.pop(); st.push(t * cur % 10000); }
    else st.push(cur);
}
long long sum = 0;
while (!st.empty()) { sum = (sum + st.top()) % 10000; st.pop(); }
```

### 验证栈序列（P4387）

给入栈顺序和出栈顺序，判断是否可能。**模拟**：按入栈顺序一个个压入，每压一个就检查栈顶是否等于下一个要出栈的，相等就一直弹。最后栈空就可能。

### 出栈序列个数（P1044）

1～n 依次入栈，有多少种出栈序列？答案是**卡特兰数**：

f(0) = 1，f(n) = Σ f(i) × f(n-1-i)（i 从 0 到 n-1）

理解：设 1 是第 i+1 个出栈的，那么在它之前出栈的 i 个数（2～i+1）有 f(i) 种，之后的 n-1-i 个数有 f(n-1-i) 种。

## 3. 队列：先进先出

排队买饭：从**队尾**进，从**队头**出（FIFO）。

```cpp
queue<int> q;
q.push(x);      // 入队（队尾）
q.front();      // 队头
q.back();       // 队尾
q.pop();        // 出队（队头）
q.empty();
q.size();
```

数组手写：

```cpp
int que[N], head = 1, tail = 0;
que[++tail] = x;     // 入队
que[head];           // 队头
head++;              // 出队
head > tail;         // 为空
```

**双端队列 deque**：两头都能进出，`push_front`、`push_back`、`pop_front`、`pop_back`。

## 4. 队列的应用

### 约瑟夫问题（P1996）

n 个人围成一圈，从 1 开始报数，报到 m 的人出圈，下一个人重新从 1 开始。输出出圈顺序。

用队列模拟"转圈"：队头的人报数，没报到 m 就移到队尾，报到 m 就出圈。

```cpp
queue<int> q;
for (int i = 1; i <= n; i++) q.push(i);
int cnt = 0;
while (!q.empty()) {
    int x = q.front(); q.pop();
    if (++cnt == m) { cout << x << " "; cnt = 0; }
    else q.push(x);
}
```

## 5. 链表

数组插入、删除要移动后面所有元素，O(n)。链表每个元素记住"前一个是谁、后一个是谁"，插入删除只要改几个指针，O(1)。

### 用数组实现双向链表

```cpp
int L[N], R[N];     // L[x]：x 左边是谁；R[x]：x 右边是谁；0 表示头哨兵

// 初始化：只有哨兵 0，自己连自己
R[0] = 0; L[0] = 0;

// 把 x 插到 k 的右边
void insertRight(int k, int x) {
    R[x] = R[k]; L[x] = k;
    L[R[k]] = x; R[k] = x;
}
// 把 x 插到 k 的左边 = 插到 L[k] 的右边
void insertLeft(int k, int x) { insertRight(L[k], x); }

// 删除 x
void remove(int x) {
    R[L[x]] = R[x];
    L[R[x]] = L[x];
}

// 从头到尾遍历
for (int x = R[0]; x != 0; x = R[x]) cout << x << " ";
```

> 插入时**改指针的顺序很重要**：先设置 x 自己的左右，再改邻居。画图辅助理解。

### 例：队列安排（P1160）

1 号同学先站好，然后 2～N 号同学依次站到某个已有同学的左边或右边，最后删掉 M 个同学，输出队列。正是上面的双向链表。

## 6. 易错点清单

1. 栈/队列为空时调用 `top()` / `front()` / `pop()`，运行错误。**先判空**。
2. 后缀表达式减法、除法的操作数顺序弄反。
3. 多组数据时没清空栈或队列（STL 没有 `clear`，可以重新定义一个，或 `while (!q.empty()) q.pop();`）。
4. 链表重复删除同一个元素，指针乱掉。用一个数组标记是否已删除。
