# 高精度

`long long` 最多存到约 9.2×10¹⁸。更大的数要用数组一位一位存，模拟竖式计算。

## 存法

把数字**倒着**存进数组，个位放在 `a[0]`，这样进位往后加很方便。

```cpp
string s; cin >> s;
int len = s.size();
for (int i = 0; i < len; i++) a[i] = s[len - 1 - i] - '0';
```

## 加法

```cpp
int lc = max(la, lb);
for (int i = 0; i < lc; i++) {
    c[i] += a[i] + b[i];
    c[i + 1] += c[i] / 10;
    c[i] %= 10;
}
if (c[lc]) lc++;              // 最高位可能进位
for (int i = lc - 1; i >= 0; i--) cout << c[i];
```

## 乘法（高精 × 高精）

第 i 位乘第 j 位，结果加到第 i + j 位，最后统一进位：

```cpp
for (int i = 0; i < la; i++)
    for (int j = 0; j < lb; j++)
        c[i + j] += a[i] * b[j];
for (int i = 0; i < la + lb; i++) { c[i + 1] += c[i] / 10; c[i] %= 10; }
```

输出前要**去掉前导零**，但如果结果是 0，至少保留一位。

## 高精 × 低精

阶乘之和（P1009）只需要"大数乘小数"，每一位乘上小数再进位即可，比高精×高精简单。

## 常见错误

1. 忘记处理最高位进位或去前导零（乘 0 的情况尤其容易错）。
2. 数组开小了：两个 2000 位数相乘，结果最多 4000 位。
