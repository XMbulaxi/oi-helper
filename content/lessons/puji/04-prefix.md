# 前缀和与差分

## 前缀和：快速求区间和

`s[i] = a[1] + a[2] + ... + a[i]`，那么区间 [l, r] 的和就是 `s[r] - s[l-1]`，一次查询 O(1)。

```cpp
for (int i = 1; i <= n; i++) s[i] = s[i - 1] + a[i];
// 查询
cout << s[r] - s[l - 1];
```

## 二维前缀和

```cpp
s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j];
// 子矩阵 (x1,y1) ~ (x2,y2) 的和
s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1];
```

## 差分：快速给区间加一个数

`d[i] = a[i] - a[i-1]`。给区间 [l, r] 都加上 x，只需要：

```cpp
d[l] += x;
d[r + 1] -= x;
```

所有修改做完后，对 d 求一遍前缀和就得到最终数组。

二维差分（P3397 地毯）：

```cpp
d[x1][y1]++; d[x1][y2+1]--; d[x2+1][y1]--; d[x2+1][y2+1]++;
```

## 最大子段和

P1115：以第 i 个数结尾的最大和 `f[i] = max(a[i], f[i-1] + a[i])`。这其实已经是动态规划了。

## 常见错误

1. 下标从 0 开始导致 `s[l-1]` 越界。前缀和数组建议从 1 开始用。
2. 和很大时用了 `int`。
