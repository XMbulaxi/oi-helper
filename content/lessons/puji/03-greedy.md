# 贪心

每一步都选**当前看起来最好**的，期望最后得到整体最优。

贪心不一定对，所以关键是：**想清楚为什么这样选是对的**。常用办法是"交换论证"：假设最优解不是这么选的，交换两个元素后答案不会变差。

## 几类经典贪心

**排序后贪心**

- 排队接水（P1223）：接水时间短的人先接，总等待时间最少。
- 部分背包（P2240）：按"价值 / 重量"从大到小拿。

**区间问题**

线段覆盖（P1803）：选最多的不重叠区间，**按右端点从小到大排序**，能选就选。

```cpp
sort(seg + 1, seg + n + 1, [](Seg a, Seg b) { return a.r < b.r; });
int last = -1, cnt = 0;
for (int i = 1; i <= n; i++)
    if (seg[i].l >= last) { cnt++; last = seg[i].r; }
```

**每次取最小：优先队列**

合并果子（P1090）：每次合并最小的两堆。

```cpp
priority_queue<int, vector<int>, greater<int>> q;  // 小根堆
while (q.size() > 1) {
    int a = q.top(); q.pop();
    int b = q.top(); q.pop();
    ans += a + b; q.push(a + b);
}
```

**双指针**

纪念品分组（P1094）：排序后，最大的和最小的能配就配成一组。

## 常见错误

1. 没想清楚就贪，样例过了但其实是错的。多造几组小数据手算验证。
2. 排序关键字选错（比如线段覆盖按左端点排）。

## 做题建议

按顺序做。P5019 铺设道路有一个很漂亮的结论：答案等于所有"比前一个高出来的部分"之和。P1106 删数问题注意前导零。
