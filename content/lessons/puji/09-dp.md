> **学完能做到**：用"状态—转移—初始值—答案"四步法设计 DP；解决数字三角形、最长上升子序列、最长公共子序列等经典问题；会写记忆化搜索。
> **前置知识**：递推与递归、数组。

## 1. 从递推到动态规划

零基础阶段学过递推：过河卒 f[i][j] = f[i-1][j] + f[i][j-1]。动态规划（DP）就是递推的升级版，用来求**最优值**（最大、最小）或**方案数**。

DP 能用的两个条件：

1. **最优子结构**：大问题的最优解，可以由小问题的最优解组合出来。
2. **无后效性**：一个状态一旦确定，以后怎么走不受"之前是怎么到这个状态的"影响。

## 2. 四步法

做任何 DP 题都按这四步：

1. **状态**：f[i] 或 f[i][j] 表示什么？**用一句完整的话写下来。**
2. **转移**：f[i] 怎么由更小的状态算出来？（想"最后一步"）
3. **初始值**：最小的状态是多少？
4. **答案**：最终答案是哪个状态（或哪些状态的最值）？

## 3. 例一：数字三角形（P1216）

```
        7
      3   8
    8   1   0
  2   7   4   4
4   5   2   6   5
```

从顶部走到底部，每步走到左下或右下，求经过数字之和的最大值。

**为什么贪心不行**：每步选大的那个，7 → 8 → 1 → 7 → 5 = 28，但最优是 7 → 3 → 8 → 7 → 5 = 30。

**四步法**（从下往上想）：

1. 状态：f[i][j] = 从 (i, j) 出发走到底部，能得到的最大和。
2. 转移：从 (i, j) 只能去 (i+1, j) 或 (i+1, j+1)，选更大的：
   **f[i][j] = a[i][j] + max(f[i+1][j], f[i+1][j+1])**
3. 初始值：最后一行 f[n][j] = a[n][j]。
4. 答案：f[1][1]。

```cpp
for (int j = 1; j <= n; j++) f[n][j] = a[n][j];
for (int i = n - 1; i >= 1; i--)
    for (int j = 1; j <= i; j++)
        f[i][j] = a[i][j] + max(f[i + 1][j], f[i + 1][j + 1]);
cout << f[1][1];
```

**为什么比暴力快**：暴力要试 2ⁿ⁻¹ 条路；DP 每个格子只算一次，O(n²)。关键在于"从 (i, j) 往下的最大和"只和 (i, j) 有关，和怎么走到 (i, j) 无关——这就是无后效性。

## 4. 例二：最长上升子序列（LIS）

给一个序列，找最长的严格递增子序列（不要求连续）。例如 [3, 1, 4, 1, 5, 9, 2, 6] 的 LIS 是 [1, 4, 5, 9] 或 [1, 4, 5, 6]，长度 4。

1. 状态：f[i] = **以 a[i] 结尾**的最长上升子序列的长度。
2. 转移：a[i] 前面接的是哪个？枚举 j < i 且 a[j] < a[i]：
   **f[i] = max(f[j] + 1)**，如果没有这样的 j，f[i] = 1。
3. 初始值：f[i] 至少为 1。
4. 答案：**max(f[1..n])**（不一定以最后一个结尾）。

```cpp
int ans = 0;
for (int i = 1; i <= n; i++) {
    f[i] = 1;
    for (int j = 1; j < i; j++)
        if (a[j] < a[i]) f[i] = max(f[i], f[j] + 1);
    ans = max(ans, f[i]);
}
```

O(n²)。

### O(n log n) 优化

维护数组 g，g[k] = 长度为 k 的上升子序列的**最小结尾**。g 一定是递增的。对每个 a[i]，在 g 中二分找第一个 ≥ a[i] 的位置替换它（找不到就接在末尾）。最后 g 的长度就是答案。

```cpp
vector<int> g;
for (int i = 1; i <= n; i++) {
    auto it = lower_bound(g.begin(), g.end(), a[i]);   // 严格上升用 lower_bound
    if (it == g.end()) g.push_back(a[i]);
    else *it = a[i];
}
cout << g.size();
```

> 求"最长不下降"（可以相等）用 `upper_bound`。求下降序列可以把数取负。

### 例：导弹拦截（P1020）

第一问：最长**不上升**子序列。第二问：最少要几套系统——根据 Dilworth 定理，等于最长**上升**子序列的长度。数据 10⁵，要用 O(n log n)。

### 例：合唱队形（P1091）

最少让几个人出列，使队形先升后降。对每个位置 i，算"以 i 结尾的 LIS"（从左往右）和"以 i 开头的最长下降"（从右往左做 LIS），两者相加减 1 就是以 i 为最高点的最长队形。

## 5. 例三：最长公共子序列（LCS）

两个序列 A、B，求最长的公共子序列（都不要求连续）。

1. 状态：f[i][j] = A 的前 i 个和 B 的前 j 个的 LCS 长度。
2. 转移：看最后一个字符：
   - A[i] == B[j]：这个字符一定可以用上，**f[i][j] = f[i-1][j-1] + 1**
   - 否则：丢掉 A[i] 或丢掉 B[j]，**f[i][j] = max(f[i-1][j], f[i][j-1])**
3. 初始值：f[0][j] = f[i][0] = 0。
4. 答案：f[n][m]。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        if (A[i] == B[j]) f[i][j] = f[i - 1][j - 1] + 1;
        else f[i][j] = max(f[i - 1][j], f[i][j - 1]);
```

O(nm)。P1439 中 n 到 10⁵，O(n²) 会超时。但两个序列都是 1～n 的**排列**，可以把 A 中每个数映射成它在 A 中的位置，然后对映射后的 B 求 LIS。

## 6. 计数 DP：小A点菜（P1164）

n 道菜，价格 aᵢ，恰好花完 M 元有多少种点法（每道菜最多点一次）。

1. 状态：f[i][j] = 前 i 道菜，恰好花 j 元的方案数。
2. 转移：第 i 道菜不点 f[i-1][j]，点 f[i-1][j - aᵢ]（j ≥ aᵢ 时）。两者相加。
3. 初始值：f[0][0] = 1（什么都不点、花 0 元，是一种方案）。
4. 答案：f[n][M]。

这其实是**01 背包求方案数**，下一单元会系统学习。

## 7. 记忆化搜索

不确定计算顺序时，可以写成递归，用数组记住算过的结果。

### 滑雪（P1434）

R × C 的高度图，只能从高处滑向相邻的低处，求最长滑雪路径。

格子之间的依赖关系不是简单的"从上到下"，很难确定循环顺序。记忆化搜索：

```cpp
int f[105][105];   // f[x][y] = 从 (x, y) 出发的最长路径长度，0 表示还没算

int dfs(int x, int y) {
    if (f[x][y]) return f[x][y];
    f[x][y] = 1;
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (inside(nx, ny) && h[nx][ny] < h[x][y])
            f[x][y] = max(f[x][y], dfs(nx, ny) + 1);
    }
    return f[x][y];
}
// 答案 = 所有 dfs(i, j) 的最大值
```

每个格子只算一次，O(RC)。

## 8. 例题精讲：挖地雷（P2196）

N 个地窖有地雷，地窖之间有单向通路（只从编号小的通向编号大的），从任意地窖出发，求最多挖多少地雷，并输出路径。

1. 状态：f[i] = 从 i 出发能挖到的最多地雷。
2. 转移：f[i] = a[i] + max(f[j])，j 是 i 能直接到的地窖。
3. 从 N 往 1 倒着算（因为只能通向更大的编号）。
4. 记录 nxt[i] 表示 f[i] 是从哪个 j 转移来的，最后沿着 nxt 输出路径。

> **记录路径的通用方法**：转移时记下"从哪来"，最后倒着（或顺着）走一遍。

## 9. 易错点清单

1. **状态定义不清**。一定先用一句话写下 f[i] 的含义。
2. **计算顺序错**：用到了还没算的状态。
3. **初始值漏设**，尤其是计数 DP 的 f[0] = 1。
4. **答案不一定是 f[n]**，LIS 的答案是 max(f[i])。
5. 数组维度开小。

## 11. 自测

1. LIS 中 f[i] 的含义是什么？答案为什么是 max(f[i]) 而不是 f[n]？
2. LCS 中 A[i] ≠ B[j] 时为什么取 max(f[i-1][j], f[i][j-1])？
3. 计数 DP 的初始值 f[0][0] = 1 表示什么？

<details><summary>答案</summary>

1. 以 a[i] 结尾的最长上升子序列长度。最长的那个不一定以最后一个数结尾。
2. 最后两个字符不同，至少有一个不在 LCS 里，分别去掉试试，取较大的。
3. 一个都不选、总和为 0，算一种方案。
