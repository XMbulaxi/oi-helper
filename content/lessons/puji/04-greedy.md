# 贪心

> **学完能做到**：在每一步做出局部最优选择来得到全局最优；掌握排序贪心、区间贪心、堆贪心；会用交换论证说明贪心是对的。
> **前置知识**：排序、STL。

---

## 1. 什么是贪心

贪心：每一步都选**当前看起来最好的**，希望最后的结果也是最好的。

例：用最少的硬币凑出 n 元（面额 1、5、10、50、100）。每次都用尽量大的面额，就是贪心。

**但贪心不总是对的**。面额是 1、3、4，凑 6 元：贪心选 4 + 1 + 1（3 枚），而最优是 3 + 3（2 枚）。

所以学贪心的关键是：**判断这个贪心对不对**。

## 2. 怎么判断贪心是对的

### 交换论证

假设有一个最优解，它不是按贪心的方式选的。如果能证明**交换其中两个元素后，答案不会变差**，那么不断交换就能把最优解变成贪心的解，说明贪心也是最优的。

### 举反例

想不清楚时，**造几组小数据**，用暴力算出正确答案，和贪心的结果对比。有反例就换思路。

## 3. 排序后贪心

### 排队接水（P1223）

n 个人接水，第 i 人要 tᵢ 分钟，怎么排队让**平均等待时间**最小？

**贪心**：接水快的人先接。

**交换论证**：相邻两人 A、B，A 在前。交换他们不影响其他人的等待时间；A 在前时 B 多等 tA，B 在前时 A 多等 tB。所以 tA < tB 时 A 应在前。

```cpp
sort(p + 1, p + n + 1, [](auto a, auto b) {
    return a.t != b.t ? a.t < b.t : a.id < b.id;
});
long long wait = 0, total = 0;
for (int i = 1; i <= n; i++) {
    total += wait;          // 第 i 个人等了前面所有人的时间
    wait += p[i].t;
}
printf("%.2f", (double)total / n);
```

### 部分背包（P2240）

金币可以分割，背包容量 T，要价值最大。按"**单位重量的价值**"从大到小拿，最后一堆拿一部分。

比较 v₁/w₁ > v₂/w₂ 时，为了避免小数，可以写成 v₁ × w₂ > v₂ × w₁。

## 4. 区间贪心

### 线段覆盖 / 活动安排（P1803）

n 个比赛，每个有开始和结束时间，最多能参加几个（不能重叠）？

**贪心**：**按结束时间从早到晚排序**，能参加就参加。

**为什么**：结束得越早，留给后面的时间越多。如果最优解第一个选的不是结束最早的那个，把它换成结束最早的，后面的安排不受影响。

```cpp
sort(seg + 1, seg + n + 1, [](auto a, auto b) { return a.r < b.r; });
int last = 0, cnt = 0;
for (int i = 1; i <= n; i++)
    if (seg[i].l >= last) { cnt++; last = seg[i].r; }
```

> 常见错误：按开始时间排序，或按长度排序，都有反例。

### 其他区间问题（了解）

- **区间选点**：最少选几个点，使每个区间至少含一个点 → 按右端点排序，每次选右端点。
- **区间覆盖**：用最少的区间覆盖整条线段 → 按左端点排序，每次在能接上的区间里选右端点最远的。

## 5. 堆贪心：每次取最小

### 合并果子（P1090）

n 堆果子，每次合并两堆，花费是两堆之和，求最小总花费。

**贪心**：每次合并**最小的两堆**。（这其实就是哈夫曼编码。）

需要反复"取出最小值、插入新值"，用**优先队列（堆）**：

```cpp
priority_queue<int, vector<int>, greater<int>> q;   // 小根堆：top 是最小值
for (int i = 1; i <= n; i++) { int x; cin >> x; q.push(x); }
long long ans = 0;
while (q.size() > 1) {
    int a = q.top(); q.pop();
    int b = q.top(); q.pop();
    ans += a + b;
    q.push(a + b);
}
```

`priority_queue<int>` 默认是**大根堆**（top 最大），要小根堆就写成上面那样。每次操作 O(log n)。

## 6. 双指针贪心

### 纪念品分组（P1094）

每组最多两件，价格和不超过 w，求最少分几组。

**贪心**：排序后，最便宜的和最贵的能配就配；配不了，最贵的单独一组。

```cpp
sort(a + 1, a + n + 1);
int l = 1, r = n, groups = 0;
while (l <= r) {
    if (l < r && a[l] + a[r] <= w) l++;   // 最便宜的和最贵的一组
    r--;                                  // 最贵的已经分好
    groups++;
}
```

## 7. 例题精讲：铺设道路（P5019）

一段路有 n 块，每块下陷深度 dᵢ，每天可以选一段**连续**区间把深度都减 1，问最少几天填平。

**结论**：答案 = d₁ + Σ max(0, dᵢ - dᵢ₋₁)。

**理解**：从左往右看，如果 dᵢ ≤ dᵢ₋₁，那么填 i-1 的时候可以"顺便"把 i 填了，不需要额外天数；如果 dᵢ > dᵢ₋₁，多出来的 dᵢ - dᵢ₋₁ 层必须新开区间。

```cpp
long long ans = d[1];
for (int i = 2; i <= n; i++) if (d[i] > d[i - 1]) ans += d[i] - d[i - 1];
```

这类"差分 + 贪心"的思路在 NOIP 里多次出现（NOIP2013 积木大赛是同一题）。

## 8. 例题精讲：删数问题（P1106）

一个高精度正整数删去 k 位，使剩下的数最小。

**贪心**：从左往右，如果当前位比下一位大，删掉当前位（这样高位变小了）。重复 k 次。可以用栈 O(n) 实现：

```cpp
string res;
for (char c : s) {
    while (k > 0 && !res.empty() && res.back() > c) { res.pop_back(); k--; }
    res += c;
}
while (k > 0) { res.pop_back(); k--; }       // 还没删够，删末尾
// 去前导零，全删光时输出 0
size_t p = res.find_first_not_of('0');
cout << (p == string::npos ? "0" : res.substr(p));
```

## 9. 例题精讲：国王游戏（P1080）

每个大臣左右手各有一个数，大臣得到的金币 = 他前面所有人左手数的乘积 ÷ 他自己右手的数。怎么排使**得金币最多的大臣得的最少**？

**交换论证**：相邻两人 i、j，比较谁在前。推导可得：**按左手 × 右手从小到大排序**。

因为乘积极大，需要用高精度乘法和高精度除以低精度。这是普及组贪心中最难的一题，适合作为挑战。

## 10. 易错点清单

1. 没验证就贪心，样例过了但实际是错的。
2. 排序关键字选错（区间问题尤其容易）。
3. `priority_queue` 默认是大根堆。
4. 比较分数时用了小数，产生精度误差，改用交叉相乘。
5. 累加和溢出。
