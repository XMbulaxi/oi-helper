# 前缀和与差分

> **学完能做到**：O(1) 求任意区间和；O(1) 给区间加上一个数；处理二维的子矩阵和与子矩阵修改。
> **前置知识**：数组。

---

## 1. 问题引入

给一个长度为 n 的数组，有 m 次询问，每次问 [l, r] 的和。每次都从 l 加到 r，最坏 O(nm)，n、m 都是 10⁵ 时要 10¹⁰ 次，超时。

## 2. 一维前缀和

定义 **s[i] = a[1] + a[2] + … + a[i]**，规定 s[0] = 0。

那么区间和：**a[l] + … + a[r] = s[r] - s[l-1]**。

```
a:    3  1  4  1  5
s: 0  3  4  8  9  14
[2, 4] 的和 = s[4] - s[1] = 9 - 3 = 6 = 1 + 4 + 1 ✓
```

```cpp
long long s[100005];
for (int i = 1; i <= n; i++) s[i] = s[i - 1] + a[i];   // 预处理 O(n)
// 每次询问 O(1)
cout << s[r] - s[l - 1] << "\n";
```

> 下标从 1 开始，s[0] = 0，l = 1 时 s[l-1] 不会越界。

## 3. 二维前缀和

s[i][j] 表示左上角 (1, 1) 到右下角 (i, j) 的矩形里所有数的和。

### 预处理（容斥）

```
s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j]
```

上面一块 + 左边一块，左上角被加了两次，减掉一次，再加上自己。

### 求子矩阵和

左上角 (x1, y1)，右下角 (x2, y2)：

```
sum = s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]
```

画个图就明白：大矩形减去上面一条和左边一条，左上角那块被减了两次，加回来。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j];
```

### 例：领地选择（P2004）

在 N × M 的地图里选一个 C × C 的正方形，使价值和最大。预处理二维前缀和，枚举正方形左上角 O(NM)，每次 O(1) 求和。

## 4. 一维差分

### 问题

有 m 次操作，每次给 [l, r] 的每个数都加上 x，最后输出整个数组。

### 差分数组

定义 **d[i] = a[i] - a[i-1]**。那么 a[i] = d[1] + d[2] + … + d[i]，即 **a 是 d 的前缀和**。

给 [l, r] 加 x，在差分数组上只改两个位置：

```cpp
d[l] += x;       // 从 l 开始都多了 x
d[r + 1] -= x;   // 从 r+1 开始把多加的减回去
```

所有操作做完后，对 d 求一遍前缀和就得到最终的 a。

```
初始 a = 0 0 0 0 0，给 [2, 4] 加 3：
d = 0 3 0 0 -3
前缀和 a = 0 3 3 3 0 ✓
```

**前缀和与差分是一对互逆运算**：前缀和把"单点"变成"区间"，差分把"区间"变成"单点"。

### 例：语文成绩（P2367）

n 个学生，p 次操作给某个区间的学生加分，最后求最低分。差分模板题。

### 例：海底高铁（P3406）

N 个城市连成一条线，第 i 段铁路买纸质票花 Aᵢ，或者买 IC 卡花 Cᵢ 之后每次 Bᵢ。给出旅行路线，求最少花费。

1. 用差分统计**每一段铁路被经过几次**（从城市 p 到 q，就给 [min, max-1] 这些段加 1）。
2. 每段分别选更便宜的：min(次数 × A, C + 次数 × B)。

## 5. 二维差分

给子矩阵 (x1, y1)～(x2, y2) 全部加 x：

```cpp
d[x1][y1] += x;
d[x1][y2 + 1] -= x;
d[x2 + 1][y1] -= x;
d[x2 + 1][y2 + 1] += x;
```

最后做一遍二维前缀和即可。

### 例：地毯（P3397）

n × n 的格子上铺 m 张地毯，问每个格子被几张地毯覆盖。二维差分模板。

## 6. 最大子段和（P1115）

给一个数列（有正有负），求和最大的一段连续子数组。

### 方法一：前缀和

区间和 = s[r] - s[l-1]。对每个 r，让 s[l-1] 尽量小。从左往右扫，记录到目前为止的最小前缀和：

```cpp
long long best = LLONG_MIN, mn = 0;    // mn 是 s[0..r-1] 的最小值
for (int r = 1; r <= n; r++) {
    best = max(best, s[r] - mn);
    mn = min(mn, s[r]);
}
```

### 方法二：动态规划（下下单元会学）

f[i] = 以第 i 个数结尾的最大子段和 = max(a[i], f[i-1] + a[i])。

### 最大加权矩形（P1719）

二维版本：枚举上下边界 (i, j)（O(n²)），把这几行"压缩"成一行（每列的和用二维前缀和 O(1) 求出），再在这一行上求最大子段和（O(n)）。总 O(n³)。

## 7. 易错点清单

1. 下标从 0 开始导致 s[l-1] 越界。
2. 和很大时用了 int。
3. 差分时 d[r+1] 越界（数组要多开一个）。
4. 二维前缀和的加减号写错，拿一个 2×2 的小例子验证。
5. 最大子段和要求至少选一个数时，全是负数的情况答案是最大的那个负数。

## 9. 自测

1. a = [2, 5, 1, 3]，s 数组是什么？[2, 3] 的和是多少？
2. 给 [3, 5] 加 2，差分数组要改哪两个位置？
3. 前缀和与差分是什么关系？

<details><summary>答案</summary>

1. s = [0, 2, 7, 8, 11]，[2, 3] 的和 = s[3] - s[1] = 6。
2. d[3] += 2，d[6] -= 2。
3. 互逆：对差分数组求前缀和得到原数组，对前缀和数组求差分也得到原数组。

</details>
