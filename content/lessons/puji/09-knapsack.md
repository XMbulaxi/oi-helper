# 背包问题

## 01 背包

n 件物品，每件有重量 w 和价值 v，每件**最多拿一次**，背包容量 m，求最大价值。

- 状态：`f[j]` 表示容量为 j 时的最大价值。
- 转移：`f[j] = max(f[j], f[j - w[i]] + v[i])`。
- **容量要倒着枚举**，保证每件物品只用一次。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = m; j >= w[i]; j--)
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```

## 完全背包

每件物品可以拿**无限次**。和 01 背包只差一点：**容量正着枚举**。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = w[i]; j <= m; j++)
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```

## 变形

- 装箱问题（P1049）：价值就等于体积，求最多能装多少。
- 开心的金明（P1060）：价值 = 价格 × 重要度。
- 5 倍经验日（P1802）：不选也有收益（失败经验），转移变成"选：赢的经验；不选：输的经验"。
- 小A点菜（P1164）：求方案数，`f[j] += f[j - w[i]]`，初始 `f[0] = 1`。

## 常见错误

1. 01 背包正着枚举，结果变成了完全背包。
2. 答案很大时没用 `long long`（疯狂的采药 P1616 就需要）。
3. P1802 里最终答案要乘 5。
