# 搜索：DFS 与 BFS

> **学完能做到**：在网格地图上用 DFS 数路径、求连通块；用 BFS 求最少步数；写出八皇后这类带剪枝的回溯。
> **前置知识**：递归与回溯、队列。

---

## 1. 搜索是什么

搜索就是**有系统地尝试所有可能**。按尝试的顺序分两种：

| | DFS 深度优先 | BFS 广度优先 |
| --- | --- | --- |
| 方式 | 一条路走到底，走不通再退回 | 一圈一圈往外扩 |
| 实现 | 递归（栈） | 队列 |
| 擅长 | 枚举所有方案、连通块 | **最少步数**（每步代价相同时） |

## 2. DFS 模板（网格）

```cpp
int n, m;
char g[105][105];
bool vis[105][105];
int dx[4] = {-1, 1, 0, 0}, dy[4] = {0, 0, -1, 1};

bool inside(int x, int y) { return x >= 1 && x <= n && y >= 1 && y <= m; }

void dfs(int x, int y) {
    vis[x][y] = true;
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (!inside(nx, ny) || vis[nx][ny] || g[nx][ny] == '#') continue;
        dfs(nx, ny);
    }
}
```

### 连通块：Lake Counting（P1596）

地图上 `W` 是水，八个方向相连的水算一个水塘，问有几个。

从每个**没访问过的水格子**出发 DFS，把能到达的水都标记掉。出发了几次就有几个水塘。

```cpp
int ans = 0;
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        if (g[i][j] == 'W' && !vis[i][j]) { dfs(i, j); ans++; }
```

（八个方向：dx、dy 改成 8 个元素。）

**注意**：求连通块**不需要回溯**（vis 不恢复），因为每个格子只要访问一次。

### 求路径数：迷宫（P1605）

从起点到终点，每个格子最多经过一次，有多少条路径？

这次要**回溯**：一条路径走完后，退回来要把格子恢复成"没走过"，别的路径还能用。

```cpp
void dfs(int x, int y) {
    if (x == fx && y == fy) { ans++; return; }
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (!inside(nx, ny) || vis[nx][ny] || wall[nx][ny]) continue;
        vis[nx][ny] = true;
        dfs(nx, ny);
        vis[nx][ny] = false;     // 回溯
    }
}
// 调用前：vis[sx][sy] = true; dfs(sx, sy);
```

> 什么时候回溯？**问"所有方案"时要回溯；问"能不能到、哪些能到"时不用。**

### 反向思考：填涂颜色（P1162）

0 和 1 组成的方阵，被 1 围起来的 0 要改成 2。

直接找"被围住的 0"很难。**反过来**：从边界外面开始 DFS/BFS，能走到的 0 都是**没被围住**的；剩下没走到的 0 就是被围住的。

技巧：在地图外面加一圈 0（下标从 0 到 n+1），从 (0, 0) 出发搜一遍。

## 3. BFS 模板

BFS 用队列，按"距离起点的步数"一层一层扩展。**第一次到达某个点时的步数就是最少步数。**

```cpp
int dis[405][405];   // -1 表示还没到过

void bfs(int sx, int sy) {
    memset(dis, -1, sizeof(dis));
    queue<pair<int, int>> q;
    q.push({sx, sy});
    dis[sx][sy] = 0;
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        for (int k = 0; k < 8; k++) {
            int nx = x + dx[k], ny = y + dy[k];
            if (!inside(nx, ny) || dis[nx][ny] != -1) continue;
            dis[nx][ny] = dis[x][y] + 1;
            q.push({nx, ny});
        }
    }
}
```


BFS 一遍，输出 dis 数组，到不了的是 -1。

### 不是网格的 BFS：奇怪的电梯（P1135）

第 i 层只能上 Kᵢ 层或下 Kᵢ 层。从 A 到 B 最少按几次？每一层是一个"点"，上下是两条"边"，同样 BFS。

## 4. DFS 和 BFS 的选择

- 求**最少步数** → BFS。DFS 也能做，但要搜完所有路径才能确定最小值，往往超时。
- 求**所有方案数**、需要**枚举每种情况** → DFS。
- 求**连通块** → 都可以。DFS 好写，但地图很大时递归层数太深可能栈溢出，这时用 BFS。

## 5. 剪枝：让搜索更快

### 八皇后（P1219）

n × n 棋盘放 n 个皇后，互不攻击（同行、同列、同对角线都不行）。

**一行一行放**，每行只放一个，行就不会冲突。对于列和两条对角线，用三个数组标记：

- 列：`col[j]`
- 主对角线（左上到右下）：同一条线上 `i - j` 相同，用 `d1[i - j + n]`（加 n 防止负数）
- 副对角线（右上到左下）：同一条线上 `i + j` 相同，用 `d2[i + j]`

```cpp
int n, ans, pos[15];
bool col[15], d1[30], d2[30];

void dfs(int i) {                       // 放第 i 行
    if (i > n) {
        ans++;
        if (ans <= 3) { 输出 pos[1..n]; }
        return;
    }
    for (int j = 1; j <= n; j++) {
        if (col[j] || d1[i - j + n] || d2[i + j]) continue;   // 剪枝
        pos[i] = j;
        col[j] = d1[i - j + n] = d2[i + j] = true;
        dfs(i + 1);
        col[j] = d1[i - j + n] = d2[i + j] = false;
    }
}
```

每次只尝试"不冲突"的位置，大大减少了搜索量。这就是**剪枝**：提前排除不可能的分支。

常见剪枝：

- **可行性剪枝**：当前状态已经不可能成功，直接返回。
- **最优性剪枝**：当前代价已经超过已知最优解，直接返回。
- **搜索顺序**：先试更可能成功的选择。

## 6. 例题精讲：01迷宫（P1141）

n × n 的 01 格子，从 0 只能走到相邻的 1，从 1 只能走到相邻的 0。m 次询问，每次问从某格出发能到多少个格子。

m 很大（10⁵），每次询问都搜一遍会超时。

**发现**：能互相到达的格子组成一个连通块，块里每个格子的答案都一样（就是块的大小）。所以**先把所有连通块求出来**，给每个格子记下它属于哪个块，询问时 O(1) 回答。

```cpp
int id[1005][1005], sz[1000005], cnt;
// 对每个没编号的格子 BFS，给整块编号 ++cnt，并统计 sz[cnt]
```

> "**预处理 + 快速回答**"是应对大量询问的通用思路。

## 7. 易错点清单

1. 忘记标记已访问，死循环或重复计数。
2. 该回溯的没回溯（求路径数），不该回溯的回溯了（求连通块会超时）。
3. 起点忘了标记。
4. BFS 在**出队时**才标记，导致同一个点入队多次。应该**入队时**就标记。
5. 大地图 DFS 栈溢出。
