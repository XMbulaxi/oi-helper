# 树与二叉树

> **学完能做到**：理解树的基本概念；存储二叉树和一般的树；写出先序、中序、后序遍历；由两种遍历序列还原第三种。
> **前置知识**：递归、DFS。

---

## 1. 什么是树

树由**节点**和**边**组成，满足：

- n 个节点恰好有 n - 1 条边；
- 任意两个节点之间**有且只有一条**路径（连通、没有环）。

```
        1          ← 根
      / | \
     2  3  4
    / \     \
   5   6     7     ← 5、6、3、7 是叶子
```

### 术语

| 术语 | 含义 | 上图中的例子 |
| --- | --- | --- |
| 根 | 最上面的节点 | 1 |
| 父亲 / 儿子 | 相邻两层之间的关系 | 2 是 5 的父亲 |
| 兄弟 | 同一个父亲的儿子 | 5 和 6 |
| 叶子 | 没有儿子的节点 | 5、6、3、7 |
| 祖先 / 子孙 | 到根路径上的点 / 子树里的点 | 1、2 是 5 的祖先 |
| 深度 | 到根的距离（根的深度一般设为 1 或 0） | 5 的深度是 3 |
| 子树 | 一个节点和它所有的子孙 | 2 的子树是 {2, 5, 6} |

## 2. 二叉树

每个节点**最多两个儿子**，分别叫**左儿子**和**右儿子**（有顺序）。

### 存储

```cpp
int lc[N], rc[N];   // 左儿子、右儿子，0 表示没有
```

或用结构体：

```cpp
struct Node { int l, r; } t[N];
```

### 特殊的二叉树

- **满二叉树**：每一层都是满的。深度为 d 的满二叉树有 2ᵈ - 1 个节点。
- **完全二叉树**：除了最后一层，每层都是满的，且最后一层的节点靠左排列。可以用数组存：节点 i 的左儿子是 2i，右儿子是 2i+1，父亲是 i/2。**堆和线段树**都用这种存法。

## 3. 遍历

### 三种深度优先遍历

区别只在于"**根**"在什么时候访问：

- **先序**（根 左 右）
- **中序**（左 根 右）
- **后序**（左 右 根）

```
      A
     / \
    B   C
   / \
  D   E
先序：A B D E C
中序：D B E A C
后序：D E B C A
```

```cpp
void pre(int u) {
    if (!u) return;
    cout << u << " ";      // 根
    pre(lc[u]);            // 左
    pre(rc[u]);            // 右
}
void in(int u) {
    if (!u) return;
    in(lc[u]); cout << u << " "; in(rc[u]);
}
void post(int u) {
    if (!u) return;
    post(lc[u]); post(rc[u]); cout << u << " ";
}
```

### 层序遍历

用 BFS，一层一层从左到右访问。

### 求深度（P4913）

```cpp
int depth(int u) {
    if (!u) return 0;
    return max(depth(lc[u]), depth(rc[u])) + 1;
}
```

## 4. 由遍历序列还原二叉树

### 已知中序和后序，求先序（P1030）

**关键**：后序的**最后一个**是根。在中序里找到根，左边是左子树的中序，右边是右子树的中序。左子树有 k 个节点，那么后序的前 k 个就是左子树的后序。

```
中序：D B E A C
后序：D E B C A
根 = A（后序最后一个）
中序中 A 左边 "DBE" 是左子树，右边 "C" 是右子树
后序前 3 个 "DEB" 是左子树的后序，接着 "C" 是右子树的后序
递归……
```

```cpp
void solve(string in, string post) {
    if (in.empty()) return;
    char root = post.back();
    int k = in.find(root);                    // 左子树大小
    cout << root;                             // 先序：先输出根
    solve(in.substr(0, k), post.substr(0, k));
    solve(in.substr(k + 1), post.substr(k, in.size() - k - 1));
}
```

### 已知先序和中序，求后序

同理：先序的**第一个**是根。

### 只知道先序和后序呢？（P1229 遍历问题）

不能唯一确定。如果一个节点只有一个儿子，这个儿子是左是右，先序和后序都一样。

在先序中，如果 A 后面紧跟 B，而在后序中 B 后面紧跟 A，说明 B 是 A 的唯一儿子，这里有 2 种可能。答案 = 2^(这种情况的个数)。

## 5. 一般的树怎么存

儿子个数不固定时，用 `vector` 存每个节点的儿子（或邻居）：

```cpp
vector<int> g[N];
// 读入 n-1 条边
for (int i = 1; i < n; i++) {
    int u, v; cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u);    // 无根树两边都加
}
```

DFS 时记录父亲，避免走回去：

```cpp
void dfs(int u, int fa) {
    for (int v : g[u]) {
        if (v == fa) continue;
        dep[v] = dep[u] + 1;
        dfs(v, u);
    }
}
```

## 6. 例题精讲：FBI 树（P1087）

一个长度为 2ᴺ 的 01 串，按规则建树：全 0 是 B 串，全 1 是 I 串，混合是 F 串；把串从中间分成两半，分别作为左右子树，直到长度为 1。输出后序遍历。

不需要真的建树，直接递归：

```cpp
char solve(const string &s) {     // 返回 s 的类型，并输出后序
    if (s.size() > 1) {
        int h = s.size() / 2;
        solve(s.substr(0, h));
        solve(s.substr(h));
    }
    bool has0 = s.find('0') != string::npos;
    bool has1 = s.find('1') != string::npos;
    char c = has0 && has1 ? 'F' : has0 ? 'B' : 'I';
    cout << c;
    return c;
}
```

## 7. 易错点清单

1. 递归没判断空节点（0）。
2. 子串的起点和长度算错，拿样例手推。
3. 无根树 DFS 时没判断父亲，来回走死循环。
4. 节点很多（10⁵）且树是一条链时，递归深度很大可能栈溢出（一般 OI 评测环境栈空间够大，但要有这个意识）。
