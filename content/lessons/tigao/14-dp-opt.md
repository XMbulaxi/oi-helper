# DP 优化：单调队列与前缀和

> **学完能做到**：识别"从一个滑动区间里取最值"的转移，用单调队列把 O(nk) 优化到 O(n)；用前缀和优化求和型转移；把二分答案和 DP 结合。
> **前置知识**：单调队列、前缀和、动态规划。

---

## 1. 为什么要优化

很多 DP 的转移形如：

**f[i] = max(f[j]) + a[i]，其中 j ∈ [i - R, i - L]**

直接枚举 j 是 O(n × (R - L))，n = 2×10⁵、区间长 10⁵ 时就超时了。

注意到：**j 的范围是一个随 i 向右滑动的窗口**——这正是滑动窗口最值，用单调队列 O(1) 均摊得到。

## 2. 单调队列优化

### 琪露诺（P1725）

格子 0～N，每个格子有冰冻指数，从 i 只能跳到 [i + L, i + R]，跳出 N 就结束，求冰冻指数和的最大值。

1. 状态：f[i] = 跳到 i 时的最大和。
2. 转移：f[i] = a[i] + max(f[j])，j ∈ [i - R, i - L]。
3. 当 i 增加 1 时，窗口 [i-R, i-L] 也向右移动 1：新进来 j = i - L，过期的是 < i - R 的。

```cpp
deque<int> dq;
fill(f, f + n + 1, LLONG_MIN);
f[0] = 0;
for (int i = L; i <= n; i++) {
    int j = i - L;                                    // 新进入窗口的 j
    if (f[j] != LLONG_MIN) {
        while (!dq.empty() && f[dq.back()] <= f[j]) dq.pop_back();
        dq.push_back(j);
    }
    while (!dq.empty() && dq.front() < i - R) dq.pop_front();
    if (!dq.empty()) f[i] = f[dq.front()] + a[i];
}
// 答案：max(f[i])，i ∈ [n - R + 1, n]（再跳一步就出界）
```

> **套路**：如果转移是"在一个两端都单调移动的窗口里取最值"，就用单调队列。

### 选择数字（P2034）/ Mowing the Lawn（P2627）

n 个数，选一些数使和最大，但**不能连续选超过 k 个**。

**反过来想**：总和 - 不选的数之和。不能连续选超过 k 个 ⟺ 每 k + 1 个连续的数中**至少有一个不选**。

g[i] = 第 i 个数**不选**时，前 i 个数中不选的数之和的最小值。

g[i] = a[i] + min(g[j])，j ∈ [i - k - 1, i - 1]

又是滑动窗口最小值。答案 = 总和 - min(g[i])，i ∈ [n - k, n]（最后 k 个数里也要有一个不选，或者在末尾加一个 0 号虚拟元素）。

## 3. 前缀和优化

如果转移是**求和**，比如：

f[i][j] = Σ f[i-1][k]，k ∈ [j - a, j]

可以对 f[i-1] 预处理前缀和 s，f[i][j] = s[j] - s[j-a-1]，O(1)。

例：摆花（P1077）中 f[i][j] = Σ f[i-1][j-k]（0 ≤ k ≤ aᵢ），用前缀和优化后从 O(nm²) 变成 O(nm)。

## 4. 二分答案 + DP + 单调队列：跳房子（NOIP2017 普及组，P3957）

格子在数轴上，有分数。机器人每次跳 d 步，花 g 个金币改造后，可以跳 [max(1, d - g), d + g] 之间的任意距离。求最少花多少金币能得到至少 k 分。

1. **二分 g**：g 越大，能跳的范围越大，得分越高——单调。
2. **check(g)**：f[i] = 跳到第 i 个格子的最大得分 = s[i] + max(f[j])，其中 xᵢ - xⱼ ∈ [L, R]。
3. 这个 j 的范围由**坐标**决定，但因为格子坐标递增，窗口仍然单调滑动，用单调队列：用一个指针把"距离 ≥ L"的格子逐个加入队尾，队头弹出"距离 > R"的格子。

```cpp
bool check(int g) {
    long long L = max(1, d - g), R = d + g;
    // f[0] = 0（起点坐标 0），其他 -INF
    deque<int> dq;
    int p = 0;                                     // 下一个待加入窗口的格子
    for (int i = 1; i <= n; i++) {
        while (p < i && x[i] - x[p] >= L) {        // 距离够远了，可以作为跳板
            if (f[p] != NEG) {
                while (!dq.empty() && f[dq.back()] <= f[p]) dq.pop_back();
                dq.push_back(p);
            }
            p++;
        }
        while (!dq.empty() && x[i] - x[dq.front()] > R) dq.pop_front();
        f[i] = dq.empty() ? NEG : f[dq.front()] + s[i];
        if (f[i] >= k) return true;
    }
    return false;
}
```

这道题把二分、DP、单调队列组合在一起，是提高组 DP 优化的标志性题目。

## 5. 其他 DP 优化（了解）

| 优化 | 适用的转移形式 |
| --- | --- |
| 单调队列 | f[i] = max(f[j]) + …，j 在滑动窗口中 |
| 前缀和 | f[i] = Σ f[j]，j 在一个区间中 |
| 斜率优化 | f[i] = min(f[j] + (sᵢ - sⱼ)²) 这类含有 i、j 乘积项的 |
| 四边形不等式 | 区间 DP 中最优分割点单调 |
| 数据结构优化 | 用线段树/树状数组快速查询前面状态的最值（j 的范围不是窗口时） |

普及到提高的过渡阶段，前两种必须熟练。

## 6. 易错点清单

1. 窗口边界（i - R 和 i - L）算错，差一。
2. 不可达的状态（-INF）被放进队列，导致错误转移。
3. 先加入新元素还是先弹出过期元素，顺序和窗口定义要一致。
4. 二分答案的上下界设错（跳房子中 g 的上界可以是最大坐标）。

## 8. 自测

1. 什么样的 DP 转移可以用单调队列优化？
2. "不能连续选超过 k 个"等价于什么条件？
3. 跳房子为什么可以二分？

<details><summary>答案</summary>

1. f[i] 由一个**两端都单调移动**的区间内 f[j] 的最大（小）值转移而来。
2. 任意连续 k + 1 个数中至少有一个不选。
3. 花的金币 g 越多，能跳的距离范围越大，能得到的最高分数不会减少，满足单调性。
