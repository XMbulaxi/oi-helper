# 数论进阶：扩展欧几里得、逆元、欧拉函数

> **学完能做到**：用裴蜀定理判断方程有无整数解；用扩展欧几里得求 ax + by = gcd(a, b) 的解和线性同余方程；求模意义下的乘法逆元（三种方法）；计算欧拉函数。
> **前置知识**：GCD、素数筛、快速幂（普及组）。

## 1. 同余

如果 a 和 b 除以 m 的余数相同，记作 **a ≡ b (mod m)**，即 m 整除 a - b。

同余可以两边同时加、减、乘，但**不能直接两边同时除**——这就是为什么需要逆元。

## 2. 裴蜀定理

**ax + by = c 有整数解 ⟺ gcd(a, b) 整除 c。**

特别地，ax + by = gcd(a, b) 一定有整数解。

### 例：裴蜀定理模板（P4549）

给 n 个整数 A₁…Aₙ，求 S = Σ AᵢXᵢ 的最小正值。由裴蜀定理推广，答案是所有 |Aᵢ| 的 gcd。

## 3. 扩展欧几里得（exgcd）

求 ax + by = gcd(a, b) 的一组解。

### 推导

辗转相除时 gcd(a, b) = gcd(b, a mod b)。假设已经求出 bx' + (a mod b)y' = g 的解，因为 a mod b = a - ⌊a/b⌋ × b：

bx' + (a - ⌊a/b⌋b)y' = g
ay' + b(x' - ⌊a/b⌋y') = g

所以 **x = y'，y = x' - ⌊a/b⌋ × y'**。递归到 b = 0 时，a × 1 + 0 × 0 = a，x = 1，y = 0。

```cpp
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long g = exgcd(b, a % b, y, x);   // 注意 x、y 交换传入
    y -= a / b * x;
    return g;
}
```

（交换传入 x、y 后，递归返回时 y 存的是 x'，x 存的是 y'，所以只需 `y -= a / b * x`。）

### 通解

求出一组解 (x₀, y₀) 后，所有解是：

x = x₀ + k × (b / g)，y = y₀ - k × (a / g)，k 为任意整数。

求**最小正整数** x：令 t = b / g，**x = (x₀ mod t + t) mod t**。

## 4. 线性同余方程

**ax ≡ b (mod m)** 等价于 ax + my = b。

1. 求 g = gcd(a, m)。如果 g 不整除 b，无解。
2. 用 exgcd 求 ax₀ + my₀ = g 的解。
3. x = x₀ × (b / g)，再取最小正整数解（模 m / g）。

### 例：同余方程（NOIP2012，P1082）

求 ax ≡ 1 (mod b) 的最小正整数解（保证有解）。直接 exgcd，答案 (x mod b + b) mod b。这其实就是求 a 在模 b 下的逆元。

### 例：青蛙的约会（P1516）

两只青蛙在长为 L 的环上，起点 x 和 y，每次分别跳 m 和 n。问跳几次后相遇。

x + km ≡ y + kn (mod L) → k(m - n) ≡ y - x (mod L)。这是线性同余方程。注意 m - n 可能为负，要先处理成正数（两边同时取反）。

## 5. 乘法逆元

在模 p 下，如果 a × x ≡ 1 (mod p)，称 x 是 a 的**逆元**，记作 a⁻¹。有了逆元，"除以 a"就可以变成"乘以 a⁻¹"：

**(b / a) mod p = b × a⁻¹ mod p**

逆元存在的条件：gcd(a, p) = 1。

### 方法一：扩展欧几里得

解 ax ≡ 1 (mod p)。适用于任何 gcd(a, p) = 1 的情况。

### 方法二：费马小定理（p 是质数）

p 是质数时，a^(p-1) ≡ 1 (mod p)，所以 **a⁻¹ = a^(p-2) mod p**。用快速幂计算。

```cpp
long long inv(long long a, long long p) { return power(a, p - 2, p); }
```

### 方法三：线性递推（求 1～n 所有数的逆元）

**inv[i] = -(p / i) × inv[p mod i] mod p**

```cpp
inv[1] = 1;
for (int i = 2; i <= n; i++) inv[i] = (p - p / i) * inv[p % i] % p;
```

推导：设 p = ki + r（k = ⌊p/i⌋，r = p mod i），则 ki + r ≡ 0，两边乘 i⁻¹r⁻¹：kr⁻¹ + i⁻¹ ≡ 0，所以 i⁻¹ ≡ -k × r⁻¹。

O(n) 求出所有逆元。

### 例：乘法逆元模板（P3811）

求 1～n 在模 p 下的逆元，n 到 3×10⁶。用线性递推（快速幂会慢一些），输出用 printf 或快写。

### 例：有理数取余（P2613）

求 a / b mod 19260817，a、b 是非常大的数（10¹⁰⁰⁰⁰ 位）。

1. 读入时边读边取模，得到 a mod p 和 b mod p。
2. 如果 b mod p = 0，无解。
3. 答案 = a × b⁻¹ mod p。

## 6. 欧拉函数

**φ(n) = 1～n 中与 n 互质的数的个数。**

- φ(1) = 1
- p 是质数：φ(p) = p - 1
- **公式**：n = p₁^k₁ × … × pₘ^kₘ，**φ(n) = n × (1 - 1/p₁) × … × (1 - 1/pₘ)**

```cpp
long long phi(long long n) {
    long long res = n;
    for (long long p = 2; p * p <= n; p++) {
        if (n % p) continue;
        res = res / p * (p - 1);
        while (n % p == 0) n /= p;
    }
    if (n > 1) res = res / n * (n - 1);
    return res;
}
```

### 线性筛求 1～n 的欧拉函数

在线性筛中顺便求：

- i 是质数：φ(i) = i - 1
- i % p == 0：φ(i × p) = φ(i) × p
- 否则：φ(i × p) = φ(i) × (p - 1)

### 欧拉定理

gcd(a, n) = 1 时，**a^φ(n) ≡ 1 (mod n)**。费马小定理是它在 n 为质数时的特例。

### 例：仪仗队（P2158）

N × N 的方阵，从左下角看过去能看到几个人（被挡住的看不到）。

点 (x, y) 能被看到 ⟺ gcd(x, y) = 1。答案 = 2 × Σφ(i)（i 从 1 到 N-1）+ 1。注意 N = 1 时答案是 0。

## 7. 博弈小专题：欧几里德的游戏（P1290）

两个数 (a, b)，每次从大数里减去小数的正整数倍（结果不能为负），先把一个数变成 0 的人赢。

设 a ≥ b：

- 如果 a / b ≥ 2，当前玩家**必胜**（他可以选择减到 a mod b + b 或 a mod b，控制对手面对的局面）。
- 如果 a == b 的倍数，当前玩家直接赢。
- 如果 a / b == 1，只能变成 (b, a - b)，局面交给对手。

沿辗转相除的过程模拟即可。

## 8. 易错点清单

1. exgcd 递归时 x、y 交换后更新 y 的公式写错。
2. 最小正整数解忘了 `(x % t + t) % t`。
3. 用费马小定理求逆元时模数不是质数。
4. 线性求逆元公式中 `p - p / i` 写成 `-p / i` 产生负数。
5. 乘法溢出：两个 10¹² 级的数相乘超过 long long，用 `__int128` 或龟速乘。
6. 青蛙的约会中系数为负数时没有处理。

## 10. 自测

1. 3x + 6y = 4 有整数解吗？
2. 模 7 下 3 的逆元是多少？
3. φ(12) 是多少？
