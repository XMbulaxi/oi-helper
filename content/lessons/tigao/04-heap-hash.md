## 1. 二叉堆

### 定义

**堆**是一棵完全二叉树，满足：每个节点都**不大于**它的儿子（小根堆）。所以根是最小值。

用数组存：节点 i 的儿子是 2i 和 2i+1，父亲是 i/2。

### 操作

**插入**：放到数组末尾，然后**上浮**——如果比父亲小就交换，直到不比父亲小。

**删除最小值**：把最后一个元素放到根，然后**下沉**——和较小的儿子比，比它大就交换，直到不比儿子大。

```cpp
int h[N], sz = 0;

void push(int x) {
    h[++sz] = x;
    int i = sz;
    while (i > 1 && h[i] < h[i / 2]) { swap(h[i], h[i / 2]); i /= 2; }
}

void pop() {
    h[1] = h[sz--];
    int i = 1;
    while (2 * i <= sz) {
        int c = 2 * i;
        if (c + 1 <= sz && h[c + 1] < h[c]) c++;   // 选较小的儿子
        if (h[i] <= h[c]) break;
        swap(h[i], h[c]);
        i = c;
    }
}

int top() { return h[1]; }
```

插入和删除都是 O(log n)，取最小值 O(1)。

竞赛中直接用 `priority_queue` 即可，但理解原理很重要（比如需要修改堆中元素时）。

### 自定义比较

```cpp
struct Node { int dist, id; };
struct Cmp { bool operator()(const Node &a, const Node &b) const { return a.dist > b.dist; } };
priority_queue<Node, vector<Node>, Cmp> pq;   // dist 小的在顶

// 或者在结构体里重载 <（注意方向是反的）
struct Node2 { int dist, id; bool operator<(const Node2 &o) const { return dist > o.dist; } };
priority_queue<Node2> pq2;                    // dist 小的在顶
```

## 2. 对顶堆：动态中位数（P1168）

依次读入数，每读入奇数个时输出当前中位数。

**两个堆**：

- 大根堆 `lo`：存较小的一半，堆顶是这一半的最大值。
- 小根堆 `hi`：存较大的一半，堆顶是这一半的最小值。

保持 `lo.size() == hi.size()` 或 `lo.size() == hi.size() + 1`，中位数就是 `lo.top()`。

```cpp
priority_queue<int> lo;                              // 大根堆
priority_queue<int, vector<int>, greater<int>> hi;   // 小根堆

void add(int x) {
    if (lo.empty() || x <= lo.top()) lo.push(x);
    else hi.push(x);
    // 平衡大小
    if (lo.size() > hi.size() + 1) { hi.push(lo.top()); lo.pop(); }
    if (hi.size() > lo.size()) { lo.push(hi.top()); hi.pop(); }
}
```

### 变形：黑匣子（P1801）

支持插入，以及"第 i 次 GET 时输出第 i 小的数"。同样是对顶堆：大根堆保持恰好 i - 1 个最小的数，第 i 小的就是小根堆的堆顶。

## 3. 多路归并：序列合并（P1631）

两个长度为 n 的有序序列 A、B，在 A[i] + B[j] 的 n² 个和中求最小的 n 个。

把所有和看成 n 个有序序列：第 i 个序列是 A[i] + B[1], A[i] + B[2], …。一开始把每个序列的第一个元素放进堆，每次取出最小的 A[i] + B[j]，再把 A[i] + B[j+1] 放进去。O(n log n)。

## 4. 例题：蚯蚓（NOIP2016，P2827）

每秒把最长的蚯蚓切成两段，其他蚯蚓都长长 q。直接用堆是 O(m log m)，m 到 7×10⁶ 会超时。

**两个关键观察**：

1. "其他都长长 q"：改成"所有都长长 q、被切的两段减 q"，用一个全局偏移量表示。
2. **先切的蚯蚓切出来的段，一定比后切的对应段更长**。所以用**三个普通队列**（原始的排好序、切出的前半段、切出的后半段），它们各自天然有序，每次取三个队头中最大的。O(m)。

> 堆能做但太慢时，看看数据有没有"天然有序"的性质，用队列代替。

## 5. 哈希

### 思想

把一个复杂的东西（字符串、数组、状态）映射成一个**整数**，比较整数就代替了比较原物。

### 字符串哈希

把字符串看成一个 P 进制数（P 一般取 131 或 13331），再对一个大数取模：

hash("abc") = (a × P² + b × P + c) mod M

**前缀哈希**：h[i] = h[i-1] × P + s[i]。

**子串哈希**：s[l..r] 的哈希 = h[r] - h[l-1] × Pʳ⁻ˡ⁺¹。

```cpp
typedef unsigned long long ull;
const ull P = 131;
ull h[N], pw[N];   // unsigned long long 自然溢出，相当于对 2^64 取模

void init(const string &s) {     // s 下标从 1 开始
    int n = s.size() - 1;
    pw[0] = 1;
    for (int i = 1; i <= n; i++) {
        h[i] = h[i - 1] * P + s[i];
        pw[i] = pw[i - 1] * P;
    }
}
ull get(int l, int r) { return h[r] - h[l - 1] * pw[r - l + 1]; }
```

预处理 O(n) 后，**O(1) 判断两个子串是否相同**。

### 哈希冲突

两个不同的字符串哈希值相同叫冲突。降低冲突的方法：

- 模数取大质数（如 10⁹+7、998244353）。
- **双哈希**：用两组 (P, M) 分别算，都相同才认为相等。
- 自然溢出（对 2⁶⁴ 取模）在某些特殊构造的数据下会被卡，重要比赛中建议用双模数。

### 例：字符串哈希（P3370）

N 个字符串，问有几个不同的。算出每个的哈希值，排序去重。

## 6. 哈希表

`unordered_map` 就是哈希表。手写哈希表：开一个大小为质数的数组，用链表或开放寻址处理冲突。一般用 STL 即可。

## 7. 易错点清单

1. `priority_queue` 默认大根堆；自定义比较时方向容易反。
2. 对顶堆插入后忘记平衡。
3. 子串哈希公式中 pw 的指数写错（是长度 r - l + 1）。
4. 单模数哈希被卡，改用双哈希。
5. 字符映射成 0 会导致 "a" 和 "aa" 哈希可能相同，用 s[i] 的 ASCII 码（不为 0）。
