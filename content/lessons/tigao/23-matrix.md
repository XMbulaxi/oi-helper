# 矩阵快速幂

> **学完能做到**：写矩阵乘法；用矩阵快速幂在 O(k³ log n) 时间内求线性递推的第 n 项；自己构造转移矩阵。
> **前置知识**：快速幂、递推。

---

## 1. 问题

求斐波那契数列第 n 项 mod 10⁹+7，n ≤ 10¹⁸。

递推 O(n) 太慢。能不能像快速幂一样 O(log n)？

## 2. 矩阵乘法

A 是 a × b 的矩阵，B 是 b × c 的矩阵，C = A × B 是 a × c 的矩阵：

**C[i][j] = Σ A[i][k] × B[k][j]**（k 从 1 到 b）

```
[1 2]   [5 6]   [1×5+2×7  1×6+2×8]   [19 22]
[3 4] × [7 8] = [3×5+4×7  3×6+4×8] = [43 50]
```

性质：

- **满足结合律**：(AB)C = A(BC)。这是能用快速幂的关键。
- 不满足交换律：AB ≠ BA。
- 单位矩阵 I（对角线为 1，其余为 0）：AI = IA = A。

```cpp
const long long MOD = 1e9 + 7;
struct Mat {
    int n;
    long long a[105][105];
    Mat(int n = 0) : n(n) { memset(a, 0, sizeof(a)); }
};

Mat mul(const Mat &A, const Mat &B) {
    Mat C(A.n);
    for (int i = 0; i < A.n; i++)
        for (int k = 0; k < A.n; k++) {
            if (!A.a[i][k]) continue;
            for (int j = 0; j < A.n; j++)
                C.a[i][j] = (C.a[i][j] + A.a[i][k] * B.a[k][j]) % MOD;
        }
    return C;
}

Mat power(Mat A, long long b) {
    Mat R(A.n);
    for (int i = 0; i < A.n; i++) R.a[i][i] = 1;   // 单位矩阵
    while (b) {
        if (b & 1) R = mul(R, A);
        A = mul(A, A);
        b >>= 1;
    }
    return R;
}
```

k × k 的矩阵乘法 O(k³)，快速幂共 O(k³ log n)。

（循环顺序 i-k-j 比 i-j-k 对缓存更友好，速度更快。）

## 3. 用矩阵表示递推

### 斐波那契

f(n) = f(n-1) + f(n-2)。把相邻两项写成向量：

```
[f(n)  ]   [1 1]   [f(n-1)]
[f(n-1)] = [1 0] × [f(n-2)]
```

验证：第一行 f(n) = 1 × f(n-1) + 1 × f(n-2) ✓；第二行 f(n-1) = 1 × f(n-1) + 0 ✓。

所以：

```
[f(n)  ]   [1 1]^(n-2)   [f(2)]
[f(n-1)] = [1 0]       × [f(1)]
```

```cpp
// P1962 斐波那契数列
if (n <= 2) { cout << 1; return 0; }
Mat A(2);
A.a[0][0] = A.a[0][1] = A.a[1][0] = 1;
Mat R = power(A, n - 2);
cout << (R.a[0][0] + R.a[0][1]) % MOD;   // f(2) = f(1) = 1
```

## 4. 构造转移矩阵的方法

1. 确定**状态向量**：递推需要哪几项，就把它们放进向量。
2. 写出新向量的每一项如何由旧向量线性组合得到，每一项对应矩阵的一行。

### 例：矩阵加速（P1939）

a(1) = a(2) = a(3) = 1，a(x) = a(x-1) + a(x-3)。

状态向量 [a(x), a(x-1), a(x-2)]：

```
[a(x)  ]   [1 0 1]   [a(x-1)]
[a(x-1)] = [1 0 0] × [a(x-2)]
[a(x-2)]   [0 1 0]   [a(x-3)]
```

- 第一行：a(x) = 1·a(x-1) + 0·a(x-2) + 1·a(x-3) ✓
- 第二行：a(x-1) = a(x-1) ✓
- 第三行：a(x-2) = a(x-2) ✓

### 例：广义斐波那契数列（P1349）

a(n) = p × a(n-1) + q × a(n-2)，给出 a(1)、a(2)，求 a(n) mod m。

```
[a(n)  ]   [p q]   [a(n-1)]
[a(n-1)] = [1 0] × [a(n-2)]
```

### 带常数项

f(n) = f(n-1) + f(n-2) + 1：把常数 1 也放进状态向量：

```
[f(n)  ]   [1 1 1]   [f(n-1)]
[f(n-1)] = [1 0 0] × [f(n-2)]
[1     ]   [0 0 1]   [1     ]
```

### 求前缀和

S(n) = f(1) + … + f(n)：把 S 也放进状态向量，S(n) = S(n-1) + f(n)，再把 f(n) 用旧状态展开。

## 5. 图上的应用（了解）

邻接矩阵 A 的 k 次方中，**Aᵏ[i][j] = 从 i 到 j 恰好走 k 步的路径数**。可以用矩阵快速幂求长度为 k 的路径条数。

## 6. 易错点清单

1. 矩阵乘法中忘了取模，或者乘积溢出（两个 10⁹ 相乘再相加多次，每次乘完就取模）。
2. 单位矩阵没初始化。
3. 幂次算错（是 n - 1 还是 n - 2），用小的 n 验证。
4. 矩阵结构体里的数组很大，放在函数里频繁复制会慢；k 小时没问题。
5. 模数不一定是 10⁹+7，看清题目（P1349 的模数是输入给定的）。

## 8. 自测

1. 为什么矩阵快速幂要求矩阵乘法满足结合律？
2. f(n) = 2f(n-1) + 3f(n-2) 的转移矩阵是什么？
3. k × k 矩阵快速幂求第 n 项的复杂度是多少？

1. 快速幂要把 Aⁿ 拆成 A^(2^i) 的乘积，需要能随意改变乘法的结合顺序。
