# 单调栈与单调队列

> **学完能做到**：O(n) 求每个元素左边/右边第一个比它大（小）的元素；O(n) 求滑动窗口最值；识别并使用"单调性"优化。
> **前置知识**：栈、队列。

---

## 1. 单调栈

### 问题

对每个 i，求它**右边第一个比它大**的元素的位置（P5788）。

暴力：对每个 i 往右扫，O(n²)。

### 思路

从左到右处理，用一个栈存"**还没找到答案的元素**"。这个栈从底到顶是**单调递减**的（因为如果栈里有一个较小的元素在较大的元素上面，新来的元素只要比它大，它就找到答案出栈了）。

新来一个元素 a[i]：

- 当栈顶元素比 a[i] 小时，a[i] 就是栈顶元素"右边第一个比它大的"，记录答案并弹出。
- 重复直到栈顶 ≥ a[i] 或栈空。
- 把 i 压入栈。

```cpp
int a[N], ans[N], stk[N], top = 0;
for (int i = 1; i <= n; i++) {
    while (top > 0 && a[stk[top]] < a[i]) {
        ans[stk[top]] = i;
        top--;
    }
    stk[++top] = i;
}
// 最后还在栈里的元素，右边没有比它大的，ans = 0
```

手推 a = [3, 1, 4, 1, 5]：

| i | a[i] | 弹出 | 栈（存下标） |
| --- | --- | --- | --- |
| 1 | 3 | — | [1] |
| 2 | 1 | — | [1, 2] |
| 3 | 4 | 2(1<4)→ans[2]=3, 1(3<4)→ans[1]=3 | [3] |
| 4 | 1 | — | [3, 4] |
| 5 | 5 | 4→ans[4]=5, 3→ans[3]=5 | [5] |

ans = [3, 3, 5, 5, 0]。

**复杂度**：每个元素入栈一次、出栈一次，总共 O(n)。

### 变形

| 求什么 | 栈的单调性 | 弹栈条件 |
| --- | --- | --- |
| 右边第一个**更大** | 递减 | 栈顶 < 当前 |
| 右边第一个**更小** | 递增 | 栈顶 > 当前 |
| 左边第一个更大/更小 | 同上 | 在**压栈前**，栈顶就是答案 |

### 例：Look Up（P2947）

每头牛找右边第一头比它高的牛。单调栈模板。

### 例：发射站（P1901）

每个发射站向两边发射能量，被两边**第一个比它高**的站接收。左右各做一次单调栈。

### 例：良好的感觉（P2422）

求一个区间，使"区间和 × 区间最小值"最大。

**枚举每个元素作为最小值**：它能向左右扩展到第一个比它小的元素为止。用单调栈求出每个元素左边、右边第一个比它小的位置 L[i]、R[i]，区间就是 (L[i], R[i])，用前缀和求区间和。O(n)。

> "**以每个元素为最值，求它能管辖的最大范围**"是单调栈最经典的用法（还有"最大矩形面积"）。

## 2. 单调队列

### 问题：滑动窗口（P1886）

长度为 n 的数组，一个长度为 k 的窗口从左滑到右，求每个位置窗口里的最小值和最大值。

ST 表可以 O(n log n)；单调队列 O(n)。

### 思路（以最小值为例）

用一个**双端队列**存下标，保持队列中对应的值**单调递增**：

1. 新元素 a[i] 从**队尾**进入前，把队尾所有 ≥ a[i] 的元素弹掉。（它们比 a[i] 大，又比 a[i] 早离开窗口，以后永远不可能成为最小值。）
2. 如果**队头**的下标已经不在窗口里了（≤ i - k），从队头弹出。
3. 现在队头就是窗口最小值。

```cpp
deque<int> dq;   // 存下标
for (int i = 1; i <= n; i++) {
    while (!dq.empty() && a[dq.back()] >= a[i]) dq.pop_back();
    dq.push_back(i);
    if (dq.front() <= i - k) dq.pop_front();
    if (i >= k) cout << a[dq.front()] << " ";
}
```

求最大值：把 `>=` 改成 `<=`。

**一句话理解**："如果一个人比你小，还比你年轻，那你永远比不过他了"——被弹掉的元素就是这样的"没前途"的元素。

### 用数组模拟（更快）

```cpp
int q[N], head = 1, tail = 0;
// dq.back() → q[tail]，pop_back → tail--，push_back → q[++tail] = i
// dq.front() → q[head]，pop_front → head++，empty → head > tail
```

## 3. 例题：切蛋糕（P1714）

n 块蛋糕有幸运值（可能为负），最多连续吃 m 块，求最大幸运值之和。

区间和 = s[r] - s[l-1]，其中 r - m ≤ l - 1 ≤ r - 1。对每个 r，求窗口 [r-m, r-1] 中 s 的**最小值**。这就是滑动窗口！

```cpp
long long best = LLONG_MIN;
deque<int> dq; dq.push_back(0);        // s[0] = 0
for (int r = 1; r <= n; r++) {
    while (!dq.empty() && dq.front() < r - m) dq.pop_front();
    best = max(best, s[r] - s[dq.front()]);
    while (!dq.empty() && s[dq.back()] >= s[r]) dq.pop_back();
    dq.push_back(r);
}
```

> **前缀和 + 单调队列**，是 DP 优化的预演（见"DP 优化"一课）。

## 4. 易错点清单

1. 栈/队列里存**下标**还是**值**：一般存下标，既能取值又能判断是否过期。
2. 单调性方向搞反（求最大值和最小值的弹出条件相反）。
3. 有相等元素时，`<` 和 `<=` 的选择会影响"第一个更大"还是"第一个不小于"。看清题意。
4. 滑动窗口中先弹过期元素还是先加新元素：看你的窗口定义，两种顺序都能写对，但要一致。

## 6. 自测

1. 单调栈为什么是 O(n)？
2. 滑动窗口求最大值，队列里的值是递增还是递减？
3. "求每个元素左边第一个比它小的"，答案在什么时候得到？

<details><summary>答案</summary>

1. 每个元素最多进栈一次、出栈一次。
2. 递减（队头最大）。
3. 维护单调递增栈，弹完比它大（或相等）的元素之后、压栈之前，此时的栈顶就是答案。
