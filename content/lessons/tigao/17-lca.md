# LCA 与树上差分

> **学完能做到**：用倍增求最近公共祖先；求树上两点距离；用树上差分统计路径覆盖次数；结合最小生成树做货车运输。
> **前置知识**：树的 DFS、倍增与 ST 表、前缀和与差分。

---

## 1. 什么是 LCA

两个点 u 和 v 的**最近公共祖先**（LCA）是它们所有公共祖先中**深度最大**的那个。

```
        1
       / \
      2   3
     / \   \
    4   5   6
   /
  7
LCA(7, 5) = 2
LCA(7, 6) = 1
LCA(4, 7) = 4（一个点是另一个的祖先时，LCA 就是它自己）
```

**用途**：树上两点的路径一定经过它们的 LCA，路径 = u → LCA → v。

- 距离：dist(u, v) = dep[u] + dep[v] - 2 × dep[LCA]（带边权时用到根的距离代替深度）。

## 2. 倍增求 LCA

### 预处理

fa[u][k] = u 往上跳 **2ᵏ** 步到达的祖先。

- fa[u][0] = u 的父亲。
- **fa[u][k] = fa[ fa[u][k-1] ][k-1]**（跳 2ᵏ 步 = 跳两次 2ᵏ⁻¹ 步）。

```cpp
const int LOG = 20;
int fa[N][LOG], dep[N];
vector<int> g[N];

void dfs(int u, int p) {
    fa[u][0] = p;
    dep[u] = dep[p] + 1;
    for (int k = 1; k < LOG; k++) fa[u][k] = fa[fa[u][k - 1]][k - 1];
    for (int v : g[u]) if (v != p) dfs(v, u);
}
```

（根的父亲设为 0，fa[0][k] = 0，dep[0] = 0。）

### 查询

1. **先跳到同一深度**：让较深的点往上跳 dep 差值步（按二进制拆分）。
2. 如果此时两点相同，就是 LCA。
3. **一起往上跳**：从大到小试 k，如果 fa[u][k] ≠ fa[v][k]，说明跳完还没到公共祖先，就跳。最后 u 和 v 的父亲就是 LCA。

```cpp
int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    for (int k = LOG - 1; k >= 0; k--)
        if (dep[fa[u][k]] >= dep[v]) u = fa[u][k];
    if (u == v) return u;
    for (int k = LOG - 1; k >= 0; k--)
        if (fa[u][k] != fa[v][k]) { u = fa[u][k]; v = fa[v][k]; }
    return fa[u][0];
}
```

预处理 O(n log n)，每次查询 O(log n)。

**为什么第二步跳到"父亲不同"为止**：如果直接判断"跳到相同"，可能跳过头（跳到了 LCA 的祖先，它们也相同）。跳到"恰好不同"的最高位置，再往上一步就是 LCA。

### 其他 LCA 算法（了解）

- **欧拉序 + ST 表**：O(n log n) 预处理，O(1) 查询。
- **Tarjan 离线**：O(n + q)，需要所有询问提前给出。
- **树链剖分**：O(log n) 查询，常数小，还能支持路径修改（提高组后期内容）。

## 3. 树上差分

### 问题

树上有 m 条路径，每条路径上的每个**点**（或每条**边**）计数加 1，最后问每个点被经过了几次。

### 点差分

路径 u → v 上所有点加 1：

```
cnt[u] += 1
cnt[v] += 1
cnt[lca] -= 1
cnt[fa[lca]] -= 1
```

最后做一次 DFS，**每个点的值 = 它子树内所有 cnt 之和**。

**理解**：从 u 往上累加到根，路径上每个点都 +1；v 同理。LCA 被加了两次，减一次；LCA 往上的部分不该加，再在 fa[lca] 减一次。

### 边差分

把每条边的值存在**它下面的那个点**上。路径 u → v 上所有边加 1：

```
cnt[u] += 1
cnt[v] += 1
cnt[lca] -= 2
```

### 例：Max Flow P（P3128）

n 个点的树，k 条路径，每条路径经过的点都 +1，求最大值。点差分模板。

### 例：松鼠的新家（P3258）

按给定顺序依次访问 a₁, a₂, …, aₙ，每到一个房间（除了最后一个房间）放一个糖果……其实就是相邻两点之间的路径都 +1。注意：相邻路径的**交界点**被加了两次，要各减 1（除了起点），最后终点也要减 1。

## 4. 带权路径：让我们异或吧（P2420）

树上边有权值，多次询问 u 到 v 路径上所有边权的**异或和**。

**异或的性质**：x ⊕ x = 0。设 d[u] = 根到 u 的路径异或和，那么 u 到 v 的路径异或和 = **d[u] ⊕ d[v]**（根到 LCA 的部分被异或两次抵消了）。

这题**连 LCA 都不用求**。

## 5. 综合：货车运输（NOIP2013，P1967）

n 个城市、m 条双向道路，每条路有限重。q 次询问，从 x 到 y 最多能运多重的货物（路径上限重的最小值，要让它最大）。

1. **最大生成树**：要让路径上的最小边尽量大，只需要走最大生成树上的边（类似 Kruskal 的证明）。
2. 在最大生成树（可能是森林）上，x 到 y 的路径唯一，答案是路径上的最小边权。
3. **倍增求路径最小值**：在求 LCA 的倍增数组旁边，再维护 mn[u][k] = u 往上跳 2ᵏ 步经过的边权最小值。查询时，跳的过程中顺便取 min。

```cpp
mn[u][k] = min(mn[u][k - 1], mn[fa[u][k - 1]][k - 1]);
```

不连通时（不在同一棵树里，用并查集判断）输出 -1。

> **Kruskal + 倍增 LCA** 的组合在 NOIP 中多次出现。

## 6. 易错点清单

1. LOG 太小：n = 5×10⁵ 时需要 LOG ≥ 19。
2. 根的父亲没设成 0，或 dep[0] 不是 0，跳出树外。
3. 点差分和边差分的公式混淆。
4. 树上差分最后的子树求和要从叶子往根（后序）累加。
5. 递归 DFS 在链状树上爆栈，需要时改用 BFS 预处理 fa 和 dep。
6. 森林的情况：每棵树分别 DFS。

## 8. 自测

1. 一棵树中，dist(u, v) 怎么用 LCA 表示？
2. 为什么倍增求 LCA 的第二步是"父亲不同才跳"？
3. 点差分为什么要在 fa[lca] 处减 1？

<details><summary>答案</summary>

1. dep[u] + dep[v] - 2 × dep[lca(u, v)]。
2. 避免跳过头到 LCA 的祖先；跳到恰好在 LCA 下面，父亲就是 LCA。
3. 子树求和时，u 和 v 的 +1 会一直传到根，在 LCA 减 1 消掉重复的那份，在 fa[lca] 再减 1 消掉 LCA 以上不该有的那份。

</details>
