# 树形 DP

> **学完能做到**：在树上做"从叶子往根"的 DP；解决最大独立集、最小点覆盖、树上背包；用换根 DP 求每个点作为根时的答案。
> **前置知识**：树的存储与 DFS、背包问题。

---

## 1. 树形 DP 的基本形式

在树上，一个节点的答案往往由它**所有儿子**的答案合并而来。所以：

1. DFS 到叶子。
2. **回溯时**用儿子的 f 计算自己的 f。

```cpp
void dfs(int u, int fa) {
    // 初始化 f[u]
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        // 用 f[v] 更新 f[u]
    }
}
```

## 2. 最大独立集：没有上司的舞会（P1352）

公司的上下级关系是一棵树，每个人有快乐值。**一个人和他的直接上司不能同时来**，求最大快乐值之和。

1. 状态：
   - f[u][0] = u **不来**时，u 的子树的最大快乐值。
   - f[u][1] = u **来**时，u 的子树的最大快乐值。
2. 转移：
   - u 来：儿子都不能来。**f[u][1] = h[u] + Σ f[v][0]**
   - u 不来：儿子来不来都行。**f[u][0] = Σ max(f[v][0], f[v][1])**
3. 答案：max(f[root][0], f[root][1])。

```cpp
void dfs(int u) {
    f[u][0] = 0;
    f[u][1] = h[u];
    for (int v : son[u]) {
        dfs(v);
        f[u][0] += max(f[v][0], f[v][1]);
        f[u][1] += f[v][0];
    }
}
```

找根：入度为 0（没有上司）的人。

> **"选或不选"是树形 DP 最常见的状态设计**：用一维 0/1 表示当前点的状态。

## 3. 最小点覆盖：战略游戏（P2016）

在树的节点上放士兵，每个士兵能看守和它相连的所有边，求看守所有边最少要几个士兵。

- f[u][1] = u 放士兵：1 + Σ min(f[v][0], f[v][1])
- f[u][0] = u 不放：每条边 (u, v) 只能由 v 看守，**Σ f[v][1]**

和上一题的转移正好"反过来"。

## 4. 最大子树和（P1122）

一棵树每个点有美丽值（可能为负），剪掉一些枝条后剩下一个连通块，求最大美丽值之和。

f[u] = 以 u 为最高点的连通块的最大和 = a[u] + Σ max(0, f[v])（儿子的贡献为负就剪掉）。

答案是所有 f[u] 的最大值。

## 5. 树上背包

### 二叉苹果树（P2015）

一棵二叉树，边上有苹果，只保留 Q 条边（必须和根连通），求最多保留多少苹果。

1. 状态：f[u][j] = 在 u 的子树中保留 j 条边的最多苹果。
2. 转移：对每个儿子 v，像分组背包一样合并：给 v 分配 k 条边（还要加上 u-v 这条边本身）：

```cpp
void dfs(int u, int fa) {
    for (auto [v, w] : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        for (int j = Q; j >= 1; j--)                       // 倒序，类似 01 背包
            for (int k = 0; k < j; k++)                    // 分给 v 子树 k 条边，再加上 u-v 这条
                f[u][j] = max(f[u][j], f[u][j - k - 1] + f[v][k] + w);
    }
}
```

### 选课（P2014）

每门课最多一门先修课，选 M 门课求最大学分。先修关系构成森林，加一个虚拟根 0（学分 0）变成一棵树，选 M + 1 个点。

f[u][j] = u 的子树中选 j 门课（u 必须选）的最大学分。合并儿子的方式和上题一样。

### 复杂度

树上背包如果 j 的上界取**子树大小**而不是固定的 M，总复杂度是 **O(n²)**（每对节点只在它们的 LCA 处合并一次）。

```cpp
// sz[u] 是目前已合并部分的大小
for (int j = min(sz[u] + sz[v], M); j >= 1; j--)
    for (int k = max(0, j - sz[u]); k <= min(sz[v], j - 1); k++)
        ...
sz[u] += sz[v];
```

## 6. 区间 DP 遇上树：加分二叉树（P1040）

中序遍历为 1, 2, …, n 的二叉树，分数 = 左子树分数 × 右子树分数 + 根的分数（空子树分数为 1）。求最大分数和对应的先序遍历。

中序遍历是 1～n，所以每棵子树对应一个**区间** [i, j]。枚举根 k：

f[i][j] = max(f[i][k-1] × f[k+1][j] + a[k])

这其实是**区间 DP**。记录每个区间选的根 root[i][j]，最后递归输出先序遍历。

## 7. 换根 DP：STA-Station（P3478）

给一棵树，求一个点作为根时，所有点的深度之和最大。

暴力：每个点当根 DFS 一次，O(n²)。

**换根**：

1. 第一次 DFS：以 1 为根，求每个点的子树大小 sz[u]，以及 f[1] = 所有点的深度之和。
2. 第二次 DFS：从父亲 u 的答案推出儿子 v 的答案。根从 u 换到 v 时：
   - v 子树中的 sz[v] 个点深度都 **减 1**；
   - 其余 n - sz[v] 个点深度都 **加 1**。
   - **f[v] = f[u] - sz[v] + (n - sz[v])**

```cpp
void dfs2(int u, int fa) {
    for (int v : g[u]) {
        if (v == fa) continue;
        f[v] = f[u] + n - 2LL * sz[v];
        dfs2(v, u);
    }
}
```

两次 DFS，O(n)。

> **换根 DP 的套路**：先以任意点为根算出一个答案，再推导"根从父亲移到儿子时答案怎么变"。

## 8. 易错点清单

1. 无根树 DFS 没判断父亲，死循环。
2. 树上背包循环方向错（应该倒序），导致一个儿子被用多次。
3. 树上背包上界固定为 M，复杂度变成 O(nM²)，可能超时。
4. 换根公式推错，用一个小例子（3 个点的链）手算验证。
5. 深度之和可能很大，用 `long long`。
6. 树很深时递归爆栈（10⁶ 个点的链），必要时改成 BFS 序倒序处理。

## 10. 自测

1. 没有上司的舞会中，u 不来时为什么儿子取 max(f[v][0], f[v][1])？
2. 换根时，从 u 换到 v，为什么 v 子树里的点深度减 1？
3. 树上背包为什么要倒序枚举 j？

<details><summary>答案</summary>

1. u 不来，儿子来不来都不违反规则，选更大的。
2. 根离它们近了一步。
3. 保证 f[u][j - k - 1] 是合并 v 之前的值，每个儿子子树只被"使用"一次。
