# 并查集进阶

> **学完能做到**：用"扩展域"处理敌人/朋友关系；用"带权并查集"维护到根的距离；把问题转化为并查集判断连通。
> **前置知识**：并查集基础（普及组）。

---

## 1. 回顾

```cpp
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
void unite(int x, int y) { fa[find(x)] = find(y); }
```

普通并查集只能表示"在同一集合"。很多题目有**两种或多种关系**（朋友 / 敌人，同类 / 吃 / 被吃），需要扩展。

## 2. 扩展域并查集

### 团伙（P1892）

规则：朋友的朋友是朋友；**敌人的敌人是朋友**。问最多有几个团伙。

**扩展域**：每个人 x 拆成两个点，x 表示"x 本人"，x + n 表示"x 的敌人"。

- x 和 y 是朋友：unite(x, y)。
- x 和 y 是敌人：unite(x, y + n)（x 和 y 的敌人是一伙），unite(y, x + n)。

这样"敌人的敌人"：x 和 y 是敌人 → x 和 y+n 同集合；y 和 z 是敌人 → z 和 y+n 同集合；所以 x 和 z 同集合，是朋友 ✓。

最后数 1～n 中有几个不同的根。

### 关押罪犯（NOIP2010，P1525）

两座监狱，罪犯之间有怨气值，同一监狱的两人会爆发冲突。求冲突的最大值的最小可能。

**贪心 + 扩展域**：把怨气从大到小排序，尽量把怨气大的两人分开。依次处理 (a, b, c)：

- 如果 a 和 b 已经在**同一集合**（被迫在同一监狱），答案就是 c，结束。
- 否则让他们在不同监狱：unite(a, b + n)，unite(b, a + n)。

```cpp
sort(e.begin(), e.end(), [](auto &x, auto &y) { return x.c > y.c; });
for (int i = 1; i <= 2 * n; i++) fa[i] = i;
for (auto [a, b, c] : e) {
    if (find(a) == find(b)) { cout << c; return 0; }
    unite(a, b + n); unite(b, a + n);
}
cout << 0;
```

（这题也可以二分答案 + 二分图染色，见"二分图"一课。）

### 食物链（P2024）

三类动物 A 吃 B、B 吃 C、C 吃 A。每个动物 x 拆成三个点：x（同类域）、x + n（猎物域）、x + 2n（天敌域）。

- x 和 y 同类：unite(x, y)，unite(x+n, y+n)，unite(x+2n, y+2n)。
- x 吃 y：unite(x+n, y)（y 在 x 的猎物域），unite(x, y+2n)，unite(x+2n, y+n)。

判断一句话是假话：检查它是否与已有关系矛盾。例如说"x 和 y 同类"，但 x+n 和 y 已经在同一集合（x 吃 y），就是假话。

## 3. 带权并查集

### 银河英雄传说（P1196）

30000 列战舰，操作：把第 i 号所在的整列接到第 j 号所在列的**尾部**；询问 i 和 j 是否在同一列，如果是，它们之间隔了几艘。

维护：

- `d[x]`：x 到它父亲的距离（前面有几艘）。路径压缩后就是 x 到根（队头）的距离。
- `sz[x]`：以 x 为根的集合大小（这一列有几艘）。

```cpp
int fa[N], d[N], sz[N];

int find(int x) {
    if (fa[x] == x) return x;
    int root = find(fa[x]);     // 先把父亲压缩到根，d[fa[x]] 变成父亲到根的距离
    d[x] += d[fa[x]];           // x 到根 = x 到父亲 + 父亲到根
    return fa[x] = root;
}

void merge(int i, int j) {      // 把 i 所在列接到 j 所在列后面
    int ri = find(i), rj = find(j);
    fa[ri] = rj;
    d[ri] = sz[rj];             // ri 前面有整列 j 那么多艘
    sz[rj] += sz[ri];
}

int query(int i, int j) {
    if (find(i) != find(j)) return -1;
    return abs(d[i] - d[j]) - 1;
}
```

**关键**：路径压缩时，要**先递归**处理父亲，再更新 d[x]。顺序写反就错了。

> 带权并查集的核心：**边权表示和父亲的关系，路径压缩时沿路累加（或做其他运算）**。

食物链也可以用带权并查集做：d[x] 表示 x 和父亲的关系（0 同类、1 吃父亲、2 被父亲吃），在模 3 意义下累加。

## 4. 把问题转化为连通性

### 程序自动分析（P1955）

很多约束 xᵢ = xⱼ 或 xᵢ ≠ xⱼ，判断能否同时满足。

1. **先处理所有相等**：unite。
2. **再检查所有不等**：如果 find(i) == find(j)，矛盾。

变量编号到 10⁹，需要**离散化**。

> 顺序很重要：如果边处理边判断，可能"不等"出现在"相等"之前，漏掉矛盾。

### 奶酪（NOIP2017，P3958）

三维空间中有若干球形空洞，相交或相切的空洞连通，问能否从底部（z = 0）到顶部（z = h）。

1. 两个球心距离 ≤ 2r 就合并。
2. 加两个虚拟点：底部和顶部。球碰到底面（z ≤ r）就和底部合并，碰到顶面就和顶部合并。
3. 最后看底部和顶部是否连通。

注意坐标到 10⁹，距离平方可能超过 long long，可以先判断各维差值是否超过 2r，或者用 `__int128` / `double`。

## 5. 易错点清单

1. 扩展域数组没开 2 倍或 3 倍。
2. 带权并查集路径压缩的顺序：先 find(fa[x]) 再更新 d[x]。
3. 合并时忘了更新被接上去的根的权值。
4. "相等"和"不等"约束的处理顺序。
5. 距离平方溢出。

## 7. 自测

1. 团伙中，x 和 y 是敌人，要合并哪两对？
2. 银河英雄传说中，`d[ri] = sz[rj]` 是什么意思？
3. 程序自动分析为什么要先处理所有相等的约束？

<details><summary>答案</summary>

1. (x, y + n) 和 (y, x + n)。
2. 整列 i 接在列 j 后面，所以原来的队头 ri 前面有 sz[rj] 艘战舰。
3. 相等关系有传递性，要等所有相等关系都合并完，才能准确判断两个变量是否被迫相等。

</details>
