## 1. 多重背包

第 i 种物品有 sᵢ 件。

### 朴素做法

把 sᵢ 件物品当成 sᵢ 个 01 物品。复杂度 O(m × Σsᵢ)，sᵢ 大时超时。

### 二进制拆分

把 sᵢ 件拆成 1, 2, 4, …, 2ᵏ, 剩余 r 这几组（每组当作一个 01 物品）。这些组的组合可以表示 0～sᵢ 之间的**任何**数量。

例：s = 13 → 拆成 1, 2, 4, 6（1+2+4 = 7，剩余 6）。0～13 都能由这几个数凑出来。

```cpp
for (int i = 1; i <= n; i++) {
    int w, v, s; cin >> v >> w >> s;
    for (int k = 1; s > 0; k *= 2) {
        int take = min(k, s);
        s -= take;
        // 把 (take * w, take * v) 当作一个 01 物品
        for (int j = m; j >= take * w; j--)
            f[j] = max(f[j], f[j - take * w] + take * v);
    }
}
```

复杂度 O(m × Σlog sᵢ)。

### 宝物筛选（P1776）

多重背包模板，用二进制拆分。（更快的做法是**单调队列优化**，复杂度 O(nm)，有兴趣可以在学完"DP 优化"后回来研究。）

## 2. 混合背包：樱花（P1833）

有的物品只能拿一次，有的能拿无限次，有的能拿 sᵢ 次。

对每个物品，按它的类型选择对应的循环方式即可：

```cpp
for (each item) {
    if (s == 0) {                                // 无限
        for (int j = w; j <= m; j++) f[j] = max(f[j], f[j - w] + v);
    } else {                                     // 有限（含 s == 1）
        二进制拆分后做 01 背包;
    }
}
```

## 3. 计数类背包

### 摆花（P1077）

n 种花，第 i 种最多摆 aᵢ 盆，一共摆 m 盆，同种花放在一起，且按种类编号顺序摆放，问方案数。

f[i][j] = 前 i 种花摆 j 盆的方案数 = Σ f[i-1][j-k]（k 从 0 到 min(aᵢ, j)）。

这是"每种物品选 0～aᵢ 个"的计数背包，O(nm × max a)，数据小直接做；数据大可以用前缀和优化掉 k 的循环。

### 完全背包求方案数

凑出 m 元的方案数（面额可以重复使用）：

```cpp
f[0] = 1;
for (int i = 1; i <= n; i++)
    for (int j = a[i]; j <= m; j++)
        f[j] += f[j - a[i]];
```

> **外层物品、内层容量**：求的是**组合数**（不计顺序）。如果反过来，外层容量、内层物品，求的是**排列数**（计顺序，比如爬楼梯每次 1、2、3 步）。

## 4. 货币系统（NOIP2018，P5020）

给一个货币系统 (n, a)，找一个面额最少的等价系统 (m, b)（能表示的金额完全一样）。

**结论**：b 一定是 a 的子集。把 a 从小到大排序，**如果 aᵢ 能被比它小的面额凑出来，就是多余的**；否则必须保留。

用完全背包判断"能否凑出"：

```cpp
sort(a + 1, a + n + 1);
memset(can, 0, sizeof(can));
can[0] = true;
int ans = 0;
for (int i = 1; i <= n; i++) {
    if (!can[a[i]]) {
        ans++;
        for (int j = a[i]; j <= a[n]; j++) can[j] |= can[j - a[i]];   // 完全背包
    }
}
```

## 5. 建模成背包：垃圾陷阱（P1156）

奶牛掉进深度 D 的井里，有 G 个垃圾按时间落下。每个垃圾可以**吃掉**（增加生命时间）或者**堆起来**（增加高度）。奶牛初始能活 10 小时，求最早何时能爬出；爬不出就求最长能活多久。

1. 状态：f[j] = 高度为 j 时最多能活到的时刻。
2. 按落下时间排序，依次处理每个垃圾（像 01 背包一样，每个用一次）：
   - 能活到这个垃圾落下（f[j] ≥ tᵢ）才能处理。
   - 堆起来：f[j + hᵢ] = max(f[j + hᵢ], f[j])；如果 j + hᵢ ≥ D，答案就是 tᵢ。
   - 吃掉：f[j] += lifeᵢ。
3. 注意高度要**倒序**枚举，避免同一个垃圾被用两次。

> 背包的本质：**每个物品做一次决策，状态中记录"已用的某种资源"**。很多题目的"资源"不是重量，而是高度、时间、次数……

## 6. 易错点清单

1. 二进制拆分时最后剩余部分 r 忘记加入。
2. 混合背包中不同类型用错了循环方向。
3. 组合数和排列数的循环顺序搞反。
4. 计数结果需要取模时漏了取模。
5. 二进制拆分后物品数变多，数组没开够（如果先存下来再做的话）。
