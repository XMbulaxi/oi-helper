## 1. 用整数表示集合

n 个元素（n ≤ 20 左右），每个选或不选，可以用一个 n 位二进制数表示：第 i 位为 1 表示第 i 个元素在集合中。

```
n = 5，集合 {0, 2, 3} → 01101₂ = 13
```

### 常用位运算

| 操作 | 写法 |
| --- | --- |
| 第 i 位是否为 1 | `S >> i & 1` |
| 加入元素 i | `S | (1 << i)` |
| 删除元素 i | `S & ~(1 << i)` |
| 集合大小 | `__builtin_popcount(S)` |
| 全集 | `(1 << n) - 1` |
| 是否有相邻的 1 | `S & (S << 1)` |
| A 是否是 B 的子集 | `(A & B) == A` |
| A、B 是否不相交 | `(A & B) == 0` |
| 枚举 S 的所有子集 | `for (int T = S; T; T = (T - 1) & S)` |

## 2. 网格上的状压：互不侵犯（P1896）

N × N 的棋盘放 K 个国王，国王能攻击周围 8 格，求方案数（N ≤ 9）。

**逐行处理**：每一行放国王的位置用一个 N 位二进制数表示。

1. **预处理合法行状态**：同一行内国王不能相邻 → `!(S & (S << 1))`。
2. 状态：f[i][S][k] = 前 i 行、第 i 行状态是 S、一共放了 k 个国王的方案数。
3. 转移：枚举上一行的状态 T，要求 S 和 T 不冲突：
   - 正上方：`S & T == 0`
   - 斜上方：`S & (T << 1) == 0` 且 `S & (T >> 1) == 0`
   - f[i][S][k] += f[i-1][T][k - popcount(S)]

```cpp
vector<int> ok;                     // 合法的单行状态
for (int S = 0; S < (1 << n); S++) if (!(S & (S << 1))) ok.push_back(S);
f[0][0][0] = 1;
for (int i = 1; i <= n; i++)
    for (int S : ok)
        for (int T : ok) {
            if ((S & T) || (S & (T << 1)) || (S & (T >> 1))) continue;
            int c = __builtin_popcount(S);
            for (int k = c; k <= K; k++) f[i][S][k] += f[i - 1][T][k - c];
        }
// 答案 = Σ f[n][S][K]
```

合法行状态很少（N = 9 时只有 89 个），所以很快。

### Corn Fields（P1879）

M × N 的牧场，有的格子不能种草，种草的格子不能相邻（上下左右），求方案数。

和上题类似，多一个条件：第 i 行的状态 S 必须是该行**可种草格子**的子集。斜方向不限制。

### 炮兵阵地（P2704）

炮兵攻击范围是上下左右各两格，有的格子是山地不能放，求最多放多少。

因为攻击范围是**两行**，状态要记录**当前行和上一行**：f[i][S][T] = 第 i 行状态 S、第 i-1 行状态 T 时的最大数量。转移时枚举第 i-2 行的状态。合法单行状态（不能有距离 ≤ 2 的两个 1）非常少（M = 10 时只有 60 个），所以三重循环也很快。

## 3. 集合上的 DP：旅行商问题

### 吃奶酪（P1433）

平面上 n 块奶酪（n ≤ 15），从原点出发吃完所有奶酪，求最短距离。

1. 状态：f[S][i] = 已经吃了集合 S 中的奶酪，**现在在第 i 块**，走过的最短距离。
2. 转移：从 S 中另一块 j 走过来：
   **f[S][i] = min(f[S \ {i}][j] + dist(j, i))**
3. 初始值：f[{i}][i] = dist(原点, i)。
4. 答案：min(f[全集][i])。

```cpp
for (int i = 0; i < n; i++) f[1 << i][i] = dist0[i];
for (int S = 1; S < (1 << n); S++)
    for (int i = 0; i < n; i++) {
        if (!(S >> i & 1)) continue;
        int pre = S ^ (1 << i);
        if (pre == 0) continue;
        for (int j = 0; j < n; j++)
            if (pre >> j & 1) f[S][i] = min(f[S][i], f[pre][j] + d[j][i]);
    }
```

复杂度 O(2ⁿ × n²)。n = 15 时约 7×10⁶。

### 售货员的难题（P1171）

经典 TSP，从村庄 1 出发经过所有村庄回到 1，n ≤ 20。O(2ⁿ × n²) ≈ 4×10⁸，需要卡常：

- 状态中**固定包含起点**，只对其他 n-1 个点状压，空间和时间都减半。
- 循环中跳过 f[S][i] 为 INF 的状态。

## 4. 什么时候想到状压

- 数据范围出现 **n ≤ 20**（甚至 ≤ 15、≤ 12），而且需要记录"哪些已经用过"。
- 网格的**某一维很小**（≤ 10 左右），按行或按列转移。

## 5. 易错点清单

1. 位运算优先级：`S & T == 0` 实际是 `S & (T == 0)`！一定写成 `(S & T) == 0`。
2. 状态数组太大：2²⁰ × 20 个 int 约 80 MB，注意内存限制。
3. 枚举顺序：f[S] 依赖 S 的子集，子集的编号一定比 S 小，所以 S 从小到大枚举即可。
4. 状态从 0 开始还是 1 开始的位，和元素编号要对齐。

3. TSP 的状态为什么要记录"现在在哪个点"？

<details><summary>答案</summary>

1. 11010₂ = 26。
2. S 中有两个相邻的 1（相邻位置都被选了）。
3. 下一步走到哪的距离取决于当前所在的点，只记录集合不够（不满足无后效性）。
