# 倍增与 ST 表

> **学完能做到**：理解倍增思想；用 ST 表 O(1) 回答区间最值询问；为以后的 LCA 打基础。
> **前置知识**：动态规划入门、位运算基础。

---

## 1. 倍增的思想

要从 1 跳到 13，每次只能跳 1 步，要跳 12 次。如果可以跳 1、2、4、8……步，只要 8 + 4 = 12，两次就够了。

**倍增**：预处理"跳 2ᵏ 步"的结果，任何步数都能拆成二进制，用 O(log n) 次跳完。

快速幂就是倍增：预处理 a¹, a², a⁴, a⁸, …，按 b 的二进制相乘。

## 2. 区间最值问题（RMQ）

给一个长度为 n 的数组，m 次询问 [l, r] 中的最大值。数组**不修改**。

- 暴力：每次 O(n)。
- 线段树：每次 O(log n)。
- **ST 表**：预处理 O(n log n)，每次询问 **O(1)**。

## 3. ST 表

### 状态

**f[i][k] = 从 i 开始、长度为 2ᵏ 的区间 [i, i + 2ᵏ - 1] 的最大值。**

### 转移

长度 2ᵏ 的区间 = 两个长度 2ᵏ⁻¹ 的区间拼起来：

**f[i][k] = max(f[i][k-1], f[i + 2ᵏ⁻¹][k-1])**

```
k=0: f[i][0] = a[i]
k=1: [i, i+1]     = max(f[i][0], f[i+1][0])
k=2: [i, i+3]     = max(f[i][1], f[i+2][1])
k=3: [i, i+7]     = max(f[i][2], f[i+4][2])
```

### 查询

[l, r] 的长度 len = r - l + 1，取 k = ⌊log₂ len⌋，那么 2ᵏ ≤ len < 2ᵏ⁺¹。

用两个长度 2ᵏ 的区间**覆盖**整个 [l, r]：一个从 l 开始，一个在 r 结束。它们可能有重叠，但**求最大值时重叠没关系**。

**max(f[l][k], f[r - 2ᵏ + 1][k])**

```
l              r
[====2^k====]
      [====2^k====]
```

### 模板

```cpp
const int N = 100005, LOG = 17;   // 2^17 > 10^5
int f[N][LOG + 1], lg[N];

void build(int n) {
    lg[1] = 0;
    for (int i = 2; i <= n; i++) lg[i] = lg[i / 2] + 1;   // 预处理 log₂
    for (int i = 1; i <= n; i++) f[i][0] = a[i];
    for (int k = 1; k <= LOG; k++)
        for (int i = 1; i + (1 << k) - 1 <= n; i++)
            f[i][k] = max(f[i][k - 1], f[i + (1 << (k - 1))][k - 1]);
}

int query(int l, int r) {
    int k = lg[r - l + 1];
    return max(f[l][k], f[r - (1 << k) + 1][k]);
}
```

> 注意循环顺序：**k 在外层**。因为算 f[·][k] 需要所有的 f[·][k-1] 都算好。

### 适用范围

ST 表要求运算满足"**重叠不影响结果**"（可重复贡献），比如 max、min、gcd、按位与、按位或。**求和不行**（重叠部分会算两次），求和用前缀和。

## 4. 位运算小知识

```cpp
1 << k          // 2^k
x >> 1          // x / 2
x & 1           // x 是否为奇数
__lg(x)         // ⌊log₂ x⌋（GCC 内置），也可以预处理 lg 数组
__builtin_popcount(x)   // x 的二进制中 1 的个数
```

## 5. 倍增的其他应用

### 跳跃问题

如果每个位置 i 都有一个"下一步去哪" nxt[i]，要问"从 i 走 k 步到哪"：

```cpp
up[i][0] = nxt[i];
up[i][j] = up[ up[i][j-1] ][j-1];   // 走 2^j 步 = 走两次 2^(j-1) 步
```

询问时按 k 的二进制拆分跳。这就是**树上倍增求 LCA** 的基础（后面会学）。

## 6. 例题：Balanced Lineup（P2880）

n 头牛排成一行，每次询问 [l, r] 中最高和最矮的差。建两个 ST 表（max 和 min）即可。

## 7. 例题：质量检测（P2251）

长度为 n 的数列，求每个长度为 m 的连续区间的最小值（也就是滑动窗口最小值）。ST 表可以做，单调队列（下一课）也可以做，而且更快。两种都写一遍对比。

## 8. 易错点清单

1. LOG 开小了：n = 10⁶ 时 2²⁰ > 10⁶，LOG 至少 20。
2. 预处理时 k 和 i 的循环顺序写反。
3. 查询时 `r - (1 << k) + 1` 写错。
4. 用 ST 表求区间和。
5. 用 `log2()` 函数（浮点）可能有误差，预处理 lg 数组或用 `__lg`。

3. ST 表能求区间和吗？为什么？

1. [3, 6]（长度 2² = 4）。
2. 长度 9，k = 3；用 [2, 9] 和 [3, 10]。
