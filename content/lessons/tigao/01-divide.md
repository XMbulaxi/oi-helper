# 分治与归并排序

> **学完能做到**：用分治思想设计算法并分析复杂度；写出归并排序；用归并排序求逆序对；理解平面最近点对的分治做法。
> **前置知识**：递归、排序。

---

## 1. 分治三步

**分治**（divide and conquer）：

1. **分**：把问题分成几个规模更小的**同类**子问题。
2. **治**：递归解决子问题（足够小时直接解决）。
3. **合**：把子问题的答案合并成原问题的答案。

零基础阶段的"赦免战俘"、二分查找都是分治。分治的难点通常在**合并**这一步。

## 2. 复杂度分析

设规模为 n 的问题耗时 T(n)。如果分成两半、合并要 O(n)：

T(n) = 2T(n/2) + O(n)

递归树每层总共处理 n 个元素，共 log n 层，所以 **T(n) = O(n log n)**。

常见情况：

| 递推式 | 复杂度 | 例子 |
| --- | --- | --- |
| T(n) = T(n/2) + O(1) | O(log n) | 二分查找 |
| T(n) = 2T(n/2) + O(1) | O(n) | 求最大值（分治写法） |
| T(n) = 2T(n/2) + O(n) | O(n log n) | 归并排序 |
| T(n) = 2T(n/2) + O(n log n) | O(n log² n) | 部分分治写法的最近点对 |

## 3. 归并排序

1. 把数组从中间分成两半。
2. 分别排好序（递归）。
3. 把两个**有序**数组合并成一个有序数组：两个指针分别指向两边开头，每次取较小的那个放进结果。

```
[5 2 4 7 1 3 2 6]
分：[5 2 4 7]  [1 3 2 6]
递归排好：[2 4 5 7]  [1 2 3 6]
合并：
  2 vs 1 → 取 1     [1]
  2 vs 2 → 取左 2   [1 2]
  4 vs 2 → 取 2     [1 2 2]
  4 vs 3 → 取 3     [1 2 2 3]
  4 vs 6 → 取 4     ...
结果：[1 2 2 3 4 5 6 7]
```

```cpp
int a[N], tmp[N];

void mergeSort(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(l, mid);
    mergeSort(mid + 1, r);
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int t = l; t <= r; t++) a[t] = tmp[t];
}
```

- 复杂度稳定 O(n log n)。
- **稳定排序**：相等元素保持原来的相对顺序（`a[i] <= a[j]` 取左边保证这点）。`std::stable_sort` 就是归并排序。

## 4. 求逆序对（P1908）

逆序对：i < j 且 a[i] > a[j] 的数对。n 到 5×10⁵，O(n²) 会超时。

**在归并的合并步骤中统计**：左半边和右半边都已排好序。当右边的 a[j] 比左边的 a[i] 小、被先放进结果时，左边从 i 到 mid 的所有数都比 a[j] 大，它们都和 a[j] 构成逆序对，一共 **mid - i + 1** 个。

```cpp
long long ans = 0;
// 在合并的 while 中：
if (a[i] <= a[j]) tmp[k++] = a[i++];
else {
    ans += mid - i + 1;     // a[i..mid] 都比 a[j] 大
    tmp[k++] = a[j++];
}
```

为什么不会漏、不会重？每个逆序对 (i, j) 恰好在"i 和 j 第一次被分到不同两半"的那一层被统计一次。左右两半内部的逆序对在递归里已经统计过了。

> 逆序对也可以用树状数组求（见树状数组一课），两种方法都要会。

### 逆序对的应用

- 冒泡排序的交换次数 = 逆序对数。
- 相邻交换把一个排列变成另一个排列的最少次数（NOIP2013 火柴排队）。

## 5. 归并思想：瑞士轮（P1309）

2N 名选手，每轮按分数排序，第 1 和第 2 比、第 3 和第 4 比……胜者加 1 分。R 轮后问第 Q 名是谁。

每轮都 `sort` 是 O(R × N log N)，会超时。

**观察**：每轮比赛后，**胜者组**内部仍然有序（大家都加 1），**败者组**内部也有序（都不变）。所以只要把这两个有序数组**归并**，O(N) 就得到新的排名。总 O(RN)。

> 利用"两个已经有序的序列"来避免重新排序，是归并思想的典型应用。

## 7. 例题：平面上的最接近点对（P1257）

n 个点，求距离最近的两个点的距离。n ≤ 10⁴ 时 O(n²) 可以过，但这是学习分治的经典例子：

1. 按 x 坐标排序，从中间分成左右两半，递归求出两边的最近距离 d₁、d₂，d = min(d₁, d₂)。
2. **合并**：跨越中线的点对，只有 x 坐标离中线不超过 d 的点才可能更近。把这些点按 y 排序，对每个点只需要检查 y 坐标差小于 d 的点——可以证明最多只有常数个（约 6 个）。

复杂度 O(n log² n)，在合并时用归并按 y 排序可以做到 O(n log n)。

## 8. 易错点清单

1. 逆序对数可能到 n²/2 ≈ 1.25×10¹¹，必须 `long long`。
2. 归并时相等元素取左边，否则逆序对会多算（相等不算逆序）。
3. tmp 数组不要在递归里每次开新的（太慢），开一个全局的。
4. mid 的分法和递归边界不一致导致死循环。
