# 最短路进阶：负环、差分约束、分层图

> **学完能做到**：用 SPFA 判断负环；把不等式组转化为最短路（差分约束）；建分层图处理"可以免费 k 次"之类的问题；在最短路基础上做 DP。
> **前置知识**：最短路（普及组）。

---

## 1. 负环

如果图中有一个环，环上边权之和为负，那么沿着它绕圈距离会无限变小，**最短路不存在**。

### SPFA 判负环

在没有负环的图中，任何最短路最多经过 n - 1 条边。所以记录每个点最短路的**边数** cnt[v]，如果 cnt[v] ≥ n，说明存在负环。

```cpp
bool spfa(int s, int n) {              // 返回 true 表示有从 s 可达的负环
    fill(dis + 1, dis + n + 1, INF);
    fill(cnt + 1, cnt + n + 1, 0);
    queue<int> q;
    dis[s] = 0; q.push(s); inq[s] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop(); inq[u] = false;
        for (auto [v, w] : g[u]) {
            if (dis[u] + w < dis[v]) {
                dis[v] = dis[u] + w;
                cnt[v] = cnt[u] + 1;
                if (cnt[v] >= n) return true;
                if (!inq[v]) { q.push(v); inq[v] = true; }
            }
        }
    }
    return false;
}
```

> 只能找到**从 s 能到达**的负环。如果要判断整张图有没有负环，加一个虚拟源点连向所有点（边权 0），或者一开始把所有点都入队、dis 都设为 0。

## 2. 差分约束

### 问题

给出若干形如 **xᵢ - xⱼ ≤ c** 的不等式，求一组满足的解（或判断无解）。

### 转化

最短路满足三角不等式：**dis[v] ≤ dis[u] + w(u, v)**，即 dis[v] - dis[u] ≤ w。

对比 xᵢ - xⱼ ≤ c：**从 j 向 i 连一条边权为 c 的边**。跑最短路，dis 就是一组解。

- 有负环 → 无解。
- 图可能不连通 → 加虚拟源点 0，向每个点连边权 0 的边，从 0 跑 SPFA。

```cpp
// x[a] - x[b] <= c  →  addEdge(b, a, c)
for (int i = 1; i <= n; i++) addEdge(0, i, 0);
if (spfa(0, n + 1)) puts("NO");
else for (int i = 1; i <= n; i++) printf("%lld ", dis[i]);
```

### 其他形式的转化

| 约束 | 改写 | 连边 |
| --- | --- | --- |
| xᵢ - xⱼ ≤ c | — | j → i，权 c |
| xᵢ - xⱼ ≥ c | xⱼ - xᵢ ≤ -c | i → j，权 -c |
| xᵢ - xⱼ = c | ≤ c 且 ≥ c | 两条边 |
| xᵢ - xⱼ < c（整数） | xᵢ - xⱼ ≤ c - 1 | j → i，权 c-1 |

### 例：小 K 的农场（P1993）

三种信息：a 比 b 至少多 c；a 比 b 至多多 c；a 和 b 一样多。判断是否可能。全部转化成上表的形式，判负环。

> **求最大解用最短路，求最小解用最长路**（把不等式全转成 ≥，跑最长路，判正环）。

## 3. 分层图

### 飞行路线（P4568）

n 个城市 m 条航线，最多可以**免费**乘坐 k 次，求从 s 到 t 的最少花费。

**建 k + 1 层图**：第 j 层表示"已经用了 j 次免费"。

- 每一层内部：原图的边，权值不变。
- 层与层之间：原图中 u → v 的边，从第 j 层的 u 连到第 **j + 1** 层的 v，**权值 0**（用一次免费）。

点 (u, j) 编号为 u + j × n。跑一次 Dijkstra，答案是 min(dis[t + j × n])，j = 0..k。

```cpp
for (auto [u, v, w] : edges) {
    for (int j = 0; j <= k; j++) {
        addEdge(u + j * n, v + j * n, w);
        addEdge(v + j * n, u + j * n, w);           // 无向
        if (j < k) {
            addEdge(u + j * n, v + (j + 1) * n, 0);
            addEdge(v + j * n, u + (j + 1) * n, 0);
        }
    }
}
```

点数 n(k+1)，边数约 4m(k+1)，注意数组大小。

也可以不显式建图：dis[u][j] 二维数组，Dijkstra 时状态是 (u, j)，转移时多一种"免费"选择。

> **"可以用 k 次特殊操作"** → 分层图，或者把"用了几次"加进最短路的状态。

## 4. 最短路 + DP：最优贸易（NOIP2009，P1073）

n 个城市，有单向和双向道路，每个城市水晶球价格不同。从 1 出发到 n，途中在某城市买一次、之后在某城市卖一次，求最大差价。

1. 正图从 1 出发，求 mn[v] = 从 1 到 v 的路径上**最低**的价格（"最短路"的运算从 + 换成 min）。
2. 反图从 n 出发，求 mx[v] = 从 v 到 n 的路径上**最高**的价格。
3. 答案 = max(mx[v] - mn[v])，对每个 v（v 作为"中转点"，在之前买、之后卖）。

求 mn 不能用 Dijkstra（这不是加法），用 SPFA 或 BFS 不断更新到稳定即可。另一种做法是 Tarjan 缩点后在 DAG 上 DP。

## 5. 易错点清单

1. 差分约束边的方向连反。
2. 判负环时 cnt 的判断条件（≥ n，注意加了虚拟源点后点数是 n + 1）。
3. 图不连通，只从 1 出发判负环漏掉了别的部分。
4. 分层图数组大小没有乘 (k+1)。
5. 分层图中"免费"的边只连向下一层，不能连回上一层。
