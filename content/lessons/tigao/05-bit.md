# 树状数组

> **学完能做到**：用树状数组支持单点修改、区间查询；通过差分支持区间修改、单点查询；用树状数组求逆序对；理解离散化。
> **前置知识**：前缀和、位运算、二进制。

---

## 1. 问题

一个数组，两种操作交替进行：

1. 把 a[x] 加上 k；
2. 求 [l, r] 的和。

- 普通数组：修改 O(1)，求和 O(n)。
- 前缀和数组：求和 O(1)，修改 O(n)（后面的前缀和都要改）。

两种操作各有 10⁵ 次时都会超时。**树状数组**让两种操作都是 O(log n)。

## 2. lowbit

**lowbit(x) = x & (-x)**，等于 x 的二进制中**最低位的 1** 所代表的值。

| x | 二进制 | lowbit |
| --- | --- | --- |
| 6 | 110 | 2 |
| 8 | 1000 | 8 |
| 12 | 1100 | 4 |
| 7 | 111 | 1 |

为什么 x & (-x) 能做到：负数用补码表示，-x = ~x + 1，最低位的 1 以下全变 0、这一位保持 1、以上全部取反，所以按位与之后只剩这一位。

## 3. 树状数组的结构

定义 **c[x] = a[x - lowbit(x) + 1] + … + a[x]**，即 c[x] 管辖以 x 结尾、长度为 lowbit(x) 的一段。

```
c[1] = a[1]
c[2] = a[1] + a[2]
c[3] = a[3]
c[4] = a[1] + a[2] + a[3] + a[4]
c[5] = a[5]
c[6] = a[5] + a[6]
c[7] = a[7]
c[8] = a[1] + ... + a[8]
```

### 求前缀和 sum(x)

把 [1, x] 拆成若干段：c[x] 管 [x - lowbit(x) + 1, x]，然后跳到 x - lowbit(x) 继续。

sum(7) = c[7] + c[6] + c[4]（7 → 6 → 4 → 0）。

每次去掉最低位的 1，最多 log n 次。

### 单点修改 add(x, k)

a[x] 变了，所有**管辖 x 的** c 都要改。从 x 开始，每次 x += lowbit(x)。

修改 a[3]：c[3]、c[4]、c[8]……（3 → 4 → 8 → 16）。

## 4. 模板

```cpp
int n;
long long c[N];

int lowbit(int x) { return x & -x; }

void add(int x, long long k) {
    for (; x <= n; x += lowbit(x)) c[x] += k;
}

long long sum(int x) {            // a[1] + ... + a[x]
    long long s = 0;
    for (; x > 0; x -= lowbit(x)) s += c[x];
    return s;
}

long long query(int l, int r) { return sum(r) - sum(l - 1); }
```

初始化：对每个 i 调用 add(i, a[i])，O(n log n)。

**代码非常短**，这是树状数组最大的优点。

## 5. 区间修改、单点查询（P3368）

操作变成：给 [l, r] 都加 k；查询 a[x]。

用**差分**：d[i] = a[i] - a[i-1]，a[x] = d[1] + … + d[x]。

- 区间加 → add(l, k)，add(r + 1, -k)
- 单点查询 → sum(x)

树状数组维护差分数组即可。

### 区间修改、区间查询（了解）

维护两个树状数组 d[i] 和 i × d[i]：

a[1] + … + a[x] = (x + 1) × Σd[i] - Σ(i × d[i])

不过区间修改 + 区间查询更常用线段树。

## 6. 求逆序对

从左到右扫描，对每个 a[i]，问"**前面有多少个数比 a[i] 大**"。

用树状数组当"桶"：c 的下标是数值，sum(v) = 前面出现过的 ≤ v 的数的个数。

```cpp
long long ans = 0;
for (int i = 1; i <= n; i++) {
    ans += (i - 1) - sum(a[i]);   // 前面 i-1 个数中，> a[i] 的个数
    add(a[i], 1);
}
```

### 离散化

数值可能到 10⁹，不能直接当下标。但只有 n 个数，**只关心大小关系**，可以把它们映射成 1～n：

```cpp
vector<int> b(a + 1, a + n + 1);
sort(b.begin(), b.end());
b.erase(unique(b.begin(), b.end()), b.end());
for (int i = 1; i <= n; i++)
    a[i] = lower_bound(b.begin(), b.end(), a[i]) - b.begin() + 1;   // 映射到 1..m
```

## 7. 例题：火柴排队（NOIP2013，P1966）

两列火柴高度分别为 a、b，每次可以交换**同一列**中相邻两根，使 Σ(aᵢ - bᵢ)² 最小，求最少交换次数。

1. **贪心**：Σ(aᵢ - bᵢ)² = Σaᵢ² + Σbᵢ² - 2Σaᵢbᵢ，要让 Σaᵢbᵢ 最大。由排序不等式，a 中第 k 小的应该和 b 中第 k 小的配对。
2. 设 a 中第 k 小在位置 p，b 中第 k 小在位置 q，令 pos[p] = q。问题变成：把序列 pos 排成 1, 2, …, n 最少要几次相邻交换 = **pos 的逆序对数**。

## 8. 例题：HH 的项链（P1972）

询问区间 [l, r] 中有多少种不同的数。

**离线**：把询问按 r 排序。从左到右扫描，对每个数只在它**最后一次出现的位置**记 1（之前出现的位置减掉）。扫到 r 时，[l, r] 中 1 的个数就是答案，用树状数组求区间和。

```cpp
// last[v]：数值 v 上次出现的位置
for (int i = 1; i <= n; i++) {
    if (last[a[i]]) add(last[a[i]], -1);
    add(i, 1);
    last[a[i]] = i;
    // 回答所有 r == i 的询问：query(l, i)
}
```

> **离线处理**：把询问按某种顺序排序后统一回答，常常能把在线很难的问题变简单。

## 9. 易错点清单

1. 树状数组下标从 **1** 开始，下标 0 会死循环（lowbit(0) = 0）。
2. 值域树状数组没有离散化，数组开不下。
3. add 时上界写成了数组长度而不是 n（或值域大小）。
4. 逆序对答案溢出 int。
5. 离散化后相等的数映射成了不同的值（要先 unique）。

## 11. 自测

1. lowbit(20) 是多少？
2. sum(13) 依次累加了哪些 c？
3. 为什么下标不能从 0 开始？

<details><summary>答案</summary>

1. 20 = 10100₂，lowbit = 4。
2. c[13]、c[12]、c[8]（13 → 12 → 8 → 0）。
3. lowbit(0) = 0，add 时 x += 0 会死循环。
