## 1. 线性 DP 进阶：编辑距离（P2758）

把字符串 A 变成 B，每次可以删除、插入或替换一个字符，求最少操作数。

1. 状态：f[i][j] = A 的前 i 个变成 B 的前 j 个的最少操作数。
2. 转移（看最后一个字符）：
   - A[i] == B[j]：不用操作，f[i-1][j-1]。
   - 删除 A[i]：f[i-1][j] + 1。
   - 插入 B[j]：f[i][j-1] + 1。
   - 替换 A[i] 为 B[j]：f[i-1][j-1] + 1。
   - 取最小。
3. 初始值：f[i][0] = i（删 i 次），f[0][j] = j（插 j 次）。
4. 答案：f[n][m]。

```cpp
for (int i = 0; i <= n; i++) f[i][0] = i;
for (int j = 0; j <= m; j++) f[0][j] = j;
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
        f[i][j] = min(f[i - 1][j], f[i][j - 1]) + 1;
        f[i][j] = min(f[i][j], f[i - 1][j - 1] + (A[i] != B[j]));
    }
```

### 回文字串（P1435）

最少插入几个字符使字符串变成回文。答案 = n - (s 与 reverse(s) 的 LCS 长度)。不在 LCS 里的字符都需要插入一个对称的字符来配对。

## 2. 多人同时走：方格取数（P1004）

N × N 方格中有数，从左上走到右下（只能向右或向下）走**两次**，取走经过的数（同一格只取一次），求最大和。

**错误思路**：先走一次取最大，再走第二次。两次的贪心不一定最优。

**正确思路**：两个人**同时**出发，每次各走一步。走了 k 步时，两人都在"横纵坐标之和 = k + 2"的斜线上。

1. 状态：f[k][x1][x2] = 走了 k 步，第一人在第 x1 行、第二人在第 x2 行时的最大和（列 = k + 2 - 行）。
2. 转移：两人各自从上或从左来，4 种组合。如果 x1 == x2（同一格），这一格只加一次。
3. 答案：f[2n-2][n][n]。

O(n³)。传纸条（P1006）是同一个模型（"来回"等价于"两个人同时去"，并且不能走同一格）。

> **多个对象同时移动、互相有影响** → 让它们同步走，把它们的位置一起放进状态。

## 3. 区间 DP

### 特征

问题定义在一段区间 [i, j] 上，大区间的答案由**小区间合并**而来。

### 标准写法

1. 状态：f[i][j] = 处理区间 [i, j] 的最优值。
2. 转移：枚举**分割点** k，f[i][j] = min/max(f[i][k] + f[k+1][j] + 合并代价)。
3. **按区间长度从小到大枚举**，保证用到的小区间已经算好。

```cpp
for (int len = 2; len <= n; len++)            // 区间长度
    for (int i = 1; i + len - 1 <= n; i++) {  // 左端点
        int j = i + len - 1;                  // 右端点
        f[i][j] = INF;
        for (int k = i; k < j; k++)           // 分割点
            f[i][j] = min(f[i][j], f[i][k] + f[k + 1][j] + cost(i, j));
    }
```

O(n³)。

### 石子合并（P1880）

n 堆石子排成**一圈**，每次合并**相邻**两堆，代价是两堆之和，求总代价的最小值和最大值。

先看排成一排的情况：f[i][j] = 把 [i, j] 合并成一堆的最小代价。最后一次合并一定是把 [i, k] 和 [k+1, j] 合并，代价是 [i, j] 的总和（用前缀和）：

f[i][j] = min(f[i][k] + f[k+1][j]) + sum(i, j)

**环形**：把数组复制一份接在后面（长度 2n），在这个链上做区间 DP，答案是所有长度为 n 的区间 f[i][i+n-1] 的最值。

> **断环成链**：环形问题把数组复制一倍，是处理环的通用技巧。

> 和合并果子（贪心）的区别：合并果子可以合并**任意**两堆，石子合并只能合并**相邻**的，所以不能贪心。

### 能量项链（P1063）

环形，每颗珠子有头尾标记，合并 (m, r) 和 (r, n) 得到 m × r × n 的能量。和石子合并几乎一样，只是代价变成三个数相乘。

### 涂色（P4170）

一条木板，每次可以把一段连续区间涂成同一种颜色，求涂成目标颜色序列的最少次数。

- f[i][i] = 1。
- 如果 s[i] == s[j]：f[i][j] = min(f[i+1][j], f[i][j-1])（涂 i 的那一次可以顺便延伸到 j）。
- 否则：f[i][j] = min(f[i][k] + f[k+1][j])。

### 关路灯（P1220）

老张从某个位置出发关灯，路灯沿直线排列，每盏灯有功率，求总耗电最少。

关掉的灯一定是一段**连续区间**（路过的灯顺手关掉），而老张一定在区间的**左端或右端**。

f[i][j][0/1] = 关掉 [i, j] 的灯、人在左端/右端时的最少耗电。转移时，走过去的时间 × 还没关的灯的总功率（前缀和）就是这段路程的耗电。

### 矩阵取数游戏（P1005）

每行独立：每次从行首或行尾取一个数，第 k 次取的数乘 2ᵏ。f[i][j] = 剩下 [i, j] 时还能得到的最大分数。答案超过 long long，需要高精度或 `__int128`。

## 4. 易错点清单

1. 区间 DP 不按长度枚举，用到了没算好的状态。
2. 环形问题没有断环成链，或者链长没开 2n。
3. 方格取数中同一格被加了两次。
4. 求最大值时 f 初始化为 0 不对的情况（有负数时）。
5. 区间 DP 数组开 [N][N]，环形时要开 [2N][2N]。

3. 方格取数中，第 k 步两人的位置有什么共同点？
