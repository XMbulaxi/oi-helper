# 拓扑排序与 DAG 上的 DP

> **学完能做到**：在 DAG 上按拓扑序做 DP；判断拓扑序是否唯一；求字典序最小或特殊要求的拓扑序；用建图表达"大于/小于"关系。
> **前置知识**：拓扑排序（普及组）、动态规划。

---

## 1. 为什么 DP 喜欢 DAG

DP 要求状态之间**没有循环依赖**。把状态看成点、"f[v] 依赖 f[u]"看成边 u → v，DP 能做的前提就是这张图是 DAG，计算顺序就是拓扑序。

所以：**在 DAG 上的很多问题，都可以按拓扑序 DP 解决**——最长路、路径计数、最早完成时间……

## 2. DAG 上的最长路：旅行计划（P1137）

n 个城市，道路只从西往东（构成 DAG），对每个城市求以它为终点最多能游览几个城市。

f[v] = max(f[u] + 1)，u → v。按拓扑序计算：

```cpp
for (int i = 1; i <= n; i++) { f[i] = 1; if (indeg[i] == 0) q.push(i); }
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) {
        f[v] = max(f[v], f[u] + 1);
        if (--indeg[v] == 0) q.push(v);
    }
}
```

> 一般图上的最长路是 NP 难问题，但 **DAG 上的最长路是 O(n + m)**。

## 3. 拓扑序是否唯一：排序（P1347）

n 个大写字母，依次给出 m 个关系 A < B。问：在第几个关系后能确定唯一的顺序？或者在第几个关系后发现矛盾？还是全部给出后仍无法确定？

每加入一条关系，重新做一次拓扑排序：

- **有环** → 矛盾。
- 拓扑排序过程中，如果某一时刻**队列里有超过一个点**，说明这两个点的先后不确定 → 顺序不唯一。
- 每一步队列里都恰好一个点，且所有点都排出 → 顺序唯一。

n ≤ 26，每次 O(n + m)，总共 m 次，完全够快。

> **注意判断的优先级**：题目要求矛盾优先于"不确定"，读题时看清楚。

## 4. 建图表达关系：车站分级（NOIP2013 普及组，P1983）

一条铁路有 n 个车站，每个车站有一个级别。每趟车次停靠的车站中，如果一个站停了，那么所有级别 ≥ 它的站（在这趟车的起点和终点之间）都必须停。给出 m 趟车次的停靠情况，求最少要分几个级别。

**建图**：对于每趟车，在它的起止范围内，**没停的站**级别一定**严格低于**停了的站。从每个没停的站向每个停了的站连边（"低 → 高"）。

答案 = 这个 DAG 上的**最长路**（点数），按拓扑序分层求。

**优化**：直接连边是 O(n²) 条每趟车，可能太多。对每趟车建一个**虚拟点**：所有没停的站 → 虚拟点 → 所有停了的站，边数从 a × b 变成 a + b。注意虚拟点不计入层数（可以让边权区分）。

> **"A 一定比 B 大"** → 连边 B → A，问题变成 DAG 上的最长路或拓扑序。

## 5. 特殊要求的拓扑序：菜肴制作（P3243）

n 道菜有若干"i 必须在 j 之前做"的限制。在满足限制的前提下，**1 号菜尽量早做**；然后 2 号菜尽量早做；以此类推。

**错误做法**：用小根堆求字典序最小的拓扑序。反例：限制 3 → 1，菜 2 无限制。字典序最小是 2, 3, 1，但让 1 尽量早是 3, 1, 2。

**正确做法**：**反向建图，用大根堆求字典序最大的拓扑序，再倒过来输出**。

直觉：在反图中，大的编号尽量先出来，倒过来就是大的编号尽量靠后，相当于把小的编号尽量往前挤。

```cpp
// 反图 rg：原来 a 在 b 前，现在连 b → a
priority_queue<int> pq;                 // 大根堆
for (int i = 1; i <= n; i++) if (rindeg[i] == 0) pq.push(i);
vector<int> res;
while (!pq.empty()) {
    int u = pq.top(); pq.pop();
    res.push_back(u);
    for (int v : rg[u]) if (--rindeg[v] == 0) pq.push(v);
}
if ((int)res.size() < n) puts("Impossible!");
else { reverse(res.begin(), res.end()); 输出 res; }
```

这是一道很经典的"直觉贪心是错的"的题目，值得仔细想清楚。

## 6. 拓扑排序的 DFS 写法（了解）

DFS 时，一个点的所有后继都访问完后把它加入列表，最后把列表**反转**就是拓扑序。同时可以判环：DFS 中遇到"正在访问中"的点就是环。

## 7. 易错点清单

1. 有环时没有判断，DP 得到错误结果。
2. 拓扑序不唯一的判断：要看队列中是否**同时**有多个点。
3. 字典序最小 ≠ 让小编号尽量靠前（菜肴制作）。
4. 多组数据时忘记清空入度和图。
5. 建图时连边方向和题意相反。

## 9. 自测

1. 为什么 DP 的状态图必须是 DAG？
2. 怎样判断拓扑序是否唯一？
3. 菜肴制作中，为什么不能直接用小根堆？

<details><summary>答案</summary>

1. 有环说明状态之间循环依赖，找不到合法的计算顺序。
2. 拓扑排序过程中，每一步可选的点（入度为 0 的点）都只有一个。
3. 字典序最小只保证第一个位置尽量小，但题目要求的是 1 号的位置尽量靠前，两者不同，有反例。
