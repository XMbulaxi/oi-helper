# 组合数学

> **学完能做到**：用加法原理、乘法原理计数；用杨辉三角或阶乘逆元求组合数；用卢卡斯定理处理模数较小的组合数；用"正难则反"和容斥原理计数；了解第二类斯特林数。
> **前置知识**：逆元、快速幂。

---

## 1. 两个基本原理

- **加法原理**：完成一件事有几类方法，各类方法数相加。
- **乘法原理**：完成一件事要分几步，各步方法数相乘。

## 2. 排列与组合

- **排列** A(n, m) = n! / (n - m)!：从 n 个中选 m 个**排成一列**（有顺序）。
- **组合** C(n, m) = n! / (m! (n - m)!)：从 n 个中选 m 个（无顺序）。

### 组合数的性质

1. C(n, m) = C(n, n - m)
2. **C(n, m) = C(n-1, m-1) + C(n-1, m)**（第 n 个选或不选）
3. Σ C(n, i) = 2ⁿ

## 3. 求组合数的方法

### 方法一：杨辉三角（n ≤ 几千）

用性质 2 递推：

```cpp
for (int i = 0; i <= n; i++) {
    C[i][0] = 1;
    for (int j = 1; j <= i; j++) C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD;
}
```

O(n²)，模数可以是任意数（不需要是质数）。

### 方法二：阶乘 + 逆元（n ≤ 10⁷，模数是大质数）

预处理 fac[i] = i! 和 ifac[i] = (i!)⁻¹：

```cpp
fac[0] = 1;
for (int i = 1; i <= n; i++) fac[i] = fac[i - 1] * i % MOD;
ifac[n] = power(fac[n], MOD - 2, MOD);
for (int i = n; i >= 1; i--) ifac[i - 1] = ifac[i] * i % MOD;   // 倒推，O(n)

long long C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fac[n] * ifac[m] % MOD * ifac[n - m] % MOD;
}
```

预处理 O(n)，每次查询 O(1)。

### 方法三：卢卡斯定理（模数 p 是较小的质数，n 很大）

**C(n, m) mod p = C(n mod p, m mod p) × C(n / p, m / p) mod p**

```cpp
long long lucas(long long n, long long m, long long p) {
    if (m == 0) return 1;
    return C_small(n % p, m % p, p) * lucas(n / p, m / p, p) % p;
}
// C_small 用阶乘 + 逆元，阶乘预处理到 p - 1
```

**为什么需要**：如果 n ≥ p，n! 里含有因子 p，模 p 等于 0，逆元方法失效。

### 例：卢卡斯定理模板（P3807）

求 C(n + m, n) mod p，p 是质数且不大（≤ 10⁵）。

## 4. 二项式定理

**(a + b)ⁿ = Σ C(n, k) aᵏ bⁿ⁻ᵏ**

### 例：计算系数（NOIP2011，P1313）

求 (ax + by)ᵏ 展开后 xⁿyᵐ 项的系数（n + m = k），对 10007 取模。

由二项式定理，系数 = **C(k, n) × aⁿ × bᵐ**。k ≤ 1000，用杨辉三角或逆元都可以。

## 5. 组合数前缀和：组合数问题（NOIP2016，P2822）

t 组询问，每次给 n、m，问有多少对 (i, j)（0 ≤ i ≤ n，0 ≤ j ≤ min(i, m)）使 C(i, j) 是 k 的倍数。

1. 用杨辉三角求所有 C(i, j) **mod k**（n、m ≤ 2000）。
2. C(i, j) mod k == 0 的记 1，否则记 0。
3. 对这个 0/1 矩阵做**二维前缀和**，每次询问 O(1)。

注意 j > i 的部分不算，前缀和时要处理好（可以把 j > i 的位置当作 0，但前缀和仍要正确延伸）。

## 6. 正难则反：越狱（P3197）

n 个房间，每个关一个犯人，犯人信仰 m 种宗教之一。如果相邻房间的犯人宗教相同就可能越狱，求可能越狱的状态数。

直接数"至少有一对相邻相同"很难。**反过来**：

- 总状态数：mⁿ。
- 没有相邻相同的：第一个 m 种，后面每个只要和前一个不同，各 m - 1 种：m × (m-1)ⁿ⁻¹。
- **答案 = mⁿ - m × (m-1)ⁿ⁻¹**（取模后注意加模数防负数）。

n 到 10¹²，用快速幂。

> **"至少一个"的问题，常常用"总数 - 一个都没有"来算。**

## 7. 容斥原理

|A ∪ B| = |A| + |B| - |A ∩ B|

|A ∪ B ∪ C| = |A| + |B| + |C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|

一般形式：奇数个集合的交加上，偶数个集合的交减去。

例：1～100 中能被 2、3 或 5 整除的数：

50 + 33 + 20 - 16 - 10 - 6 + 3 = 74

## 8. 第二类斯特林数：盒子与球（P1287）

r 个**不同**的球放进 n 个**不同**的盒子，每个盒子至少一个，求方案数。

先考虑盒子**相同**的情况：S(r, n) 叫第二类斯特林数，递推：

**S(r, n) = S(r-1, n-1) + n × S(r-1, n)**

（第 r 个球单独占一个新盒子；或者放进已有的 n 个盒子之一。）

盒子不同，再乘以 n!：答案 = **n! × S(r, n)**。

## 9. 常见计数模型（了解）

| 问题 | 答案 |
| --- | --- |
| n 个相同的球放进 m 个不同的盒子，可以空 | C(n + m - 1, m - 1)（隔板法） |
| 同上，不能空 | C(n - 1, m - 1) |
| n 对括号的合法序列数 | 卡特兰数 C(2n, n) / (n + 1) |
| n 个元素的错排数 | D(n) = (n-1)(D(n-1) + D(n-2)) |

## 10. 易错点清单

1. 逆元法求组合数时模数不是质数，或者 n ≥ p。
2. 减法取模出现负数，加上模数再取模。
3. C(n, m) 中 m > n 或 m < 0 时应返回 0。
4. 组合数直接用阶乘相除（不取模时），中间结果溢出。
5. 快速幂的指数 n 很大时，类型要用 long long。
