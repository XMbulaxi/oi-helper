# 字符串：KMP 与 Trie

> **学完能做到**：用 KMP 在 O(n + m) 时间内做字符串匹配；理解并使用 next 数组（最长相等前后缀）；用 Trie 存储和查询大量字符串；用 01-Trie 求最大异或。
> **前置知识**：字符串、哈希、树。

---

## 1. 字符串匹配

在文本串 S（长度 n）中找模式串 P（长度 m）所有出现的位置。

暴力：对每个起点逐个比较，最坏 O(nm)。

## 2. KMP 的核心：失配时不回头

暴力匹配失败时，S 的指针要退回去。KMP 的想法是：**S 的指针永远不回退**，失配时只移动 P 的指针。

```
S: a b a b a b c
P: a b a b c
           ↑ 第 5 位失配（S 是 a，P 是 c）
已经匹配了 "abab"。它的后缀 "ab" 和前缀 "ab" 相同，
所以 P 可以直接从第 3 位继续比较，前面的 "ab" 已经对上了。
```

### next 数组

**nxt[i] = P 的前 i 个字符组成的子串中，最长的"相等的真前缀和真后缀"的长度。**

```
P    = a b a b c
i    = 1 2 3 4 5
nxt  = 0 0 1 2 0
```

- "a"：0
- "ab"：0
- "aba"："a" = "a"，1
- "abab"："ab" = "ab"，2
- "ababc"：0

失配时，P 的指针跳到 nxt[j]，继续比较。

### 求 next 数组

用 P 自己匹配自己：

```cpp
// P 下标从 1 开始，m = 长度
nxt[1] = 0;
for (int i = 2, j = 0; i <= m; i++) {
    while (j > 0 && P[i] != P[j + 1]) j = nxt[j];
    if (P[i] == P[j + 1]) j++;
    nxt[i] = j;
}
```

### 匹配

```cpp
for (int i = 1, j = 0; i <= n; i++) {
    while (j > 0 && S[i] != P[j + 1]) j = nxt[j];
    if (S[i] == P[j + 1]) j++;
    if (j == m) {
        // 在 S 中以 i 结尾找到一次匹配，起点 i - m + 1
        j = nxt[j];      // 继续找下一个
    }
}
```

**复杂度 O(n + m)**：j 每次最多 +1，而每次 `j = nxt[j]` 至少 -1，所以总的减少次数不超过总的增加次数。

两段代码几乎一模一样——求 nxt 就是"P 匹配 P"。

### 例：KMP 模板（P3375）

输出所有匹配位置，以及 P 的 next 数组。

## 3. next 数组的应用：最小循环节

### Radio Transmission（P4391）

字符串 s 是由某个字符串 t 不断重复得到的（最后一段可以不完整），求 t 的最短长度。

**结论：答案 = n - nxt[n]。**

理解：如果 s 的前缀和后缀有长度为 k 的重叠（k = nxt[n]），那么 s 向右平移 n - k 位后和自己重合，所以 s 有周期 n - k。nxt[n] 最大时周期最小。

## 4. Trie（字典树）

### 结构

把很多字符串存在一棵树上，**公共前缀共用节点**。每条边代表一个字符。

```
插入 "cat"、"car"、"dog"：
        (root)
        /    \
       c      d
       |      |
       a      o
      / \     |
     t   r    g
```

### 代码

```cpp
int tr[N][26], cnt[N], tot = 0;   // tr[u][c]：节点 u 沿字符 c 走到的儿子；0 表示没有

void insert(const string &s) {
    int u = 0;
    for (char ch : s) {
        int c = ch - 'a';
        if (!tr[u][c]) tr[u][c] = ++tot;
        u = tr[u][c];
    }
    cnt[u]++;               // 有一个字符串在这里结束
}

int query(const string &s) {   // s 出现了几次
    int u = 0;
    for (char ch : s) {
        int c = ch - 'a';
        if (!tr[u][c]) return 0;
        u = tr[u][c];
    }
    return cnt[u];
}
```

插入和查询都是 O(字符串长度)。N 是所有字符串的总长度（节点数上限）。

### 前缀计数

如果要问"有多少个字符串**以 s 为前缀**"，在插入时给**路径上每个节点**都 +1（pass[u]++），查询时返回 s 结束节点的 pass 值。

### 例：于是他错误的点名开始了（P2580）

先插入所有名字。每次点名：不存在输出 WRONG；第一次点到输出 OK；重复点到输出 REPEAT。在结束节点上记录"被点过几次"即可。（用 map 也能过，但这是 Trie 的好练习。）

### 例：Secret Message（P2922）

给出若干密码和若干信息（都是 01 串），对每条信息，问有多少个密码和它是"前缀关系"（一个是另一个的前缀）。

插入密码时，路径上每个节点记录 pass（经过它的密码数），结束节点记录 end（在这里结束的密码数）。查询信息时：沿路累加路径上的 end（比信息短、是信息前缀的密码），走到信息末尾时再加上 pass - end（以信息为前缀、比信息长的密码，不重复计算）。

## 5. 01-Trie：最大异或

### 问题

给 n 个数，求两个数异或的最大值。

把每个数看成 31 位二进制串（从高位到低位）插入 Trie。对每个数 x，在 Trie 中**贪心地每一位尽量走和 x 相反的方向**（因为高位为 1 比低位全为 1 都大）。

```cpp
int tr[N * 31][2], tot;

void insert(int x) {
    int u = 0;
    for (int k = 30; k >= 0; k--) {
        int b = x >> k & 1;
        if (!tr[u][b]) tr[u][b] = ++tot;
        u = tr[u][b];
    }
}

int maxXor(int x) {
    int u = 0, res = 0;
    for (int k = 30; k >= 0; k--) {
        int b = x >> k & 1;
        if (tr[u][!b]) { res |= 1 << k; u = tr[u][!b]; }
        else u = tr[u][b];
    }
    return res;
}
```

### 例：最长异或路径（P4551）

树上求一条路径，使边权异或和最大。

结合"让我们异或吧"的结论：路径 u-v 的异或和 = d[u] ⊕ d[v]（d 是根到点的异或和）。问题变成：在 n 个数 d[1..n] 中选两个，异或最大。01-Trie！

## 6. 易错点清单

1. KMP 中字符串下标从 0 还是 1 开始要统一，和 nxt 的定义对应。
2. 匹配成功后忘了 `j = nxt[j]`，漏掉重叠的匹配。
3. Trie 节点数组开小：总长度 × 字符集大小。
4. 01-Trie 位数不够（数到 2³¹ 要 31 位）。
5. 多组数据时 Trie 没有清空（清空时只清用过的节点，不要 memset 整个大数组）。

## 8. 自测

1. "aabaa" 的 next 数组是什么？
2. KMP 为什么是线性的？
3. 01-Trie 求最大异或时为什么从高位开始贪心？

<details><summary>答案</summary>

1. [0, 1, 0, 1, 2]。
2. 主串指针不回退；模式串指针每次最多 +1，每次回跳至少 -1，总回跳次数不超过总前进次数。
3. 二进制中高位的 1 比所有低位加起来都大，所以先保证高位为 1。
