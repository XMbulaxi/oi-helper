## 1. 搜索在提高组的地位

很多 NOIP 题的**部分分**甚至满分都靠搜索。区别在于：普及组的搜索直接写就能过，提高组的搜索要**剪枝**到位，或者用合适的**状态表示**。

## 2. 状态搜索：把"局面"当作点

BFS 不仅能在网格上走。只要能定义"状态"和"一步能变成哪些状态"，就能 BFS 求最少步数。

### 八数码（P1379）

3 × 3 的格子里有 1～8 和一个空格，每次把空格和相邻数字交换，求变成目标状态的最少步数。

- **状态**：9 个数字排成的字符串，如 "283104765"。
- **转移**：空格和上下左右交换。
- **判重**：状态最多 9! = 362880 个，用 `map<string, int>` 或 `unordered_map` 记录步数。

```cpp
string start, goal = "123804765";
unordered_map<string, int> dist;
queue<string> q;
q.push(start); dist[start] = 0;
int dx[4] = {-1, 1, 0, 0}, dy[4] = {0, 0, -1, 1};
while (!q.empty()) {
    string s = q.front(); q.pop();
    if (s == goal) { cout << dist[s]; break; }
    int z = s.find('0'), x = z / 3, y = z % 3;
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (nx < 0 || nx > 2 || ny < 0 || ny > 2) continue;
        string t = s;
        swap(t[z], t[nx * 3 + ny]);
        if (!dist.count(t)) { dist[t] = dist[s] + 1; q.push(t); }
    }
}
```

## 3. 双向 BFS

从起点和终点**同时**开始 BFS，两边相遇时就找到了最短路。

如果每步有 b 种选择、最短距离为 d：单向要搜 bᵈ 个状态，双向只要 2 × b^(d/2)，**指数减半**。

### 字串变换（P1032，洛谷标了“疑似错题”，只看思路）

给出 A、B 和至多 6 条变换规则（把子串 x 换成 y），问 10 步以内能否从 A 变到 B，最少几步。

每步可能的变换很多，单向 BFS 10 层可能状态爆炸。双向 BFS 各搜 5 层：

1. 正向从 A 用规则 x→y 搜，反向从 B 用规则 y→x 搜。
2. 每次扩展**较小**的那一边的一整层。
3. 一边扩展出的状态在另一边出现过，答案 = 两边步数之和。

## 4. 剪枝技巧

### 小木棍（P1120）

一些等长的木棍被砍成小段，给出所有小段长度，求原来木棍的**最小可能长度**。

这是剪枝的经典题。从小到大枚举原长 len（必须是总长的约数），DFS 尝试拼出 sum / len 根：

```cpp
// cnt：已拼好几根；cur：当前这根已有的长度；last：上一段用的下标（只往后选）
bool dfs(int cnt, int cur, int last) {
    if (cnt == total) return true;
    if (cur == len) return dfs(cnt + 1, 0, 0);
    int fail = 0;                                // 上一次失败的长度
    for (int i = last; i < n; i++) {
        if (used[i] || cur + a[i] > len || a[i] == fail) continue;
        used[i] = true;
        if (dfs(cnt, cur + a[i], i + 1)) return true;
        used[i] = false;
        fail = a[i];
        if (cur == 0 || cur + a[i] == len) return false;
    }
    return false;
}
```

用到的剪枝：

1. **搜索顺序**：小段**从大到小排序**，大的先放，更早发现失败。
2. **枚举范围**：len 从最长的小段开始，到总长为止，且必须整除总长。
3. **组合不重复**：同一根木棍内，只选下标更大的（last 参数），避免同一组合的不同顺序。
4. **等长跳过**：同样长度的小段失败了一次，下一个同样长的也会失败（fail 变量）。
5. **最关键的剪枝**：如果当前这根是**空的**（cur == 0）放第一段就失败了，说明这一段放在哪根都不行，整个方案失败。如果放入后**正好填满**（cur + a[i] == len）却失败了，换更小的段来凑也不会更好，直接失败。

### 靶形数独（P1074）

填数独并使得分最大。**优化搜索顺序**：优先填**空格最少的行**（可选项少的先填，分支少）。用位运算记录每行、每列、每宫已用的数字，快速得到可选集合。

### 剪枝分类总结

| 剪枝 | 说明 |
| --- | --- |
| 可行性剪枝 | 当前状态已经不可能满足要求，返回 |
| 最优性剪枝 | 当前代价 + 最少还需的代价 ≥ 已知最优，返回 |
| 搜索顺序 | 先搜分支少、更可能出解或更容易失败的 |
| 排除等效 | 不同顺序得到同一结果，只搜一种 |
| 记忆化 | 同一状态只搜一次 |

## 5. 迭代加深（IDDFS）

答案深度很浅，但搜索树很宽，BFS 内存不够、DFS 可能陷入很深的错误分支。

**迭代加深**：限制深度为 1 搜一遍，不行就限制为 2 再搜……第一次搜到解时深度就是最优的。

看起来重复搜了很多次，但因为每层节点数是指数增长的，前面所有层加起来也没有最后一层多，总代价只多一个常数倍。

## 6. 估价函数与 A*（了解）

给每个状态一个估价 h(s)："从 s 到终点**至少**还要几步"。

- **IDA***：迭代加深 + 当前深度 + h(s) > 限制时剪掉。
- **A***：BFS 中按"已走步数 + h(s)"从小到大扩展（用优先队列）。

h 必须**不超过真实值**才能保证正确。八数码中，h 可以取"每个数字到目标位置的曼哈顿距离之和"。

## 7. 例题：虫食算（P1092）

N 进制加法竖式，每个字母代表一个不同的数字，求一种合法的对应。

从**最低位**开始搜（进位确定），按字母在竖式中从右往左**首次出现的顺序**确定搜索顺序。剪枝：每填一个字母，检查所有**三个字母都已确定**的列，(a + b) mod N 必须等于 c 或 (c - 1)（考虑进位的两种可能）。

## 8. 易错点清单

1. BFS 状态判重的数据结构太慢（`map<string,...>` 可以改成康托展开或哈希）。
2. 双向 BFS 没有"一次扩展一整层"，导致步数算错。
3. 剪枝条件写错把正解剪掉，先不加剪枝验证正确性，再一个个加。
4. 迭代加深忘记限制深度。
