# 排序入门

> **学完能做到**：熟练使用 `sort`；理解冒泡、选择、计数排序；去重；多关键字排序；知道什么时候排序能让问题变简单。
> **前置知识**：数组、函数与结构体。

## 1. 为什么排序这么重要

排好序之后，很多问题会变得简单：最大最小值在两头、相同的数挨在一起、可以用二分查找……"先排个序"是 OI 里最常见的第一步。

## 2. 用 sort（考试首选）

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[100005];

int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    sort(a + 1, a + n + 1);                      // 下标 1..n 从小到大
    // sort(a + 1, a + n + 1, greater<int>());   // 从大到小
    for (int i = 1; i <= n; i++) cout << a[i] << " ";
}
```

- `sort(起点, 终点)`：排序范围是 **[起点, 终点)**，左闭右开。下标 1～n 就写 `a + 1, a + n + 1`；下标 0～n-1 写 `a, a + n`。
- 时间复杂度 O(n log n)，10⁶ 个数也只要零点几秒。
- 对 `vector` 用 `sort(v.begin(), v.end())`；对 `string` 也行，会把字符排序。

## 3. 理解排序原理

考试直接用 `sort`，但理解原理有助于解题（比如求交换次数）。

### 冒泡排序

每一轮从左到右比较相邻两个数，前面大就交换。这样一轮下来，最大的数会"冒"到最后。

```cpp
for (int i = 1; i < n; i++)             // 共 n-1 轮
    for (int j = 1; j <= n - i; j++)    // 后面 i-1 个已经排好
        if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);
```

手推 `[3, 1, 2]`：

- 第 1 轮：3>1 交换 → `[1,3,2]`；3>2 交换 → `[1,2,3]`
- 第 2 轮：1<2 不换。完成。

复杂度 O(n²)。**重要性质**：冒泡排序交换的总次数 = 序列中**逆序对**的个数（i < j 但 a[i] > a[j] 的对数）。

### 选择排序

每轮选出剩下的最小值，放到前面。O(n²)。

### 计数排序（桶排序）

数值范围小（比如 0～1000）时，数每个值出现几次，再按值从小到大输出。O(n + 值域)，比 `sort` 还快。

```cpp
int cnt[1005];
for (int i = 1; i <= n; i++) cnt[a[i]]++;
for (int v = 0; v <= 1000; v++)
    while (cnt[v]--) cout << v << " ";
```

## 4. 去重

排序后相同的数挨在一起，用 `unique` 把重复的挪到后面：

```cpp
sort(a + 1, a + n + 1);
int m = unique(a + 1, a + n + 1) - (a + 1);   // 去重后剩 m 个，在 a[1..m]
```

`unique` 只去掉**相邻**的重复，所以一定要先排序。

## 5. 结构体与多关键字排序

题目常这样要求：先按总分从高到低；总分相同按语文从高到低；再相同按学号从小到大。

```cpp
struct Stu { int id, chinese, math, english, total; };
Stu s[305];

bool cmp(const Stu &a, const Stu &b) {
    if (a.total != b.total) return a.total > b.total;
    if (a.chinese != b.chinese) return a.chinese > b.chinese;
    return a.id < b.id;
}
sort(s + 1, s + n + 1, cmp);
```

**套路**：一层一层比，前面的关键字不同就直接返回；全部相同的最后一层要能分出先后（或者返回 false）。

### Lambda 写法（了解）

```cpp
sort(s + 1, s + n + 1, [](const Stu &a, const Stu &b) {
    return a.total > b.total;
});
```

## 6. 特殊的比较规则

### 拼数（P1012）

n 个正整数拼成一个最大的数。直觉是按字典序从大到小，但 `"3"` 和 `"30"`：拼成 `330` 比 `303` 大，所以 `3` 应该在前，而字典序是 `"30" > "3"`。

**正确的比较**：把 a 和 b 当字符串，比较 `a + b` 和 `b + a`：

```cpp
bool cmp(const string &a, const string &b) {
    return a + b > b + a;
}
```

### 大数比较（P1781 宇宙总统）

票数可能有 100 位，存成字符串。比较时**先比长度**，长度相同再比字典序：

```cpp
bool bigger(const string &a, const string &b) {
    if (a.size() != b.size()) return a.size() > b.size();
    return a > b;
}
```

## 7. 例题精讲：分数线划定（P1068）

n 名选手，计划录取 m 人，面试分数线是第 ⌊m × 1.5⌋ 名的分数，所有分数 ≥ 分数线的人都进面试。按分数从高到低（相同按报名号从小到大）输出。

```cpp
sort(p + 1, p + n + 1, cmp);       // 分数降序，报名号升序
int k = m * 3 / 2;                 // 用整数算 1.5 倍，避免小数
int line = p[k].score;
int cnt = 0;
for (int i = 1; i <= n; i++) if (p[i].score >= line) cnt++;
cout << line << " " << cnt << endl;
for (int i = 1; i <= cnt; i++) cout << p[i].id << " " << p[i].score << endl;
```

## 8. 易错点清单

1. 排序范围写错（0 开始还是 1 开始）。
2. 比较函数用了 `>=` 或 `<=`。
3. `unique` 前没排序。
4. 数据量大（10⁵ 以上）还用冒泡排序，超时。
5. 用字符串存的数字直接比较字典序（`"9" > "10"`）。

## 10. 自测

1. 要对 `a[0]` 到 `a[n-1]` 排序，怎么写？
2. `[2, 3, 1]` 的逆序对有几个？
3. 为什么 `"30"` 和 `"3"` 不能直接按字典序比较来拼数？

<details><summary>答案</summary>

1. `sort(a, a + n);`
2. 2 个：(2,1)、(3,1)。
3. 字典序认为 `"30" > "3"`，但 `"330" > "303"`，`"3"` 应该在前。
