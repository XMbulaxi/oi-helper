# 排序入门

## 用 sort

```cpp
int a[100005];
sort(a + 1, a + n + 1);                 // 下标 1..n 从小到大
sort(a + 1, a + n + 1, greater<int>()); // 从大到小
```

`sort` 的速度是 O(n log n)，10⁶ 个数也能很快排完。考试和做题时直接用它。

## 自己写排序（理解原理）

冒泡排序，每轮把最大的"冒"到最后：

```cpp
for (int i = 1; i < n; i++)
    for (int j = 1; j <= n - i; j++)
        if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);
```

它是 O(n²) 的，数据大时会超时，但它交换的次数等于"逆序对"个数（P1116 车厢重组就考这个）。

## 去重

```cpp
sort(a + 1, a + n + 1);
int m = unique(a + 1, a + n + 1) - (a + 1);  // 去重后剩 m 个
```

## 多关键字排序

先按总分，再按语文，再按学号……写在 `cmp` 里，一层一层比较（见"函数与结构体"一课）。

## 特殊的比较：拼数

P1012 要把数字拼成最大的数，比较方式是：`a + b > b + a`（把数字当字符串拼起来比）。

## 常见错误

1. 排序范围写错：`sort(a, a + n)` 对应下标 0..n-1，`sort(a + 1, a + n + 1)` 对应 1..n。
2. 大数据用了冒泡排序导致超时。
