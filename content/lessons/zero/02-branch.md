# 分支结构：if 和 switch

程序根据条件选择走哪条路。

## if 的写法

```cpp
if (score >= 90) {
    cout << "优秀";
} else if (score >= 60) {
    cout << "及格";
} else {
    cout << "不及格";
}
```

## 条件怎么写

- 等于是 `==`，**一个 `=` 是赋值**。`if (a = 1)` 永远成立，这是最常见的 bug。
- 并且是 `&&`，或者是 `||`，取反是 `!`。
- 判断闰年：`(y % 4 == 0 && y % 100 != 0) || y % 400 == 0`。

## switch

适合对一个整数的多种取值分别处理，例如月份天数：

```cpp
switch (m) {
    case 2: days = leap ? 29 : 28; break;
    case 4: case 6: case 9: case 11: days = 30; break;
    default: days = 31;
}
```

别忘了每个 `case` 后面的 `break`。

## 三个数排序的小技巧

```cpp
if (a > b) swap(a, b);
if (a > c) swap(a, c);
if (b > c) swap(b, c);   // 现在 a <= b <= c
```

## 常见错误

1. 把 `==` 写成 `=`。
2. 判断条件有遗漏，比如等号情况没考虑（`>` 和 `>=` 要看清题意）。
3. `else` 跟错了 `if`。养成**总是写大括号**的习惯。
