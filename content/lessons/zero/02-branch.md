# 分支结构：if 和 switch

> **学完能做到**：让程序根据不同情况做不同的事；写对各种条件判断。
> **前置知识**：顺序结构。

---

## 1. 为什么需要分支

很多题的答案"看情况"：成绩大于等于 60 输出及格，否则输出不及格；是闰年 2 月有 29 天，否则 28 天。这就需要**分支结构**。

## 2. if 语句

### 最基本的形式

```cpp
if (条件) {
    条件成立时执行
} else {
    条件不成立时执行
}
```

### 多个分支

```cpp
if (score >= 90) {
    cout << "A";
} else if (score >= 80) {
    cout << "B";
} else if (score >= 60) {
    cout << "C";
} else {
    cout << "D";
}
```

程序从上往下检查，**遇到第一个成立的条件就执行它，后面的都不看了**。所以 `score = 95` 只会输出 `A`，虽然它也满足 `>= 80`。

## 3. 怎么写条件

### 比较运算符

| 写法 | 含义 |
| --- | --- |
| `a == b` | 等于（**两个等号**） |
| `a != b` | 不等于 |
| `a > b`、`a >= b` | 大于、大于等于 |
| `a < b`、`a <= b` | 小于、小于等于 |

> ⚠️ **最常见的错误**：把 `==` 写成 `=`。`if (a = 1)` 的意思是"把 1 赋给 a"，结果永远为真。

### 逻辑运算符

| 写法 | 含义 | 例子 |
| --- | --- | --- |
| `&&` | 并且（两个都成立） | `x >= 1 && x <= 10` 表示 1 ≤ x ≤ 10 |
| `\|\|` | 或者（至少一个成立） | `c == 'a' \|\| c == 'A'` |
| `!` | 取反 | `!found` 表示没找到 |

> ⚠️ 数学里写 `1 ≤ x ≤ 10`，C++ **不能**写成 `1 <= x <= 10`，必须拆成 `1 <= x && x <= 10`。

### 判断闰年（必背）

闰年规则：能被 4 整除但不能被 100 整除，**或者**能被 400 整除。

```cpp
bool leap = (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
```

手推验证：2000 年（能被 400 整除）是闰年；1900 年（能被 100 整除但不能被 400 整除）不是；2024 年是。

## 4. switch 语句

当要根据一个**整数或字符**的不同取值做不同的事时，`switch` 更清楚：

```cpp
switch (month) {
    case 1: case 3: case 5: case 7: case 8: case 10: case 12:
        days = 31;
        break;
    case 4: case 6: case 9: case 11:
        days = 30;
        break;
    case 2:
        days = leap ? 29 : 28;
        break;
}
```

- 每个 `case` 后面通常要有 `break;`，否则会"掉"到下一个 case 继续执行。
- 多个 case 写在一起表示"这几种情况做同样的事"。

### 三目运算符

`条件 ? 值1 : 值2`：条件成立取值1，否则取值2。适合简单的二选一：

```cpp
int mx = (a > b) ? a : b;
```

## 5. 常用技巧

### 三个数排序

```cpp
if (a > b) swap(a, b);   // 现在 a <= b
if (a > c) swap(a, c);   // 现在 a 是最小的
if (b > c) swap(b, c);   // 现在 a <= b <= c
```

### 找最大值

```cpp
int mx = a;
if (b > mx) mx = b;
if (c > mx) mx = c;
// 或者直接 max({a, b, c})
```

### 比较小数

小数在计算机里有误差，`0.1 + 0.2 == 0.3` 可能是 false。比较小数时用一个很小的数 eps：

```cpp
const double eps = 1e-9;
if (fabs(x - y) < eps) { /* 认为相等 */ }
```

## 6. 例题精讲：买铅笔（P1909）

题意：需要 n 支铅笔，有三种包装，每种包装有支数和价格，只能买**同一种**包装，问最少花多少钱。

**思路**：分别算三种包装各需要多少钱，取最小。每种需要买 ⌈n / 每包支数⌉ 包。

```cpp
int n;
cin >> n;
int ans = INT_MAX;               // 一开始设成很大的数
for (int i = 0; i < 3; i++) {
    int cnt, price;
    cin >> cnt >> price;
    int packs = (n + cnt - 1) / cnt;   // 向上取整
    ans = min(ans, packs * price);
}
cout << ans << endl;
```

（这里提前用了 `for` 循环，下一课会讲。也可以写三遍。）

## 7. 例题精讲：ISBN 号码（P1055）

格式 `x-xxx-xxxxx-x`，前 9 个数字分别乘 1～9 求和，再模 11 得到识别码，余数为 10 时识别码是 `X`。

要点：

1. 读入一个字符串，跳过 `-`，取出前 9 个数字：字符转数字用 `c - '0'`。
2. 算出正确的识别码字符 `right`（10 对应 `'X'`）。
3. 和最后一个字符比较：相同输出 `Right`，否则把最后一位改成 `right` 再输出。

## 8. 易错点清单

1. `=` 和 `==` 混淆。
2. 边界：">= 60" 和 "> 60" 差一个等号，题目说"不低于"就是 `>=`。
3. 条件顺序：`else if` 链要从严格到宽松（或从大到小）排列。
4. **一律写大括号**。下面这段代码的 `else` 其实跟的是第二个 `if`：

```cpp
if (a > 0)
    if (b > 0) cout << 1;
else cout << 2;   // 看起来跟第一个 if，实际跟第二个
```

## 10. 自测

1. `if (x = 0) cout << "zero";` 有什么问题？
2. 写出"x 是两位数"的条件。
3. 1900 年是闰年吗？

<details><summary>答案</summary>

1. 把 `==` 写成了 `=`，条件变成赋值，结果为 0（假），永远不会输出。
2. `x >= 10 && x <= 99`（若可能是负数还要考虑 `-99 <= x && x <= -10`）。
