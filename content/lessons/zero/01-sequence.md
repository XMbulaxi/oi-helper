# 顺序结构：输入、输出和计算

> **学完能做到**：写出一个完整的 C++ 程序，读入数据，做加减乘除，按题目要求的格式输出。
> **前置知识**：无。会开机、会打字就行。

---

## 1. 程序是什么

程序就是一份写给计算机的"做事清单"。计算机会**从上往下、一行一行**地执行，这叫**顺序结构**。

做 OI 题时，每道题都是同一个套路：

1. **读入**题目给的数据（输入）
2. **计算**出答案
3. **输出**答案

评测机会准备很多组输入，把你的输出和标准答案逐字比较。完全一样才算对（AC）。

## 2. 第一个程序：A+B

```cpp
#include <bits/stdc++.h>   // 万能头文件：把常用的工具一次全部引进来
using namespace std;       // 让我们可以直接写 cin、cout，而不用写 std::cin

int main() {               // 程序从 main 开始执行
    int a, b;              // 准备两个"盒子"，用来装整数
    cin >> a >> b;         // 从输入里读两个整数，分别放进 a 和 b
    cout << a + b << endl; // 输出 a+b，然后换行
    return 0;              // 告诉系统：程序正常结束
}
```

逐行理解：

- `#include <bits/stdc++.h>`：竞赛里几乎都这样写，省去记各种头文件。
- `int main() { ... }`：大括号里的内容就是程序要做的事。
- `;`：每条语句结尾都要有分号，**最容易忘**。
- `cin >>`：箭头指向变量，表示"数据流进变量"。
- `cout <<`：箭头指向 cout，表示"数据流向屏幕"。

## 3. 变量与类型

变量就是一个有名字的盒子。不同的盒子装不同的东西：

| 类型 | 装什么 | 范围（大约） | 例子 |
| --- | --- | --- | --- |
| `int` | 整数 | -2.1×10⁹ ～ 2.1×10⁹ | 人数、分数 |
| `long long` | 大整数 | -9.2×10¹⁸ ～ 9.2×10¹⁸ | 很大的乘积、累加和 |
| `double` | 小数 | 有效数字约 15 位 | 面积、平均分 |
| `char` | 一个字符 | 一个字母或符号 | `'A'`、`'7'` |
| `bool` | 真或假 | `true` / `false` | 是否找到 |

**什么时候用 long long？** 先看题目的数据范围。如果答案可能超过 20 亿（比如两个 10⁵ 的数相乘是 10¹⁰），就用 `long long`。拿不准时用 `long long` 一般不会错。

**溢出是什么？** `int` 装不下时，数字会"绕一圈"变成奇怪的负数。例如：

```cpp
int x = 2000000000;
x = x * 2;        // 结果不是 40 亿，而是一个负数！
long long y = 2000000000;
y = y * 2;        // 正确：4000000000
```

## 4. 算术运算

| 运算 | 写法 | 例子 | 结果 |
| --- | --- | --- | --- |
| 加减乘 | `+ - *` | `3 * 4` | `12` |
| 除 | `/` | `7 / 2` | `3`（整数相除，小数部分直接扔掉） |
| 除（小数） | `/` | `7.0 / 2` | `3.5` |
| 取余 | `%` | `7 % 2` | `1` |

### 整数除法的坑

两个**整数**相除，结果还是整数，小数部分被**直接舍去**（不是四舍五入）。想得到小数，至少让一个数是小数：

```cpp
int a = 7, b = 2;
cout << a / b;              // 3
cout << (double)a / b;      // 3.5   把 a 临时当作小数
cout << a * 1.0 / b;        // 3.5   乘 1.0 也行
```

### 取余的妙用

`%` 求的是余数，在 OI 里特别常用：

- `n % 10`：取 n 的**个位**数字
- `n / 10`：**去掉**个位
- `n % 2 == 0`：判断偶数

例：把三位数 `n = 365` 拆开：

```cpp
int bai = n / 100;      // 3
int shi = n / 10 % 10;  // 6
int ge  = n % 10;       // 5
```

### 向上取整

买东西"每包 k 个，要 n 个，至少买几包"：答案是 ⌈n/k⌉。整数写法：

```cpp
int packs = (n + k - 1) / k;
```

## 5. 输出格式

### 保留小数

```cpp
double x = 3.14159;
printf("%.2f\n", x);   // 3.14  保留两位，会四舍五入
cout << fixed << setprecision(2) << x << endl;  // 同样效果
```

`printf` 的格式符：`%d` 整数、`%lld` long long、`%f` 小数、`%c` 字符、`%s` 字符串。

### 空格和换行

- 题目要求"空格隔开"，就输出 `cout << a << " " << b;`
- 一般最后要换行：`endl` 或 `"\n"`。

## 7. 例题精讲：小鱼的游泳时间（P1425）

题意：给出开始时刻 a 时 b 分，结束时刻 c 时 d 分（同一天），问游了多少小时多少分钟。

**思路**：时间有"进位"（60 分钟进 1 小时），直接相减很麻烦。**把时刻都换成"从 0 点开始的分钟数"**，相减后再换回来：

```cpp
int a, b, c, d;
cin >> a >> b >> c >> d;
int start = a * 60 + b;
int end = c * 60 + d;
int t = end - start;
cout << t / 60 << " " << t % 60 << endl;
```

> 这种"**统一单位再计算**"的想法以后会反复用到：时间换成秒，钱换成分，日期换成天数。

## 8. 易错点清单

1. **分号**：每条语句后都要有。
2. **多余输出**：不要输出"请输入"、"答案是"之类的提示文字。
3. **整数除法**：要小数时别忘了 `1.0 *`。
4. **溢出**：答案大就用 `long long`，而且乘法之前就要是 `long long`：`(long long)a * b`。
5. **中文标点**：代码里的符号必须是英文半角（`;` 不是 `；`，`"` 不是 `”`）。
