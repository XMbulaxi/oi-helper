# 顺序结构：输入、输出和计算

程序从上往下一行一行执行，这就是"顺序结构"。这一单元学会：读入数据、做计算、按格式输出。

## 第一个程序

```cpp
#include <bits/stdc++.h>   // 万能头文件，竞赛里常用
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;          // 读入两个整数
    cout << a + b << endl;  // 输出它们的和
    return 0;
}
```

## 变量类型怎么选

| 类型 | 能存什么 | 范围（大约） |
| --- | --- | --- |
| `int` | 整数 | ±2.1×10⁹ |
| `long long` | 大整数 | ±9.2×10¹⁸ |
| `double` | 小数 | 有效数字约 15 位 |
| `char` | 一个字符 | 如 `'a'` |

**经验：** 题目里数字可能超过 20 亿，或者两个大数相乘，就用 `long long`。

## 运算要点

- 整数相除会**直接舍去小数**：`7 / 2` 等于 `3`。要得到 `3.5`，写成 `7.0 / 2`。
- `%` 是取余：`7 % 2` 等于 `1`。常用来取个位：`n % 10`。
- 保留小数输出：`printf("%.2f\n", x);` 保留两位。

## 常见错误

1. 输出多了空格、少了换行，或者多输出了"请输入"之类的提示文字。评测只比对答案，**不要输出任何多余内容**。
2. 忘记 `return 0;`，或者 `main` 写成 `void main`。
3. 小数题用了 `int`，结果被截断。
