# 递推与递归

## 递推：用前面的答案推出后面的

斐波那契数列：`f[i] = f[i-1] + f[i-2]`。

```cpp
f[1] = f[2] = 1;
for (int i = 3; i <= n; i++) f[i] = f[i - 1] + f[i - 2];
```

想递推，关键是找到"**第 i 个答案和前面答案的关系**"。

**过河卒（P1002）：** 走到 (i, j) 的方法数 = 从上面来的 + 从左边来的，即 `f[i][j] = f[i-1][j] + f[i][j-1]`，被马控制的点设为 0。注意答案很大，要用 `long long`。

## 递归：自己调用自己

写递归要想清楚两件事：

1. **出口**：最简单的情况直接返回答案。
2. **怎么把大问题变小**。

## 用递归枚举：搜索的雏形

输出 1～n 的全排列：

```cpp
int n, a[15];
bool used[15];

void dfs(int k) {            // 正在填第 k 个位置
    if (k > n) {             // 填完了，输出
        for (int i = 1; i <= n; i++) cout << setw(5) << a[i];
        cout << "\n";
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (!used[i]) {
            used[i] = true; a[k] = i;
            dfs(k + 1);
            used[i] = false;  // 回溯：恢复现场
        }
    }
}
```

"选一个、递归下去、再撤销"叫**回溯**，是之后学搜索的基础。

## 记忆化

P1464 Function 如果直接递归会重复计算很多次。把算过的结果存起来，下次直接用：

```cpp
if (mem[a][b][c]) return mem[a][b][c];
```

## 常见错误

1. 递归没有出口，或出口条件写错，导致无限递归、栈溢出。
2. 回溯时忘记恢复 `used` 数组。
3. 答案太大，`int` 溢出。
