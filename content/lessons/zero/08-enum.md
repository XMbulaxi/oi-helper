# 暴力枚举

把所有可能的答案都试一遍，找出符合要求的。数据小的时候，这往往是最稳的方法。

## 基本思路

1. 确定要枚举**什么**（枚举答案？枚举某个参数？）。
2. 确定枚举的**范围**。
3. 对每种情况**判断**是否满足条件。

## 例子：三连击

把 1～9 分成三个三位数，比例为 1:2:3。只需要枚举第一个数（123～329），算出另外两个，再检查 9 个数字是否恰好各用一次：

```cpp
for (int a = 123; a <= 329; a++) {
    int b = a * 2, c = a * 3;
    int cnt[10] = {0};
    // 把 a, b, c 的每一位放进 cnt，检查 1~9 各出现一次
}
```

## 估算会不会超时

计算机一秒大约能做 **10⁸** 次简单运算。

- 一层循环到 10⁶：没问题。
- 两层循环各到 10⁴（共 10⁸）：勉强。
- 三层循环各到 1000（共 10⁹）：会超时。

**减少枚举量的办法：** 能算出来的量就别枚举（如上面的 b 和 c），利用题目条件缩小范围。

## 常见错误

1. 枚举范围漏了边界。
2. 枚举量太大导致超时，没先估算。
