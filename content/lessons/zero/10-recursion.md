## 1. 递推：用小的答案推出大的答案

很多问题，第 n 个的答案可以由前面几个答案算出来。找到这个关系，就能从小到大一个个算。

### 斐波那契数列

f(1) = f(2) = 1，f(n) = f(n-1) + f(n-2)。

```cpp
long long f[100];
f[1] = f[2] = 1;
for (int i = 3; i <= n; i++) f[i] = f[i - 1] + f[i - 2];
```

### 爬楼梯

每次走 1 级或 2 级，走到第 n 级有几种方法？

**想最后一步**：到第 n 级，最后一步要么从 n-1 级走 1 步，要么从 n-2 级走 2 步。所以 ways(n) = ways(n-1) + ways(n-2)。又是斐波那契！

> **找递推关系的诀窍：想"最后一步"是怎么来的。**

## 2. 例题精讲：过河卒（P1002）

卒从 (0, 0) 走到 (n, m)，只能向下或向右，马的位置和它能一步跳到的 8 个点不能走。问有几条路径。

**最后一步**：到 (i, j) 要么从上面 (i-1, j) 下来，要么从左边 (i, j-1) 过来。

f[i][j] = f[i-1][j] + f[i][j-1]，被马控制的点 f = 0。

```cpp
long long f[25][25];
bool ban[25][25];
int dx[9] = {0, 1, 2, 2, 1, -1, -2, -2, -1};
int dy[9] = {0, 2, 1, -1, -2, -2, -1, 1, 2};

int main() {
    int n, m, hx, hy;
    cin >> n >> m >> hx >> hy;
    for (int k = 0; k < 9; k++) {
        int x = hx + dx[k], y = hy + dy[k];
        if (x >= 0 && x <= n && y >= 0 && y <= m) ban[x][y] = true;
    }
    f[0][0] = 1;
    for (int i = 0; i <= n; i++)
        for (int j = 0; j <= m; j++) {
            if (ban[i][j]) { f[i][j] = 0; continue; }
            if (i > 0) f[i][j] += f[i - 1][j];
            if (j > 0) f[i][j] += f[i][j - 1];
        }
    cout << f[n][m];
}
```

注意：

- 答案很大，必须 `long long`。
- 边界：第 0 行、第 0 列只有一个方向能来，用 `if (i > 0)` 处理。
- 起点本身被马控制时答案是 0，上面的写法会自动处理（先设 1 再被置 0）。

## 3. 递归：自己调用自己

递归把大问题变成**同样形式的**小问题。写递归时要想清楚：

1. **函数的含义**：f(x) 返回什么？
2. **出口**：最简单的情况直接返回。
3. **递归关系**：f(x) 怎么用更小的 f 表示？

### 例：数的计算（P1028）

给 n，在它左边加一个不超过它一半的数，新数还可以继续加，问能得到多少个数（包括 n 自己）。

设 f(n) 是答案。左边可以加 1～n/2 中的任意一个 k，加了 k 之后的方案数就是 f(k)。所以：

f(n) = 1 + f(1) + f(2) + … + f(n/2)

用递推写（从小到大算）：

```cpp
f[1] = 1;
for (int i = 2; i <= n; i++) {
    f[i] = 1;
    for (int k = 1; k <= i / 2; k++) f[i] += f[k];
}
```

## 4. 回溯：用递归来枚举

### 全排列（P1706）

输出 1～n 的所有排列。想象有 n 个空位，从第 1 个位置开始依次填数：

```cpp
int n, a[15];
bool used[15];

void dfs(int k) {                  // 正在填第 k 个位置
    if (k > n) {                   // 全部填完，输出
        for (int i = 1; i <= n; i++) printf("%5d", a[i]);
        printf("\n");
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (used[i]) continue;     // 已经用过的数不能再用
        used[i] = true;            // 做选择
        a[k] = i;
        dfs(k + 1);                // 递归填下一个位置
        used[i] = false;           // 撤销选择（回溯）
    }
}
```

n = 3 的搜索过程（树）：

```
            (空)
      /      |      \
     1       2       3
    / \     / \     / \
   2   3   1   3   1   2
   |   |   |   |   |   |
   3   2   3   1   2   1
```

每条从上到下的路径就是一个排列。

**"做选择 → 递归 → 撤销选择"** 叫回溯，是之后所有搜索的基础。

### 组合（P1157）

从 1～n 中选 r 个数，按字典序输出所有组合。和排列的区别是**不考虑顺序**，所以让选出的数递增：下一个数从上一个数 +1 开始选。

```cpp
void dfs(int k, int start) {       // 正在选第 k 个，可以从 start 开始选
    if (k > r) { 输出 a[1..r]; return; }
    for (int i = start; i <= n; i++) {
        a[k] = i;
        dfs(k + 1, i + 1);
    }
}
// 调用 dfs(1, 1)
```

这里不需要 `used` 数组，因为递增保证了不重复。

### 选或不选（P1036 选数）

n 个数里选 k 个，和为质数的方案有几种。对每个数决定"选"或"不选"：

```cpp
void dfs(int i, int chosen, int sum) {   // 考虑第 i 个数
    if (chosen == k) { if (isPrime(sum)) ans++; return; }
    if (i > n) return;
    dfs(i + 1, chosen + 1, sum + x[i]);  // 选
    dfs(i + 1, chosen, sum);             // 不选
}
```

## 5. 记忆化：别重复算

### Function（P1464）

题目给出一个三元递归函数 w(a, b, c)。直接按定义递归，同一个 w(a, b, c) 会被算很多很多次，超时。

**记忆化**：算过的结果存进数组，下次直接取：

```cpp
long long mem[25][25][25];
bool vis[25][25][25];

long long w(long long a, long long b, long long c) {
    if (a <= 0 || b <= 0 || c <= 0) return 1;
    if (a > 20 || b > 20 || c > 20) return w(20, 20, 20);
    if (vis[a][b][c]) return mem[a][b][c];      // 算过了
    long long res;
    if (a < b && b < c) res = w(a, b, c - 1) + w(a, b - 1, c - 1) - w(a, b - 1, c);
    else res = w(a - 1, b, c) + w(a - 1, b - 1, c) + w(a - 1, b, c - 1) - w(a - 1, b - 1, c - 1);
    vis[a][b][c] = true;
    return mem[a][b][c] = res;
}
```

> 记忆化搜索 = 递归 + 记录结果。它和递推本质相同，只是计算顺序由递归自动决定。普及组的动态规划会大量用到。

## 6. 递归处理嵌套结构：外星密码（P1928）

`[3AB]` 表示 `ABABAB`，可以嵌套：`AC[3FUN[2Y]]`。

遇到 `[` 就递归处理里面的内容，遇到 `]` 就返回：

```cpp
string s; int pos = 0;

string parse() {                    // 从 pos 开始解析，直到 ']' 或结尾
    string res;
    while (pos < (int)s.size() && s[pos] != ']') {
        if (s[pos] == '[') {
            pos++;                  // 跳过 '['
            int k = 0;
            while (isdigit(s[pos])) k = k * 10 + (s[pos++] - '0');
            string inner = parse();
            pos++;                  // 跳过 ']'
            while (k--) res += inner;
        } else {
            res += s[pos++];
        }
    }
    return res;
}
```

## 7. 易错点清单

1. 递归没出口或出口错，导致无限递归、栈溢出。
2. 回溯时忘了撤销 `used`。
3. 答案大但用了 `int`。
4. 递推的边界（第 0 行、第 0 列、f[1]）没设好。
5. 没有记忆化，同样的状态被反复计算导致超时。

## 9. 自测

1. 走楼梯每次可以走 1、2 或 3 级，递推式是什么？
2. 全排列里为什么要 `used[i] = false`？
3. 组合为什么不需要 `used` 数组？

<details><summary>答案</summary>

1. f(n) = f(n-1) + f(n-2) + f(n-3)。
2. 回到上一层后，数字 i 又可以在别的位置使用了，需要恢复。
3. 因为每次都从上一个数 +1 开始选，选出的数严格递增，不会重复。

</details>
