# 数组：存一串数

当要保存很多个同类型的数据时，用数组。

## 定义和使用

```cpp
int a[100005];          // 开在 main 外面，自动清零，也不会栈溢出

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];   // 下标从 1 开始更直观
    for (int i = n; i >= 1; i--) cout << a[i] << " ";  // 倒序输出
}
```

**经验：** 数组开得比题目最大范围稍大一点（多开几个或几十个），并且定义在 `main` 外面。

## 计数数组（桶）

统计每个数出现了几次：

```cpp
int cnt[10];
// 统计 n 中每个数字出现的次数
while (n > 0) { cnt[n % 10]++; n /= 10; }
```

P1047 校门外的树、P1554 梦中的统计都是这个思路。

## 二维数组

```cpp
int g[105][105];
g[i][j] = 1;   // 第 i 行第 j 列
```

用来存表格、地图、矩阵。

## 常见错误

1. **数组越界**：下标超出了定义的大小，结果可能是错误答案也可能是运行错误（RE）。
2. 数组定义在 `main` 里面又很大，导致栈溢出。
3. 多组数据时忘记清空数组。
