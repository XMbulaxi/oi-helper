# 数组：存一串数

> **学完能做到**：保存和处理大量同类数据；用"桶"统计次数；使用二维数组表示表格和地图。
> **前置知识**：循环。

---

## 1. 为什么需要数组

题目给你 n 个数（n 可能到 10⁵），让你**倒着输出**。只用几个变量做不到，因为要把它们全部记住。数组就是**一排连续编号的盒子**。

## 2. 定义和使用

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;   // 比题目最大范围（10⁵）多开一点
int a[N];               // 定义在 main 外面：自动清零，空间也大

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];       // 读入
    for (int i = n; i >= 1; i--) cout << a[i] << " "; // 倒序输出
    return 0;
}
```

要点：

- `a[i]` 叫做数组的第 i 个**元素**，`i` 叫**下标**。
- 定义 `int a[N]` 后，合法下标是 `0` 到 `N-1`。
- 竞赛里常从下标 **1** 开始用，和题目"第 1 个、第 2 个"对应，不容易乱。
- **全局数组**（定义在 `main` 外面）会自动初始化为 0，而且可以开得很大（几千万个 int 都行）。`main` 里面的局部数组既不清零，开大了还会**栈溢出**。

## 3. 数组的基本操作

### 求和、最大值

```cpp
long long sum = 0;
int mx = a[1];
for (int i = 1; i <= n; i++) {
    sum += a[i];
    mx = max(mx, a[i]);
}
```

### 查找

```cpp
int pos = -1;
for (int i = 1; i <= n; i++) {
    if (a[i] == x) { pos = i; break; }
}
```

### 和前面的元素比较（P1428 小鱼比可爱）

对每个 i，数前面有几个比它小：

```cpp
for (int i = 1; i <= n; i++) {
    int cnt = 0;
    for (int j = 1; j < i; j++)
        if (a[j] < a[i]) cnt++;
    cout << cnt << " ";
}
```

两层循环，复杂度 O(n²)，n ≤ 100 很轻松。

## 4. 桶：用下标来计数

**想法**：如果要统计"每个数出现了几次"，而数的范围不大，就开一个数组 `cnt`，**用数本身当下标**：

```cpp
int cnt[1005];    // 假设数的范围是 0~1000
for (int i = 1; i <= n; i++) {
    int x;
    cin >> x;
    cnt[x]++;     // x 出现了一次
}
// 现在 cnt[5] 就是 5 出现的次数
```

### 用桶排序

```cpp
for (int v = 0; v <= 1000; v++)
    for (int k = 1; k <= cnt[v]; k++)
        cout << v << " ";
```

数值范围小的时候，这比任何排序都快。

### 例题：校门外的树（P1047）

马路上 0～L 每个整数点有一棵树，若干个区间要把树移走，问最后剩几棵。

```cpp
bool removed[10005];   // removed[i] 表示位置 i 的树是否被移走
int L, m;
cin >> L >> m;
while (m--) {
    int u, v;
    cin >> u >> v;
    for (int i = u; i <= v; i++) removed[i] = true;
}
int ans = 0;
for (int i = 0; i <= L; i++) if (!removed[i]) ans++;
cout << ans;
```

## 5. 二维数组

二维数组像一张表格：`g[i][j]` 表示第 i 行第 j 列。

```cpp
int g[105][105];
int n, m;
cin >> n >> m;
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        cin >> g[i][j];
```

**用途**：地图、棋盘、矩阵、表格。

### 矩阵转置

```cpp
// 输出 m 行 n 列的转置矩阵
for (int j = 1; j <= m; j++) {
    for (int i = 1; i <= n; i++) cout << g[i][j] << " ";
    cout << endl;
}
```

### 方向数组

在地图上向四周走时，用两个数组记录方向，避免写四遍：

```cpp
int dx[4] = {-1, 1, 0, 0};   // 上 下 左 右
int dy[4] = {0, 0, -1, 1};
for (int k = 0; k < 4; k++) {
    int nx = x + dx[k], ny = y + dy[k];
    if (nx >= 1 && nx <= n && ny >= 1 && ny <= m) {
        // (nx, ny) 是 (x, y) 的一个邻居
    }
}
```

## 6. 例题精讲：神奇的幻方（P2615）

按规则把 1～N×N 填进 N×N 的方格（N 是奇数）：

1. 1 放在第一行中间。
2. 对 K = 2, 3, …，看 K-1 的位置 (x, y)：
   - 在第一行但不在最后一列 → 放在最后一行、下一列；
   - 在最后一列但不在第一行 → 放在第一列、上一行；
   - 在第一行最后一列 → 放在正下方；
   - 都不是：如果右上方是空的，放在右上方；否则放在正下方。

这种题叫**模拟**：照着规则一条一条翻译成代码即可。

```cpp
int a[45][45];
int n; cin >> n;
int x = 1, y = (n + 1) / 2;
a[x][y] = 1;
for (int k = 2; k <= n * n; k++) {
    if (x == 1 && y != n)      { x = n; y = y + 1; }
    else if (y == n && x != 1) { y = 1; x = x - 1; }
    else if (x == 1 && y == n) { x = x + 1; }
    else if (a[x - 1][y + 1] == 0) { x--; y++; }
    else { x++; }
    a[x][y] = k;
}
```

## 7. 多组数据与清空

如果一个程序要处理多组数据，每组开始前要**清空**数组：

```cpp
memset(cnt, 0, sizeof(cnt));   // 把 cnt 全部设为 0
```

`memset` 只适合设成 0 或 -1（按字节填充的原因）。设成别的值用循环或 `fill`。

## 8. 易错点清单

1. **数组越界**：下标超过了定义的大小。可能导致答案错误或运行错误（RE），而且很难查。数组开大一点（多开 5～10 个）。
2. **局部大数组**：放在 `main` 里会栈溢出，而且初值是随机的。
3. **多组数据忘记清空**。
4. **下标从 0 还是从 1**：全程统一一种。

## 10. 自测

1. `int a[10];` 的合法下标范围是什么？
2. 为什么大数组要开在 main 外面？
3. 数的范围是 1～10⁹，还能用桶计数吗？

<details><summary>答案</summary>

1. 0 到 9。
2. 全局数组自动清零，而且不会栈溢出。
3. 不能直接开 10⁹ 的数组（内存不够）。可以排序后统计，或者以后学的 `map`。

</details>
