# 循环结构：for 和 while

> **学完能做到**：让程序重复做事；拆数字、求和、判断质数、打印图形。
> **前置知识**：顺序结构、分支结构。

---

## 1. 为什么需要循环

求 1 + 2 + … + 100，不可能写 100 个加号。循环让计算机重复执行同一段代码。

## 2. for 循环

```cpp
for (初始化; 条件; 每次之后做什么) {
    循环体
}
```

例：求 1 到 n 的和

```cpp
long long sum = 0;           // 累加器一定要先清零
for (int i = 1; i <= n; i++) {
    sum += i;                // sum = sum + i
}
```

执行过程（n = 3）：

| 步骤 | i | 条件 i<=3 | sum |
| --- | --- | --- | --- |
| 初始化 | 1 | 成立 | 0 → 1 |
| i++ | 2 | 成立 | 1 → 3 |
| i++ | 3 | 成立 | 3 → 6 |
| i++ | 4 | 不成立，结束 | 6 |

**适合**：知道要循环多少次。

### 常见写法

```cpp
for (int i = 1; i <= n; i++)    // 1, 2, ..., n
for (int i = 0; i < n; i++)     // 0, 1, ..., n-1
for (int i = n; i >= 1; i--)    // n, n-1, ..., 1（倒着）
for (int i = 2; i <= n; i += 2) // 2, 4, 6, ...（步长为 2）
```

## 3. while 循环

```cpp
while (条件) {
    循环体
}
```

**适合**：不知道要循环多少次，只知道什么时候停。

### 拆数字（必会）

```cpp
// 依次输出 n 的个位、十位、百位……
while (n > 0) {
    int d = n % 10;   // 取出个位
    cout << d << " ";
    n /= 10;          // 去掉个位
}
```

n = 365 时：取 5，n 变 36；取 6，n 变 3；取 3，n 变 0，停止。

用这个模板可以：求各位数字之和、数某个数字出现几次、把数字倒过来。

### 数字反转

```cpp
long long rev = 0;
while (n > 0) {
    rev = rev * 10 + n % 10;
    n /= 10;
}
```

n = 123：rev = 3 → 32 → 321。

### do-while

至少执行一次再判断条件，很少用，知道即可：

```cpp
do { ... } while (条件);
```

## 4. break 和 continue

- `break`：立刻跳出**整个**循环。
- `continue`：跳过**本次**剩下的部分，直接进入下一次。

```cpp
for (int i = 1; i <= 100; i++) {
    if (i % 3 == 0) continue;   // 跳过 3 的倍数
    if (i > 50) break;          // 超过 50 就结束
    cout << i << " ";
}
```

## 5. 判断质数（必会）

质数：大于 1，且只能被 1 和它自己整除。

**想法**：如果 n 有一个因数 d，那么 n/d 也是因数，两者中较小的一定 ≤ √n。所以只要试到 √n 就够了。

```cpp
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; (long long)i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}
```

- 用 `i * i <= n` 而不是 `i <= sqrt(n)`，避免小数误差。
- n 很大时 `i * i` 可能溢出，所以转成 `long long`。
- 试到 √n，复杂度 O(√n)，n = 10⁹ 时也只要约 3 万次。

（`bool` 函数的写法下下课会细讲，这里先照着用。）

## 6. 嵌套循环

循环里面再套一个循环。外层循环每走一步，内层循环要完整走一遍。

### 打印直角三角形

```cpp
for (int i = 1; i <= n; i++) {        // 第 i 行
    for (int j = 1; j <= i; j++) {    // 第 i 行有 i 个星号
        cout << "*";
    }
    cout << endl;
}
```

n = 3 时输出：

```
*
**
***
```

### 枚举两个数

```cpp
// 找所有满足 a + b = 10 的正整数对
for (int a = 1; a <= 9; a++)
    for (int b = 1; b <= 9; b++)
        if (a + b == 10) cout << a << " " << b << endl;
```

## 7. 找最大值、最小值

```cpp
int mn = INT_MAX;     // 先设一个"不可能更大"的初值
for (int i = 1; i <= n; i++) {
    int x;
    cin >> x;
    mn = min(mn, x);
}
```

也可以把第一个数当作初值。**不要**把初值设成 0：如果所有数都是正数，最小值会错成 0。

## 8. 循环会跑多久

计算机每秒大约能做 **10⁸** 次简单运算（加法、比较等）。

| 循环 | 次数 | 1 秒内？ |
| --- | --- | --- |
| 一层到 10⁷ | 10⁷ | 很快 |
| 两层各到 10⁴ | 10⁸ | 差不多 |
| 两层各到 10⁵ | 10¹⁰ | 超时 |

写代码前先估算，养成好习惯。

## 9. 例题精讲：计数问题（P1980）

问 1 到 n 中，数字 x 一共出现了多少次。

```cpp
int n, x, cnt = 0;
cin >> n >> x;
for (int i = 1; i <= n; i++) {
    int t = i;              // 不能直接拆 i，否则会破坏循环变量
    while (t > 0) {
        if (t % 10 == x) cnt++;
        t /= 10;
    }
}
cout << cnt << endl;
```

> 注意：拆数字时**复制一份**再拆，直接改 `i` 会让外层循环乱掉。

## 10. 例题精讲：金币（P2669）

骑士第 1 天得 1 枚，接下来 2 天每天 2 枚，再接下来 3 天每天 3 枚……问前 k 天共多少金币。

**模拟**：用 `now` 表示当前每天的金币数，`left` 表示这个金额还剩几天。

```cpp
int k, now = 1, left = 1;
long long sum = 0;
for (int day = 1; day <= k; day++) {
    sum += now;
    left--;
    if (left == 0) {       // 这个阶段结束，进入下一个阶段
        now++;
        left = now;
    }
}
```

## 11. 易错点清单

1. **死循环**：`while` 里忘记改变变量，条件永远成立。
2. **累加器没清零**：`sum` 一定要初始化为 0。
3. **边界差一**：`i < n` 和 `i <= n` 想清楚。
4. **拆数字时改坏了循环变量**：先复制一份。
5. **最小值初值设成 0**。
