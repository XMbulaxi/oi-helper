# 循环结构：for 和 while

让计算机重复做一件事。

## for 循环

```cpp
for (int i = 1; i <= n; i++) {
    sum += i;
}
```

知道要循环多少次时用 `for`。

## while 循环

```cpp
while (n > 0) {
    cout << n % 10;   // 取出个位
    n /= 10;          // 去掉个位
}
```

不知道要循环多少次、只知道什么时候停时用 `while`。上面这段是**拆数字**的固定写法，非常常用。

## break 和 continue

- `break`：立刻跳出整个循环。
- `continue`：跳过这一次，进入下一次。

## 判断质数

```cpp
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
```

只需要试到 √n，用 `i * i <= n` 代替 `i <= sqrt(n)` 可以避免小数误差。

## 嵌套循环

打印图形、枚举两个数时会用到两层循环。外层控制"行"，内层控制"列"。

## 常见错误

1. 死循环：`while` 的条件永远成立，忘记改变变量。
2. 累加变量 `sum` 忘记初始化为 0。
3. 循环边界差一：`i < n` 和 `i <= n` 想清楚。
