# 暴力枚举

> **学完能做到**：把所有可能的情况列出来逐一检查；估算枚举量，判断会不会超时；用技巧减少枚举。
> **前置知识**：循环、数组、函数。

---

## 1. 什么是枚举

枚举就是"**把所有可能都试一遍**"。它的思路最简单，只要情况数不太多，就是最稳的方法。很多难题的**部分分**也可以用枚举拿到。

## 2. 枚举三问

1. **枚举什么？** 答案本身？某个参数？一对数？
2. **范围是多少？** 从几到几？
3. **怎么判断？** 满足什么条件才算？

## 3. 估算复杂度

计算机 1 秒大约做 **10⁸** 次简单运算。写之前先算一下：

| 数据范围 | 能接受的枚举方式 |
| --- | --- |
| n ≤ 10 | 枚举所有排列 n!（3.6×10⁶） |
| n ≤ 20 | 枚举所有子集 2ⁿ（10⁶） |
| n ≤ 500 | 三层循环 n³ |
| n ≤ 5000 | 两层循环 n² |
| n ≤ 10⁶ | 一层循环 n，或 n log n |

**看数据范围猜算法**，是 OI 里非常实用的技能。

## 4. 例题精讲：烤鸡（P2089）

10 种配料，每种放 1～3 克，总质量为 n。输出所有方案。

每种配料 3 种选择，共 3¹⁰ = 59049 种，完全可以全部枚举。最直接的写法是 10 层循环：

```cpp
for (int a = 1; a <= 3; a++)
for (int b = 1; b <= 3; b++)
// ... 共 10 层
    if (a + b + ... == n) { 记录方案 }
```

写 10 层很丑，学了递归后可以这样：

```cpp
int n, cnt, cur[11];
vector<array<int, 10>> ans;

void dfs(int k, int sum) {        // 正在决定第 k 种配料
    if (sum > n) return;          // 剪枝：已经超了
    if (k == 10) {
        if (sum == n) {
            array<int, 10> t;
            for (int i = 0; i < 10; i++) t[i] = cur[i];
            ans.push_back(t);
        }
        return;
    }
    for (int g = 1; g <= 3; g++) {
        cur[k] = g;
        dfs(k + 1, sum + g);
    }
}
```

## 5. 例题精讲：三连击（P1618 升级版）

把 1～9 分成三个三位数 A、B、C，使 A:B:C = a:b:c。输出所有解。

**笨办法**：枚举 9 个数字的全排列（9! = 362880），再检查比例。可以，但写起来麻烦。

**聪明办法**：只枚举 A（123～987），B 和 C 可以**算出来**：B = A × b / a，C = A × c / a。然后检查：

1. 能否整除（A × b % a == 0）。
2. B、C 都是三位数。
3. A、B、C 的 9 个数字恰好是 1～9 各一个。

```cpp
bool check(int A, int B, int C) {
    int cnt[10] = {0};
    for (int x : {A, B, C}) {
        while (x) { cnt[x % 10]++; x /= 10; }
    }
    if (cnt[0]) return false;
    for (int d = 1; d <= 9; d++) if (cnt[d] != 1) return false;
    return true;
}

for (int A = 123; A <= 987; A++) {
    if (A * b % a || A * c % a) continue;
    int B = A * b / a, C = A * c / a;
    if (B > 999 || C > 999) continue;
    if (check(A, B, C)) { 输出; found = true; }
}
```

> **能算出来的量就不要枚举**，这是减少枚举量最重要的技巧。

## 6. 例题精讲：涂国旗（P3392）

N 行 M 列，要把它改成"上面若干行全白、中间若干行全蓝（至少一行）、下面若干行全红"，问最少改几个格子。

**枚举分界线**：白色占第 1～i 行，蓝色占第 i+1～j 行，红色占第 j+1～N 行。枚举 i 和 j（O(N²)），再算需要改的格子数。

预处理每一行改成白/蓝/红分别要改几个格子：`costW[r]`、`costB[r]`、`costR[r]`。

```cpp
int best = INT_MAX;
for (int i = 1; i <= n - 2; i++)
    for (int j = i + 1; j <= n - 1; j++) {
        int s = 0;
        for (int r = 1; r <= i; r++) s += costW[r];
        for (int r = i + 1; r <= j; r++) s += costB[r];
        for (int r = j + 1; r <= n; r++) s += costR[r];
        best = min(best, s);
    }
```

总共 O(N³)，N ≤ 50 很轻松。（学了前缀和后可以做到 O(N²)。）

## 7. 枚举子集：二进制法

n 个物品，每个选或不选，共 2ⁿ 种。用一个整数的二进制位表示选择：第 i 位是 1 表示选第 i 个。

```cpp
for (int mask = 0; mask < (1 << n); mask++) {
    int sum = 0;
    for (int i = 0; i < n; i++)
        if (mask >> i & 1) sum += w[i];
    // 检查 sum
}
```

`1 << n` 就是 2ⁿ；`mask >> i & 1` 取出第 i 位。

## 8. 例题精讲：火柴棒等式（P1149）

用 n 根火柴摆出 A + B = C（A、B、C 是非负整数），问有多少种。数字 0～9 分别需要 6,2,5,5,4,5,6,3,7,6 根火柴，`+` 和 `=` 各 2 根。

n ≤ 24，除去符号最多 20 根，可以估计 A、B 都不会超过 1000 左右。枚举 A 和 B（各到 1000，共 10⁶），算出 C = A + B，再数火柴：

```cpp
int need[10] = {6, 2, 5, 5, 4, 5, 6, 3, 7, 6};
int sticks(int x) {
    if (x == 0) return 6;
    int s = 0;
    while (x) { s += need[x % 10]; x /= 10; }
    return s;
}
int ans = 0;
for (int A = 0; A <= 1000; A++)
    for (int B = 0; B <= 1000; B++)
        if (sticks(A) + sticks(B) + sticks(A + B) + 4 == n) ans++;
```

> 枚举的范围不确定时，可以先写个程序试一试：上界改大一点，看答案会不会变。

## 9. 易错点清单

1. 没估算复杂度就开写，结果超时。
2. 枚举范围漏了边界（0、最大值）。
3. 重复计数：(A, B) 和 (B, A) 是否算同一种，要看题意。
4. 能算的量也去枚举，白白多一层循环。

**进阶题**

- P2241 统计方形：n、m 到 5000，枚举所有矩形是 O(n²m²)，会超时。换个思路：枚举矩形的**长和宽**（O(nm)），长 a 宽 b 的矩形在 n×m 的棋盘里有 (n-a+1)(m-b+1) 个，a == b 时是正方形。
- P3799 小 Y 拼木棒：四根木棒拼正三角形，必须是两根一样长的 + 两根加起来和它们一样长的。木棒长度值域小，用桶计数，枚举"一样长的那两根"的长度和另外两根中的一根，组合数计数并取模。

2. n ≤ 2000，O(n²) 和 O(n³) 哪个能过？
3. 三连击里为什么只枚举 A？
