# 模拟

> **学完能做到**：把题目描述的过程一步一步翻译成代码；处理复杂的规则和输出格式。
> **前置知识**：分支、循环、数组、字符串。

---

## 1. 什么是模拟

模拟题不需要什么特别的算法，**题目怎么说，你就怎么做**。难点在于：规则多、细节多、容易漏情况。NOIP 和 CSP 每年几乎都有一道模拟题，是拿分的关键。

## 2. 做模拟题的步骤

1. **仔细读题，列出所有规则**。最好在草稿纸上编号写下来。
2. **设计数据怎么存**：用什么变量、数组表示"当前状态"。
3. **一条规则对应一段代码**，按顺序翻译。
4. **用样例手推一遍**，和代码的中间输出对比。
5. **想特殊情况**：0、1、最大值、全部相同、刚好等于边界……

## 3. 例题精讲：铺地毯（P1003）

n 张地毯按顺序铺在地上，第 i 张左下角是 (a, b)，长 g、宽 k。问点 (x, y) 最上面是哪张地毯，没有输出 -1。

**思路**：后铺的盖在上面，所以**从最后一张往前找**，第一张覆盖了 (x, y) 的就是答案。

```cpp
int n;
cin >> n;
vector<array<int, 4>> c(n + 1);
for (int i = 1; i <= n; i++) cin >> c[i][0] >> c[i][1] >> c[i][2] >> c[i][3];
int x, y;
cin >> x >> y;
int ans = -1;
for (int i = n; i >= 1; i--) {
    auto [a, b, g, k] = c[i];
    if (a <= x && x <= a + g && b <= y && y <= b + k) { ans = i; break; }
}
cout << ans;
```

> 注意边界：地毯的边缘也算覆盖，所以用 `<=`。

## 4. 例题精讲：玩具谜题（P1563）

n 个玩具小人围成一圈，每个小人面朝圈内或圈外。从第 1 个开始，按指令"向左数 s 个"或"向右数 s 个"，问最后到了谁。

**关键**：面朝内时的"左"等于面朝外时的"右"。把四种情况合并：

| 朝向 | 指令 | 编号变化 |
| --- | --- | --- |
| 朝内（0） | 左（0） | 减 s |
| 朝内（0） | 右（1） | 加 s |
| 朝外（1） | 左（0） | 加 s |
| 朝外（1） | 右（1） | 减 s |

发现：朝向和指令**相同**时减，**不同**时加。

```cpp
int pos = 0;                         // 编号用 0..n-1，取模更方便
for (int i = 0; i < m; i++) {
    int dir, s;
    cin >> dir >> s;
    if (face[pos] == dir) pos = (pos - s % n + n) % n;
    else pos = (pos + s) % n;
}
cout << name[pos];
```

**技巧**：

- 环形结构用下标 0～n-1，前进 `(pos + s) % n`，后退 `(pos - s % n + n) % n`（加 n 防止负数）。
- 找规律合并情况，代码更短、更不容易错。

## 5. 例题精讲：乒乓球（P1042）

给出比赛中每一球的胜负（W/L），到 E 结束。分别按 11 分制和 21 分制输出每局比分。一局结束的条件：**某人达到 11（或 21）分，且领先对方至少 2 分**。

```cpp
string all, line;
while (cin >> line) {
    for (char c : line) {
        if (c == 'E') goto done;
        all += c;
    }
}
done:
for (int lim : {11, 21}) {
    int w = 0, l = 0;
    for (char c : all) {
        if (c == 'W') w++; else l++;
        if (max(w, l) >= lim && abs(w - l) >= 2) {
            cout << w << ":" << l << "\n";
            w = l = 0;
        }
    }
    cout << w << ":" << l << "\n\n";   // 最后一局（可能是 0:0）也要输出
}
```

易错点：

- 输入可能分成很多行。
- 最后一局即使没打完、甚至是 0:0 也要输出。
- 两种赛制之间有一个空行。

## 6. 例题精讲：多项式输出（P1067）

给出一元 n 次多项式的系数，按规则输出。规则非常多，正是练模拟的好题：

1. 系数为 0 的项不输出。
2. 最高次项系数为正时前面不输出 `+`，其它正系数项前面输出 `+`。
3. 系数为 1 或 -1 时（非常数项）不输出 1，只输出符号。
4. 指数大于 1 输出 `x^k`，等于 1 输出 `x`，等于 0 只输出系数。

```cpp
for (int i = n; i >= 0; i--) {
    int a; cin >> a;
    if (a == 0) continue;
    if (a > 0 && i != n) cout << "+";
    if (a < 0) cout << "-";
    int v = abs(a);
    if (v != 1 || i == 0) cout << v;
    if (i > 1) cout << "x^" << i;
    else if (i == 1) cout << "x";
}
```

把规则逐条对应到代码，再拿样例检查。

## 7. 调试技巧

模拟题代码长，出错是常态，关键是**会查错**：

1. **打印中间状态**：每处理一步就输出当前变量的值，和手推的结果对比。
   ```cpp
   cerr << "step " << i << ": pos=" << pos << endl;   // cerr 不影响评测输出
   ```
   交题前删掉或注释掉。
2. **造小数据**：自己编几组简单输入，手算答案再对比。
3. **一段一段测**：先确认输入读对了，再确认每条规则。

## 8. 易错点清单

1. 漏了某条规则或某种情况。
2. 边界条件：`<` 还是 `<=`，从 0 还是从 1。
3. 环形下标出现负数。
4. 输出格式：空格、换行、空行、最后一项。
5. 输入格式：数据分几行、什么时候结束。

## 10. 自测

1. 环形有 n 个位置（0～n-1），从 pos 后退 s 步，怎么写才不会出现负数？
2. 调试时用 `cerr` 而不是 `cout` 输出中间结果，有什么好处？

<details><summary>答案</summary>

1. `(pos - s % n + n) % n`
2. `cerr` 输出到错误流，不会混进评测的标准输出（不过交题前最好还是删掉，避免拖慢速度）。

</details>
