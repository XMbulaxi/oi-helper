# OI 学习助手

一个 VS Code 插件，给机房的学弟学妹用：按学习路线每天生成题单，配知识点讲解，并从洛谷同步 AC 记录。

## 功能

- **两条学习路线**：零基础路线（9 个单元，C++ 语法到递归）和普及组路线（13 个单元，高精度到最短路）。
- **今日题单**：每天从路线里挑出接下来没做的几道题（默认 3 道，可在设置里改），一天之内不会变。做完了可以点 **+** 再来一题。
- **进度计划**：每个单元有建议天数，插件会告诉你比计划快了还是慢了。
- **知识点讲解**：每个单元有一篇讲解，包括要点、C++ 模板代码和常见错误。
- **洛谷同步**：填上洛谷用户名，AC 的题会自动打勾。同步不了时也可以手动打勾。
- **新建代码文件**：点题目旁边的按钮，自动在 `luogu/` 文件夹里建好 `P1001.cpp` 并写好头文件。

## 安装

1. 下载 `oi-helper-x.y.z.vsix`。
2. 在 VS Code 里按 `Ctrl+Shift+P`，输入 `Install from VSIX`（从 VSIX 安装），选择下载的文件。
3. 左边活动栏会出现 **OI 学习助手** 的图标，点开后选择学习路线。

## 洛谷同步说明

洛谷没有官方公开的接口，插件读取的是洛谷网页"练习"页面用的数据。

- 在设置 `oiHelper.luoguUser` 里填用户名或 UID。
- 如果提示需要登录：在浏览器登录洛谷，按 F12 打开开发者工具，在"应用 / Application → Cookies → https://www.luogu.com.cn"里找到 `__client_id` 和 `_uid` 两行，按 `__client_id=xxx; _uid=xxx` 的格式拼好。然后在 VS Code 里按 `Ctrl+Shift+P`，运行"设置洛谷 Cookie"，粘贴进去。Cookie 只保存在你自己的电脑上，**不要发给别人**。在浏览器里退出洛谷登录会让这个 Cookie 失效，到时重新复制一次即可。
- 如果洛谷改了网页导致同步失败，需要修改的代码在 `src/luogu.ts`。

## 怎么改内容（不用会写代码）

所有内容都在 `content/` 文件夹里：

```
content/
  routes/zero.json      零基础路线：单元、建议天数、题目
  routes/puji.json      普及组路线
  lessons/zero/*.md     零基础路线的讲解
  lessons/puji/*.md     普及组路线的讲解
```

**加一道题**：在对应单元的 `problems` 里加一行 `{ "pid": "P1234", "title": "题目名" }`。同一道题不要在两个单元里重复出现。

**加一个单元**：在 `units` 里加一项，写好 `id`、`title`、`days`、`lesson`（讲解文件路径）和 `problems`，再在 `lessons/` 里新建对应的 `.md` 文件。

改完后运行 `npm test`，它会检查讲解文件是否存在、题号格式是否正确、有没有重复的题。

## 开发

需要 Node.js 18 以上。

```bash
npm install
npm test          # 编译并运行测试
npm run package   # 打包成 .vsix
```

在 VS Code 里打开本文件夹，按 F5 可以启动一个装好插件的调试窗口。

代码结构：

- `src/plan.ts`：每日题单和进度计算（纯逻辑，有单元测试）
- `src/luogu.ts`：洛谷同步
- `src/extension.ts`：VS Code 界面、命令和本地存储
